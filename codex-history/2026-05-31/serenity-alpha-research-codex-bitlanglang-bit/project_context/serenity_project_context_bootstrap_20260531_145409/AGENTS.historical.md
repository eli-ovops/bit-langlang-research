# AGENTS.md

Project: Serenity Alpha Research

This project is fully independent from BitLangLang / bitlanglang. Do not import,
inherit, cite, or mix BitLangLang fields, H-series numbering, paper observation,
small-live concepts, crypto trading logic, or any crypto trading system concept.

## Core Mode

- Research-only.
- Public-source evidence only.
- US equity research framework engineering and deep-dive preparation.
- No brokerage, order, holding, balance, equity, secret, token, cookie, or
  private API access.

## Hard Prohibitions

Never output:

- Buy recommendations.
- Sell recommendations.
- Target prices.
- Position sizing.
- Entry points.
- Trading plans.
- Current buy lists.

Never access or print:

- Brokerage accounts.
- API keys, secrets, tokens, cookies, SSH keys, or `.env`.
- Real orders, holdings, balances, or account equity.

Never create:

- Scheduler.
- Cron.
- Service.
- Monitor.
- Automated trading workflow.

## Allowed Sources

Allowed research-only sources include:

- Public SEC / EDGAR filings.
- Company IR pages.
- Company filings and press releases.
- Exchange filing links.
- Reputable public news sources.

No login, paid-wall bypass, private API, brokerage access, or secret access is
allowed.

## Evidence Discipline

Every output must separate:

- Evidence.
- Confirmation.
- Outcome.

Social-media heat can only be treated as crowding risk. It must never be treated
as positive evidence.

Historical stock movement is not current evidence.

Demo, sample, evaluation, pilot, and MoU evidence must not be treated as
production revenue.

Hard STOP gates must be checked before scoring.

Final responses should be short summaries and include ZIP path/hash when a ZIP
is generated.
