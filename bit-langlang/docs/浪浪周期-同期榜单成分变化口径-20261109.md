# 同期榜单成分变化检查口径

沿用此前固定的 2023Q1、2025Q2 每季度全部 13 个周观察及经修复的页面解析，不新增样本。每季度只比较时间上相邻的预定周点，合计 24 对；只要任一端页面为 UNKNOWN，该对即 UNKNOWN，不跨缺失点拼接。抓取时间和报价指标内部截止不同，先记两次存档间隔，且不将页面读数当成 UTC 周点的实时状态。

对两次页面原排行前 30 行提取 CoinGecko 数字 `data-coin-id`，验证各页身份字段非空且在页内唯一；按同一 ID 做集合交集。记录重合数、离开与进入数量；逐个对重合者分别记录页面可见的7日上涨、下跌、显示 0.0% 状态，以及跌转涨、涨转跌的数量。零是显示精度而非精确零，缺值/冲突则 UNKNOWN。直接从保存的页面核查 7d 方向样式、文本和 `data-sort`，并复核摘要。

这是已接触历史上的来源质量和样本构成检查，不利用旧量化候选或未来走势。前30名包括稳定币和包装资产，仍不能代表全市场、独立风险资产或真实情绪，不能由资产同步变化推定因果、定义阶段或宣称盈利。该统计非用户交易选币；不设计入场和交易。任何平台 start/stop 前先告知。
