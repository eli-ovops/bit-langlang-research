# 2014 年摆点后价格状态：两所历史检验

**结论：本轮两所同在摆高上方、或都在摆低下方的状态，仍不足以区分春天启动与下跌反弹、秋天衰退与正常回调。**在本轮可核对的案例里，两种状态之后均出现过价格返回原摆点边界内侧；一笔固定区间下破后次日也返回。缺少独立真人阶段标签，不能计算真实漏判率或认定假突破，不能说已经复刻浪浪。

## 预定义和数据质量

[定义](摆点状态-2014两所历史事前定义-20261102.md) 在获取 2014 行情前写定，沿用此前 56/28/8 日固定背景、日线两侧各 2 根确认摆点、摆点穿越后保持 STALE 的规则。新增的 ABOVE/BELOW/INSIDE 只描述截至观察时前一完整日收盘位于本所摆高上方、摆低下方或中间；它不等同新突破、趋势或季节。两所均满足同一位置才记 JOINT；价格、边界均独立计算、不混拼。

历史是 BTC/USD **现货**，不是 BTC/USDT 或当年永续；2014-06-02 至 11-24 UTC 每周 26 点，数据覆盖 2014-04-01 至 2015-01-01，包含 56 日预热及 28 日后续。定向搜索未发现目标时段参与当前状态规则设计，但公开历史可能被模型或研究者接触；2015 已用于该状态设计，不能说方法无既有历史启发。不能称严格盲测、前瞻或真人独立标签。

Bitstamp 和 Bitfinex 4h 时间网格均 1650/1650、OHLC 合法；Bitfinex 原始 1h 按四根独立合成并逐柱复核。但 08-14 08:00 UTC 的 4h 最低价分别为 502.99、451 USD，触发事前规定的跨所 >10% 高低价质量警报。原因可能是交易所真实成交差异或数据问题，UNKNOWN；两所该日及受影响窗口保守留空，不代换价格。因它位于摆点 56 日窗口，26 点中 **8 点的双所摆点位置 UNKNOWN**。因此本轮是“两所时间网格完整”，不是“全期价格质量均已确认”。[数据与原始请求](../data/market/btc-2014-usd-cross-20261102-01/manifest.json)。

## 全量覆盖，不是阶段准确率

两所各自计算，26 个时点旧联合候选中 UNKNOWN 19、NO_JOINT_CANDIDATE 5、可能转强 1、可能转弱 1；两所价格状态为 JOINT_ABOVE 2、JOINT_BELOW 4、JOINT_INSIDE 12、UNKNOWN 8。旧 UNKNOWN 中的 6 个外侧状态被新字段保留下来，但这只增加位置事实，不能叫阶段覆盖或真实漏判率改善。样本每周相邻、使用共同 56 日窗口，结果高度重叠；一个市场时段与两个相关价格源不能当成大量独立市场周期。

## 启动与反弹、衰退与回调：竞争证据

所有价位均为各所美元现货，时间 UTC，后续结果只在事件发生后可知，不回填观察时点。

- **06-02，两所在摆高上方：**Bitstamp 观察前日收 P=630.99，已确认摆高 H=595；Bitfinex P=626.42、H=597.30。两个摆点均已过时、旧联合状态 UNKNOWN，新位置均 ABOVE；其后 7 个完整日没有收盘回到各自 H 下方，但 Bitstamp 在 06-13 00:00 收 569.10、Bitfinex 在 06-15 00:00 收 570.27，均于 28 日内回收。28 日结束价分别为 599.89、601.95，相对观察时约 -4.93%、-3.91%。这反驳“摆点上方就必然持续上涨”，不能仅据此断定当时不是真正春天。
- **06-16，两所在摆低下方却随后回升：**Bitstamp P=588.55、L=635.88，Bitfinex P=593.89、L=637.01；前 7 个完整日均未收盘回到 L 上方，但 07-01 00:00 两所分别收 641.11、640.79，28 日内返回。28 日结束价 630.88、629.49，分别较观察时 +7.19%、+5.99%。Bitfinex 旧 autumn_watch YES、Bitstamp NO，因为两所 28 日背景不同；不能把该分歧或后的上涨算作任何一方真实对错。
- **11-10，两所在摆高上方后回收：**Bitstamp P=364.77、H=353.10，Bitfinex P=362.61、H=354.32。7 日内未收回，而 11-22 00:00 两所分别收 351.20、350.46，回到 H 以下；28 日结束仍分别较观察时高约 3.42%、3.70%。因此“28 日收盘涨跌”和“期间曾收回摆点”描述不同问题，都不能充当真实春天标签。
- **11-24，两所旧秋观察 YES：**此前固定大背景 UP、小层 DOWN，摆点为 ACTIVE_DOWN，价格仍在确认摆点区间内。Binance 没有参与；Bitstamp 原固定 28 日低点 L=316.61，12-19 00:00 日收 312.67 跌破，12-20 00:00 日收 318.33 返回 L 上方；Bitfinex 的 L=315.54，同日先收 311.77、次日 318.47，亦返回。28 日结束价两所相对观察时约 -12.84%、-12.89%。这同时展示了走弱后的日收回现象；既不能将其直接认定为市场操纵，也无法独立确认观察当天的真实季节。

两个 ABOVE 时点的两个来源在 7 日均未收回、28 日均收回；四个 BELOW 时点中三点两所均在 28 日内收回，07-28 因后续质量警报 UNKNOWN。观察点少、窗口重叠，不能把比例当假突破概率；两所同属 BTC 现货，也不是独立人工判读。

## 减少不必要留空的新观察

对 09-22，56 日摆点窗口受 08-14 的受疑价格影响而 UNKNOWN；但两所各自此前 **28 日固定层与 8 日小层均为 DOWN**，两个较短窗口未含该受疑日。应当保留“较短层走弱”的可见事实，同时将长背景、摆点及季节留空。不能把某一层可用误称为完整春秋判断，也不应因为长层有问题就隐去可靠的短层信息。该处理不更改事前摆点规则，仅呈现已经独立计算的分层结果。
