# 周期连续复盘：2015Q2、2024Q3 和 2026Q1

## 结论

本轮完整保留三个季度的逐日价格证据。可比的 2024-07-15 与 2026-02-19，两所各自的研究结构都为较长 DOWN、中期 DOWN、短期 UP，即下行背景里出现小级别上行。Bitstamp 的前一完整日收在当时前28日高低区间中的相对位置分别约 **53%** 和 **21%**：前者后来日收上破当时冻结上沿、再收回；后者之后21个完整日没有日收越过当时冻结上下沿。位置为观察时已知，后续事件则分别在后面才可知。

两例说明背景相同不意味着结构、空间和后续一样；但不能只凭位置推断“春天启动”或“下跌反弹”。同样，上涨背景中的小级别回落在收回参考下沿后仍可能再次跌破。真实阶段、情绪、市场广度、浪浪同期判断、独立人工阶段标签和真实漏判/假突破为 UNKNOWN。56/28/8、相对位置及四季名词均为研究工具，不是浪浪本人确认的数学规则。

## 研究范围与边界

按[主要定义](周期研究-2015二季度与2026一季度连续复盘定义-20261104.md)筛查 [2015-04-01,2015-07-01) 和 [2026-01-01,2026-04-01)；看到2015 Kraken大量缺柱后，另按[事后补充定义](周期研究-2024三季度补充复盘定义-20261104.md)筛查 [2024-07-01,2024-10-01)。三个季度此前均被项目直接或间接接触；2024Q3补选发生在看到2015缺口后，全部均为历史回顾，不是严格独立盲测或样本外准确率。

逐日保留 Bitstamp 与 Kraken BTC/USD 现货各自事实，不跨所补价。每7日分段，末段截至季度末；每个段首UTC 00:00仅用已完成的56日、28日日线和8日4h结构、上一完整日收及前28日高低边界。UP为两个半窗口高低均上移、DOWN均下移、INSIDE后半位于前半内部、MIXED为其他。固定的前28日边界是可重复的研究参考，不是唯一的真实关键位。观察点之后最长21日首次严格日收越界及其后7日是否收回另记，只在后来各自收盘后可知；等值不算严格越界或收回。下面价格为 Bitstamp；百分比是对应段末BTC价格变化，不是交易收益。相邻段窗口及越界事件可能高度重叠，不是独立事件或胜率。

## 核验与后续限制

2024Q3和2026Q1每所所需窗口分别1062/1062和1050/1050根4h，OHLC、4h正量和预设同期高低比 >1.1/<0.9 警报通过；2024Q3价格范围早于2024-04-14 Kraken已知缺口，不得扩大成 Kraken全年无缺口。2015缺柱与预热期跨所警报按规定留空。宽松极值警报无触发、正量和网格完整不认证全部成交真实。

三个季度共80条来源级分段的段首字段与逐日表一致；改变每段后续价格不改变段首输入。2024-07-15两所、2026-02-19 Bitstamp、2026-01-22 Kraken，用4h原数据独立复核前28日上下沿和未来21日日收首次越界；已有1项字段覆盖回归测试通过。这些验证不证明真实阶段或预测有效性。
