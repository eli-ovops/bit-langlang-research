# 摆点后价格状态：2014 两所历史事前检验

## 目的与样本
只研究 BTC 春启动/下跌反弹与秋衰退/正常回调的结构解释，不选币、入场、交易或操作策略 start/stop；固定窗口、摆点、期限、阈值均是研究假设，不是 Bit浪浪原话，真实季节及情绪 UNKNOWN。此前 2015 已用于设计价格事实字段，不能将 2015 当成它的独立验证。定向检索本地 docs/verify 的阶段及摆点研究未发现 2014-04–12 用于该字段设计；该公开历史可能被模型、研究者或项目其他途径认识，故称「未发现参与本规则设计的历史时段」，不称严格盲测、真实独立标签或前瞻。2014 USD 现货与后年 USDT/永续产品不同。

数据目标 [2014-04-01,2015-01-01) BTC/USD 现货；固定 2014-06-02 至 11-24 UTC 00:00 每周一次 26 点，有 56 日日线预热和 28 日后续。预设 Bitstamp 4h 与 Bitfinex 1h 各自聚合 4h；保留原始响应、哈希、原始缺失、4h时间网格与 OHLC；一所缺柱不得由另一所填补。两所同 4h 高低价比值超 10% 为事先数据审查警报，双方将该柱所在日排除，影响窗口 UNKNOWN；警报不能证明交易有误、未报警也不能证明成交真实。只有两所及所需窗口实际完整才称该窗口可比；若整个区间缺失或有价格警报不得称全期完整。

## 固定规则与状态

不改 2015 已冻结的 56/28/8 日固定窗口、日线左右各两日确认摆点（j+3 UTC 最早可知、相等/同日双摆点不确认）、以及已穿越后摆点仍 STALE 的规则。单所完整时，比较决策前最后完整日收盘 P 与当前最近已确认摆高 H、摆低 L，P>H 为 ABOVE、P<L 为 BELOW、否则 INSIDE，H<=L 或必需数据不全 UNKNOWN；旧摆点若曾突破仍标过时。两所各自 ABOVE/BELOW/INSIDE 同为对应 JOINT 值；不一致 DISAGREE，任一未知为 UNKNOWN，不互相填价。旧联合候选仍原样并排，单所事实不能冒充两所确认。

所有 26 点、所有非触发时点均留在逐点输出。报告旧联合 UNKNOWN 中新增 ABOVE/BELOW/INSIDE 等价格事实的数目，不称阶段识别覆盖、准确率、减少漏判或成功率。两个交易所相关、相邻周窗口重叠，不算独立样本。

## 事后对抗结果（非季节真值）

ABOVE 或 BELOW 的观察冻结各自 H 或 L，向后 7 及 28 个完整 UTC 日：ABOVE 时第一次日收严格<H 或 BELOW 时第一次日收严格>L 记录首次返回日期及当时价格，等于边界不触发；提前缺柱/警报为 UNKNOWN，先发生事件则保留。观察时已经在外并不意味着之后第一根在外日线是新突破。INSIDE、不触发旧候选、联合 UNKNOWN 同样记录原 28 日固定区间首次日收越界及越界后7日返回代理（未越界、缺口也分别保留）。这些事件无法证明假突破、真假春秋及收益，不能用来标定“正确季节”或从结果倒填观察。

对每个观察点若能获得之后连续 28 个完整日，记录 28 日结束收盘相对于观察前一日收盘的百分比，缺失则 UNKNOWN；如两所同为 ABOVE/BELOW，分别列自身后续状态，不将它们当独立事件。此收益仅价格描述，非交易回测、真实阶段或预测准确率；按具体状态列出全部样本，不以选择少数好的事例替代全量。

## 验收
独立实现从 4h 原始行情逐时点重算摆点、确认时间、旧固定层、过时及两所价格状态、全部后续事件及 28 日收盘变化；Bitfinex 4h 另从原始 1h 重算。测试未来数据扰动、时间确认、等值、缺失、突破后收回不恢复摆点、双方不一致、事件先后。保存定义、代码、数据和输出哈希。没有独立真人标签不能测真实漏判或验证真正春秋，须显式标明是否达到完整历史覆盖，不按本轮结果再调参并称独立验证。
