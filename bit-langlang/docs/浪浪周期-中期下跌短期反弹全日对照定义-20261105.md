# 中期下跌、短期上涨：完整季度全日回顾对照

## 目的与范围

已有 2023 和 2026 两个已见点都表现为此前 90 日价格下降、7 日上升，但后来价格路径不同。本轮在计算全日组合之前固定：复用 2022Q4、2023Q4、2024Q4、2025Q3、2025Q4、2026Q1，保留每季度全部日点及期末收盘；每个判断点都是 UTC 00:00，以截至该点最近完成的日收为基准。六个季度每个日点计一次，固定区域用原季度各所期初 28 日范围；为避免把两所同一事件当独立案例，主表仅 Bitstamp BTC/USD 现货，不声称双所验证。

这些行情及先前展示案例、部分未来结果已被项目看到，所提条件也由其启发，是事后诊断，不是未参加设计的样本、盲测或真实阶段准确率。90 日/7 日窗口、固定区间等均为研究代理，不是浪浪规则，也不是入场条件。
