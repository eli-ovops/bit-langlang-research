Bitstamp 与 Bitfinex 作为新增一组独立行情对照；原 Bitstamp–Coinbase 仍完整保留、不得事后挑选哪个组合更有利。三家不拼接。对每一组，任何一所缺失或价格被该组同时段 >10% 极值差异标记时，该组两个来源相关日保守 UNKNOWN；每组单独记录所用源质量标记，因此同一所两个组合结果可因质量屏蔽不同而不同。若 Bitfinex 不可用或缺口过多，报告范围与限制，不声称完整或成功。Bitfinex 与 Coinbase 不自动合并。组合共同方向仍只是价格事实，不是春秋真值。不可因为新来源调整原时点、规则或阈值。
