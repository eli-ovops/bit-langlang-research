# BTC 七日口径差异：两种参考时间对照

现已看到 2023-01-22 观察对应的 CoinGecko BTC 7d 显示与 Bitstamp 严格相隔168小时收益差异很大，且发现抓取时刻七日前的 UTC 零点与同小时价差可能解释一部分。以下**先固定再比较全部**先前14个已通过存档检查的周点，其他12点保持 UNKNOWN；不挑吻合的点后称此方法已验证。

对于每个快照，保持同一个 Bitstamp 当前参考价格：快照抓取前最后一根完整4小时柱的收盘。对照两种假设分母：（A）此前168小时的同一结束时刻收盘；（B）此前7个日历日前一个UTC日结束时刻，即目标日00:00的上一完整柱收盘。均须所需柱及中间每根4h有效，缺口为 UNKNOWN。提取 CoinGecko 页面 BTC 行显示的 7d 有向百分比（按其颜色箭头与显示精度，0.0 单列），用百分点分别计算两种方法与该展示数值的绝对差。该对照不试图确定 CoinGecko 的真实算法。

不同交易所、CoinGecko 现价与数据内部时间、价差、显示四舍五入均可能造成误差；（A）或（B）更接近仅是数值拟合，不是方法归属证明，也不证明旧页面数据准确。这是看过一个异常后的事后诊断，14点都已接触且缺失非随机，不能进行独立样本外、阶段或交易结论。禁止选币、入场和交易，任何平台 start/stop 前告知。
