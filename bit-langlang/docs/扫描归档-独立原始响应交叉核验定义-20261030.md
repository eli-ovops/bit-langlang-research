# 扫描归档：独立原始响应交叉核验定义

对归档中已绑定的采集前基线、公开请求正文和每次结果，使用单独实现的 CSV、时间和 Decimal 数值比较，不调用采集器的 `load_base`、`advance` 或其 K 线校验函数。每次检查服务器与请求时间、请求分页参数及顺序、K 线时间网格与 OHLC，核对首根重叠行与上一份 CSV 末行，确认当前 CSV 保留上一份全部原始字节且新增行与已收盘响应逐项一致；未收盘行不得追加。仍使用现有归档加载器恢复、校验压缩载荷，因此不是完全独立的归档系统实现。

首条缺采集前基线、某条缺公开原始响应时标 UNKNOWN；内容、时间或分页不一致为 INVALID。源文件、锚点及服务器/本机时间均未独立认证，本地格式与数值匹配不证明交易所实际来源、实时连续覆盖或成交。状态最多 `PARTIAL_INDEPENDENT_CROSSCHECK`，不能视为前瞻通过。
