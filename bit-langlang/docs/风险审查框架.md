# 风险审查框架（Go / No-Go）

> 目标：在"上大额资金"之前，把"这套模仿有没有风险问题"变成**可测量、有上限、有断路器**的工程问题。
> 结论先行：**不存在零风险的交易策略**。我们能证明的是：亏损有上限、回撤可承受、极端情况下不会死、以及**在什么条件下不应该加钱**。

---

## 1. 已知风险清单（附真实交割单证据）

| # | 风险 | 证据（来自 4808 笔 / Monto Carlo） | 严重度 |
|---|---|---|---|
| R1 | **连续亏损**（心理与资金双重打击） | 实际出现过 **22 连亏**；1097 段亏损中 ≥10 连亏 20 段、≥15 连亏 3 段 | 高 |
| R2 | **回撤深度** | ⚠️ 原“-39%/-52%”无代码可复现（独立复核 H2）；按 1.5% 权益直译复算 MDD≈-99.9%。**以实际回测产物为准，旧数字作废** | 高 |
| R3 | **尾部/时间集中** | 最高的 3 个月贡献 **76%** 利润；剔除最大 20 笔后利润缩水 **76%** | 高 |
| R4 | **市场状态依赖** | 2022 全年 +12.4 万、2023 +72.4 万、**2024 上半年 +468.8 万（85%）**；样本内是牛市，"只多"在熊市无信号 | 高 |
| R5 | **复刻偏差** | 公开话术≠真实行为：真实空单 36.5%、杠杆中位 10×/最大 100×、保证金中位 8321U 并非固定 1 万 | 中高 |
| R6 | **成本侵蚀** | 历史手续费 **75.1 万 U = 毛利的 13.5%**；山寨滑点更高 | 中高 |
| R7 | **杠杆/强平** | 5× 下强平约 -20%；止损多在 0.2%–1%，通常安全，但**跳空/插针/标记价格**可越过止损 | 中 |
| R8 | **数据可信度** | 26 个月全部为正收益（异常平滑），不能排除数据经过筛选/美化；且只有自述收益率 | 中 |
| R9 | **长期不赚钱** | 累计收益最长 **81 天**未创新高；实际月内可能有数周“只亏不赚” | 中 |
| R10 | **过拟合/拟合风险** | 参数从同一份 4808 笔数据反推，若不切样本外，回测必然"好看" | 高 |

## 2. 风险预算与资金阶梯（"多大算大额"的准入条件）

### 2.1 单笔风险上限

| 阶段 | 单笔风险 | 2000U 账户对应 | 用途 |
|---|---|---|---|
| **纸面/回测验证** | — | — | 样本外 + 压力测试 |
| **L0 实盘验证** | **0.5%** | 10U | 跑 30–50 笔，验证滑点/成交/心理 |
| **L1 小仓** | **1.0%** | 20U | 跑满 3 个月或 100 笔 |
| **L2 正常** | **1.5%** | 30U | 通过全部 Gate 后 |
| **上大额** | ≤1.5%，且随回撤动态降档 | — | 见 §2.3 |

> 为什么建议先 0.5%–1%：22 连亏 × 1.5% ≈ **-28%** 回撤；×0.5% ≈ -10%。"输得起无数次"必须用数字兑现。

### 2.2 硬性资金曲线规则

- **日亏损** ≥ 5% → 当日停手；
- **周亏损** ≥ 10% → 下周降半仓 + 复盘；
- **连续亏损 ≥ 8 笔** → 暂停，检查是否"季节判断错误"；
- **账户回撤 ≥ 25%** → **全部平仓、停止实盘**，重新做样本外验证；
- 任何一条触发后，**恢复条件**必须写下来（不是"感觉好了"）。

### 2.3 动态降档（回撤越深，风险越小）

| 当前回撤 | 单笔风险 |
|---|---|
| < 10% | 1.5% |
| 10%–20% | 1.0% |
| 20%–25% | 0.5% |
| ≥ 25% | 0（停机） |

## 3. Go / No-Go 门槛（全部通过才允许上大额）

| Gate | 检验 | 通过标准 |
|---|---|---|
| **G1 可复现** | 用 2022-05~2024-06 数据回测 | 胜率 32%–48%、盈亏比 ≥2.2、PF ≥1.5；成交笔数量级一致（±30%） |
| **G2 样本外** | 2024-07 ~ 2026-10 回测（只跑一次，不许改参） | PF ≥1.1、最大回撤 ≤25%、无爆仓；允许收益很低 |
| **G3 去尾** | 剔除最大 5/10 笔 | 样本内 PF 仍 ≥1.2；样本外仍不爆仓 |
| **G4 连亏压力** | 按 1.5% 风险模拟 | 最大回撤 ≤25%；若超过，降到 1% 或 0.5% 再达标 |
| **G5 参数稳健** | 核心参数 ±20% 网格 | 不存在"悬崖"：90% 邻域参数 PF 仍 ≥1.2 |
| **G6 成本敏感** | 手续费/滑点 ×2 | PF 仍 ≥1.2；若崩，说明利润是摩擦假设的产物 |
| **G7 单币依赖** | 去掉贡献最大的币 | 仍盈利；否则说明是单币运气 |
| **G8 极端行情** | 2024-08-05、2025 大跌等事件回放 | 单日最大亏损 ≤5% 账户；无强平 |
| **G9 容量** | 2000U / 1万U / 5万U 滑点模型 | 5万U 时 PF 下降 ≤30% |
| **G10 运营** | 断路器、告警、交易所故障预案 | 全部就位并有演练记录 |

> 任何一条不通过：**不上大额**，回到开发阶段。这份框架的意义就是让"感觉稳了"变成"数据允许了"。

## 4. 回测报告必须包含的风险指标（缺一不可）

1. 净值曲线 + 回撤曲线（按 0.5%/1%/1.5% 三档风险各一条）
2. 最大连续亏损笔数、最长水下时间、最差单月
3. R 倍数分布（直方图）+ 最大单笔亏损（R 与账户%）
4. 去尾检验（剔除 1/3/5/10/20 笔）
5. 成本敏感性（费/滑点 ×1、×2、×3）
6. 样本内 vs 样本外对照表
7. 分币/分方向/分季节的归因
8. 蒙特卡洛（bootstrap 10,000 次）的终值与回撤分位数
9. 极端日回放（最大单日亏损、插针日）
10. 与"基准"对比：买入持有 BTC、随机入场同规则

## 5. 断路器与运营手册（实盘必备）

| 场景 | 动作 |
|---|---|
| 连续 8 笔亏损 | 停止开新仓，检查季节/结构判断，写下恢复条件 |
| 单日 -5% | 当日停手，记录到交易日志 |
| 回撤 25% | 全平、停机、重做样本外 |
| 交易所异常（断线/插针/标记价格偏离） | 立即用只减仓模式平掉，暂停 |
| 资金费率极端（>0.3%/8h） | 不开新多单 |
| 重大数据（CPI/FOMC）前 30 分钟 | 不开新仓（可选，需回测验证） |
| 周末/低流动性山寨 | 降杠杆或不做 |

## 6. 仍需你确认的风险偏好

1. **能接受的最大回撤**：15% / 25% / 40%？（决定单笔风险上限与资金阶梯）
2. **能接受的最长不赚钱时间**：2 个月 / 6 个月 / 12 个月？
3. **连续亏损 8 笔就停机**，还是 15 笔？（越松，回撤越大）
4. **大额**具体指多少（2000U → 1万U → 5万U？）——决定容量/滑点测试档位。

> 这 4 个答案直接决定回测里用哪档风险跑，以及 Gate 的门槛数字。
