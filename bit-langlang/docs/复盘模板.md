# 交易复盘模板（每天 20 分钟）

## 一、逐笔记录

| # | 日期 | 标的 | 方向 | 入场 | 止损 | 出场 | 仓位 | 计划内? | 分类 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | 是/否 | 体系内/逻辑错/纪律错 | |

**分类标准**
- **体系内亏损**：有逻辑、按纪律、仍止损 → 接受，重复做
- **逻辑错误**：无逻辑、逆势、箱体内、追高 → 从开仓条件删除
- **纪律错误**：改止损、补仓、提前砍、反手、超仓 → 用机制约束

## 二、当日三问

1. 今天有没有"计划外"的单？为什么？
2. 有没有该拿住却提前下车 / 该砍却扛了？
3. 如果重来，我会不会做同样的单？

## 三、每周复盘（周日 30 分钟）

- 本周交易笔数 / 计划内比例 / 纪律错误次数
- 连亏最长几笔？停机规则触发了吗？
- 同类结构对照：赚钱的单 vs 亏钱的单，入场逻辑是否一致？
- 下周只改 **1 个**可执行动作（不要一次改五个）

## 四、月度复盘

- 行为 KPI：五问完成率 / 止损率 / 逆势补仓次数 / 盯盘时长 / 复盘完成率
- 只评估"是否按规矩"，不评估盈亏
- 若 KPI < 90%，**不增加资金、不调参数**
