# 盘口预检时钟与间隔：事后描述定义

对已获得的单次公开预检原始 `events.json` 和快照，在核验文件哈希及数量后，仅描述本机记录的相邻消息时间间隔、接口字段 `E`/`T` 的顺序，以及本机接收时间减 `E` 的数值分布。`E` 是接口事件时间、`T` 是交易时间；未校准本机与交易所时钟，该差值不是可测得的单程网络延迟，也不证明实时性或来源。分别计算空采集首尾、REST 请求区间与 WebSocket 消息接收时刻的关系，记录负值、倒序和缺失数，不自动补充。

8 秒样本不是代表性性能测试；相邻接收时间没有消息并不代表该区间盘口未变化，序号连接亦不证明前后未漏。JSON 仅存为原始记录的派生统计，保留输入和定义哈希，不添加交易或重发网络请求。
