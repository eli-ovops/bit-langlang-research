# 五分钟影子模型：资金费覆盖补充核验

`verify.shadow_5m_candidate` 新增可选 `--funding-snapshot <目录>`。快照覆盖研究区间且结算时刻与输入 CSV 的费率一致时，报告 `PARTIAL_PUBLIC_RATE_COVERAGE_UNVERIFIED`；快照没有覆盖整个区间标 `UNKNOWN_INCOMPLETE_SNAPSHOT`，未提供快照仍为 `UNKNOWN`。覆盖完整但记录或费率对不上、快照采集晚于检查时间、输入在计算中变化时拒绝输出结果。资金费时间戳超出可表示范围及非有限净 R 也会拒绝；结果先完整序列化，再写新文件，避免留下半份成功报告。

合成测试覆盖费率匹配、覆盖不足、费率不匹配、采集时间过晚及快照中途改变；并用 5 分钟开盘价 100、公开快照标记价 101 的例子确认模型仍按前者估算，不能误称真实标记价结算。既有正负费率、待止损持仓和未来数据隔离测试通过。
