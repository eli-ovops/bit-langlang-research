# BTC周期：2018与2020二季度连续复盘事前定义

在下载本轮 2018 Bitstamp 和计算逐日状态前，固定 BTC/USD 现货 [2018-04-01,2018-07-01) 和 [2020-04-01,2020-07-01) 全部UTC日点，每7日为连续段、末段截断。各所各自取 [段首前57日,季度末后28日) 完整K线，包含背景和21日越界+7日返回的所需后续。Kraken 使用本地保留并经ZIP成员CRC核对的官方XBTUSD_240.csv；Bitstamp 2020使用已留存官方4h原响应重建含量数据、逐项与现有标准4h比较，2018固定使用Bitstamp官方4h API自身分段历史回包，保存原响应、请求URL、哈希，任何缺口标UNKNOWN、不用另一所补。两个交易所均为 BTC/USD 现货；与其他季度BTC/USDT或永续分列。

说明选择基于已知历史：两个时段均曾在项目春秋/阶段研究中被查看，2020-05-13曾是支撑回退开发动机；人为选择不同市场环境存在结果暴露，不能称样本外、独立、盲测或准确率检验。研究旨在展示分阶段证据及竞争解释，禁止用未来走势倒推当时可知的判断；没有浪浪本人同期阶段判读和独立人类阶段标签，不冒称真实春夏秋冬或浪浪本人量化规则。

复用此前56日、28日与8日两半高低关系及前28日高低作为价格参考；连续观察保留每日日点和非触发日期。补充此前旧边界事实：旧区间取 [t-35d,t-7d) 的28日高低，最近7日收盘严格越界次数及最后收盘位置只使用t之前信息；等值非严格越界。观察点之后，单独固定截至t前28日高低，最长21个完整日找首次严格收盘越界，之后连续第二个同侧日收和7个完整日是否收回另列。后续21+7和段内价格是事后事实，不是阶段真值、收益或交易信号；事件重叠不能当独立概率，返回不自动是真假突破。
