# 日线突破、后续回试与再越高点：回顾结果

## 结论

已去除原有恒成立条件，换成可复算、有时间先后的研究假设。109 个每周观察中，15 个符合新设结构；其余均保留。重新收过回试前高点后仍可能很快收回，因此单靠这个事件不能确认主升、区分所有下跌反弹，也不能断言已经复刻浪浪。没有独立的阶段真值，无法计算误判或漏判率。

规则先写在[研究口径](浪浪周期-日线突破后回踩研究口径-20261105.md)，核心是 28 天固定旧高 B → 后续 7 天内日收突破 → 另一天低点到达或跌破 B → 日收重新越过回试前高 P。所有时间均为 UTC 的日线收盘确认时点。B 和 P 是研究者定义，浪浪未提供此组数值与规则。

15 个观察中，2 个在观察时已经重新收过 P；另外 13 个尚未收过，其中之后 28 天且不超过该季度结束：8 个收过 P，3 个完整观察 28 天未收过，2 个因季度结束而不足 28 天。后续收过的 8 个中，5 个在再往后七个日收里回到 P 或以下，3 个七日内未回到；这只描述相对同一价格水平的收盘，不能直接认定上涨终结或假突破。相邻每周窗口可能重叠，数字是观察次数而不是独立走势或成功概率。

## 逐段对照与反例

- **2022 Q1：**13 个观察都未满足七日内日收突破旧高的前提。这不说明该季度没有反弹；下跌中的反弹可能未超过较早高点，也可能发生在周采样窗口之外。
- **2022 Q4：**2022-10-29 观察时 B 为 20,469、P 为 21,012；11-05 UTC 日线收盘确认再次越过 P，但 11-07 收于 20,907，回到 P 下方。11-12 另一观察则在之后完整 28 天未收过其 P。反例说明一次重新越高并不能保证继续推动。
- **2023 Q4：**10-08 观察 B 为 27,486、P 为 28,053；10-17 日收确认越过 P，此后七个日收均在 P 之上。另一次 11-09 越过 35,612 后，11-15 收于 35,564。两个案例的后续不同，不能据此声称阶段判断准确。
- **2024 Q2：**05-27 的 B 为 67,654、P 为 71,958；此后完整 28 天没有日收超过 P。它是符合回试条件却未重新越高的保留案例。
- **2024 Q4：**11-05 的 B 为 70,218、P 为 73,600；11-07 日收越过 P，随后七个日收未回到该水平。但 11-26 另一观察的 P 为 99,800，12-07 越过后，12-10 收于 97,468。已经上涨并不排除随后的反复；不应仅以回落断言整个趋势结束。
- **2025 Q3：**08-19 观察的 B 为 122,312、P 为 123,715，后面完整 28 天未收过 P；需保留这一未延续案例。
- **2025 Q4：**14 个观察都没有出现该结构，其中 13 个未突破、1 个突破后没有在窗口内回试。不触发并不能证明不存在其他形态的启动。
- **2026 Q1：**01-15 观察时，重新越过 P 已经在该观察时刻完成，不能误当未来信号。03-19 观察因季度结束不足 28 天，结局留空；情绪代理也有 LOCAL_PARTIAL 质量限制。

## 证据与限制

原有背景和固定区域按既有字段保留于[全部观察明细](../data/verify/cycle-causal-pullback-20261105-01/segments.csv)；资金费只是情绪代理，并不等于真实情绪。浪浪同期阶段判断、真实情绪、是否启动及主升的标签均缺少独立证据，继续 UNKNOWN。[第 15 页原始截图](../data/ocr-2026-10-29/pages/page-15.png)提及复盘主升浪的日线结构；其账号身份与完整上下文未独立核实，不能推导为这里的具体阈值。

本次分别检查八个季度内的每根日线由六个有效 4 小时柱组成，缺失或无效日均为零；独立从原 4 小时记录复算 109 个结构及所有已触发的时序、未来越高状态，再独立核对八次越高后的七日回落。八个季度在此前研究中均已查看，设计也受既有结果影响，故这不是独立样本；Bitstamp 单所结果也不代表其他交易所完全一致。输入与输出哈希见[统计摘要](../data/verify/cycle-causal-pullback-20261105-01/summary.json)，可复算[脚本](../scripts/cycle_causal_pullback_20261105.py)。
