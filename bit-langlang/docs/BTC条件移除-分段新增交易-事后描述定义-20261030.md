# BTC 条件移除：分段新增交易事后描述定义

对已有四个 ETH 原规则和移除 BTC 风险开启条件候选的分段账本，按入场时间比较共有、仅原组、仅候选组，分别汇总仅候选组的已平仓数量、盈利笔数、净盈亏、出场原因及盈利最大几笔的集中度。记录各组输入哈希及总金额对账；分段独立空仓、从 2000 USDT 重置，合并后段与两个子段互有重叠，不能当成额外独立样本。

此比较是在最近 79 笔候选独有交易全部净亏、较早分段移除条件后总体净盈利较高等结果已知后提出，属于事后探索，不是样本外检验。两组各自动态改变仓位和持仓容量，候选独有并不严格等价于“原模型过滤掉的所有信号”；已有数量、金额和出场都不能直接解释为取消门槛的因果效应。统计盈亏为假设执行及成本下的已实现账面值，真实成本、真实成交、未来表现 UNKNOWN。不开启或更改策略。
