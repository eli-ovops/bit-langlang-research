# 历史入场匹配：同币同日时间基线

在看到历史匹配率及信号数量后定义本描述性对照，因此是事后检查，不是独立显著性检验。针对原十币跌破收回、三柱及 BTC 例外候选，逐条可比较多头历史记录，取它的同一币种和 UTC 日期，计算该日期 24 小时内有多大时间比例落在任一模型执行时刻之后 0 至 15 分钟的覆盖区间；包含前一天尾部的信号区间，重叠区间只计算一次。按每条历史记录所属币日覆盖比例相加，得到“假定在该币当日均匀随机取入场时刻”的期望重合笔数。实际记录仍按原时刻计算匹配。

该基线保留币种、日期及模型候选密度，但假定日内均匀，并不保留日内成交高峰、历史记录间聚集、K 线活动、交易方向选择或资金路径；并非 p 值、因果证据或真正随机策略回测。原始信号未模拟持仓及每日次数限制，也不等于可下单数量。需输出每个币日覆盖与总体期望，不能因高于基线断言策略具有复刻能力。
