# 公开历史资金费率交叉核验定义

目的：检查影子模型所用 ETH 历史资金费时间与费率，是否与另一次取得的 Binance USDⓈ-M 公开资金费接口响应一致；同步采集 BTC 作为同一快照格式要求。范围为已研究的 `[2024-07-01T00:00:00Z, 2026-10-25T00:00:00Z)`，仅公开数据，不访问账户、下单、启动策略或付费。数据另存新目录，不覆盖原市场文件。

接口按包含端点的毫秒时间查询，逐页升序读取；脚本使用 `endTime=end-1ms` 表达右开区间、每页最多 1000 条，具体接口语义以 [Binance 官方资金费历史接口](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data#get-funding-rate-history) 为依据。完成后校验快照文件哈希、时间范围、排序、重复与有限值，并按 ETH 结算时刻逐项比较现有 `ETHUSDT_funding.csv.gz` 费率；差异、缺失和额外事件分别列出，不自动修正或改写原数据。

公开快照是一次本地取得的未独立认证数据；即使记录完全一致，也不能证明接口从未遗漏事件、用户使用 Binance、真实账户手续费/资金费、账户结算标记价或实际成交。若来源不可达、接口拒绝或数据缺字段，记录实际错误并保持 UNKNOWN，不绕过权限或静默替代。该历史快照不是前瞻数据；影子模型仍按 5 分钟开盘价代理资金费，不把接口 `markPrice` 称为真实账户结算价。
