# 不同历史环境：固定区间与多尺度冲突的事前检查

仅研究 BTC/USD 现货大背景、小变化和关键位置，不选币、入场、交易、调整策略或执行 start/stop。沿用 [2014 事前定义](排除当前日大区间-2014一季度事前定义-20261103.md) 排除当前日的 28 日范围、56/28/8 日层、已确认摆点、各所独立及 7 日严格收回的研究口径；所有窗口为研究者假设，不是浪浪本人规则，不得由价格事件冒充真实阶段。

在读取本轮逐日结果之前，预定两段历史：[2015-04-01,2015-06-01) 每日 UTC 00:00 共 61 点；[2017-11-01,2018-01-01) 共 61 点（两段均左闭右开）。行情分别取 [2015-02-01,2015-06-15) 与 [2017-09-01,2018-01-15) BTC/USD Bitstamp 原 4h、Bitfinex 原 1h 自身聚合 4h；保证 56 日预热及事件后的七个完整日。比较两段的尺度和实际价格变化，不预设每段是真正春秋或价格一定涨跌。逐日同时保留周一，不因信号或结果筛选。

项目曾将 2015 年 4 月部分行情用作 2015 一季度研究后续及 2015 年中研究预热，也将 2017 年 11 月作为 2018 研究预热、2017 十月研究后续；这些背景和可能已有的历史知识会造成接触。定向检索未发现上述全部 122 个逐日点直接用于排除当前日区间的规则设计，但不能证明未曾间接影响设计，不称无污染样本外、完全盲测或前瞻。两段是目标不同环境的事前候选，是否完整及确实呈现不同价格走势需本轮检验，不得事后换样本。

按每所时间网格、OHLC 检查，跨所相同 4h 柱高/低价格比大于 1.1 或小于 0.9 触发预设质量警报；问题整日和依赖它的任何窗口 UNKNOWN，不跨所补价。完整网格、无警报、交易所同意均不认证成交真实性。

输出全部时点的 56/28/8 日各自关系、摆点、旧春秋观察、修复后 28 日高低和状态、双方一致或冲突，以及区间外后的 7 日严格日收回/未收回/UNKNOWN。比较周频遗漏的逐日状态，但不把它称为真实季节漏判；价格收回不自动成为真实假突破，缺独立真人参考时真实漏判率、假突破率及阶段准确率 UNKNOWN。相邻观察期重叠，不计算独立胜率或预测概率。

独立从原 4h 复算所有时点的 29 日边界和区间状态、七日收回、两所关系、大背景和摆点；Bitfinex 原 1h 独立重聚合；复跑既有边界、未来扰动、返回和分歧测试。若无法获得完整有效数据和独立真人阶段判断，则如实报告未完成，不凭选择/可计算样本声称通过。
