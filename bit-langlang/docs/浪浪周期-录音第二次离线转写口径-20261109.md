# 录音阶段片段的第二次离线转写口径

使用已保存的第三方重剪录音，固定源时间 14:50–16:45，覆盖市场不同阶段及样本参与的机器转写线索。原始说话人身份、原直播时间和剪辑连续性均未认证；本次不会把机器输出称为已听校原话。

沿用本机现有离线 Whisper tiny 模型，与先前本机 whisper.cpp base 中文转写比较，记录实际软件、模型、哈希、输入时间、机器输出及两者一致/分歧；不同模型同家族，输出一致不是独立人证或人工听校。标明不同转写可能各自误识别，图示指代、具体币名和数字不能猜补。仅抽样此115秒，不声称复核整段66分钟；不得把模型生成的策略、阈值或字幕当成浪浪真实规则。

执行不上传音频、不使用云识别；不选币、入场、交易。研究仍需未参与规则设计的近五年完整行情与独立评审，任何平台 start/stop 前告知。
