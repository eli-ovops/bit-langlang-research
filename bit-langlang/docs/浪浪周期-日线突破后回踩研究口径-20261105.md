# 日线突破后回踩：研究口径（2026-11-05）

这是对浪浪周期、空间和情绪思路的研究假设，并非其原话或真实交易规则。2022 Q1、Q4，2023 Q4，2024 Q2、Q4，2025 Q3、Q4，2026 Q1 是本项目此前已研究过的完整季度；本次定义和区间都不构成独立盲样本。每周 UTC 零点保留全部观察，不能只报告触发案例。

对每个观察时刻 t，以此前第 35 天至第 8 天的 28 根完整日线最高价为固定水平 B；此后 7 根完整日线依次观察：先找首次日收盘严格高于 B 的突破日，之后另一个日线低点不高于 B 才记为回试或跌穿。突破和回试均在各自日线收盘后才可确认；最后一天才突破时尚无后续日线，不能判成没有回试。日线开盘在 B 下方要单独标注，低点跌到 B 下方不能证明在 B 有成交或守住支撑。

回试前高点 P 是突破日到回试前一天各完整日线最高价的最大值；不含回试日。回试日或以后某根已完成日线收盘严格高于 P，才称重新越过近期高点，确认时点为该日线收盘。观察时已发生的单列，不与之后发生混算；否则在本季度内向后最多跟踪 28 个完整日线，找首次重新越过。随后七根完整日线内收盘再次不高于 P 则记为回落；观察不足记未知。跟踪不得越过季度末，不得用将来数据构造 B 或 P。

原筛选把 B 定成包含观察日前一日的近期高点，又用最新收盘不高于 B 作为回踩条件，此条件恒成立，不能证明回踩。新口径将固定基准提前，并明确突破、次日以后回试、收盘确认的先后顺序。它会漏掉未碰 B 的回踩、仅盘中突破、同日突破回踩和七天窗口之外的结构，未触发不能等同于市场没有回踩。

日线由 Bitstamp BTC/USD 六根完整且有效的 4 小时线合成；缺失或无效则未知。保留已有大背景、固定区域和历史资金费字段；资金费只是情绪代理，真实情绪和行情阶段没有可核验标签时均为 UNKNOWN。季度回溯可能重叠，同一结构可能被多周重复观察，不能把观察次数当独立行情数，也不能由此声称识别准确率、交易收益或复刻成功。
