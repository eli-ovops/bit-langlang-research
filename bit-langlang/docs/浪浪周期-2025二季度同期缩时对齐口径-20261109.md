# 2025Q2 全部周报的近时点对齐口径

沿用[一月方法](浪浪周期-缩短同期资料时间差核查口径-20261109.md)，本轮覆盖先前已接触的 2025Q2 全部 13 个 UTC 周观察及其各自原定文章，不按涨跌、正文或是否有回踩触发选择。对每篇使用已保存 CDX 结果，选文章发表日至原周点前最早的 HTTP 200 抓取，抓取后第一个 UTC 00:00 作为审阅时点，刚好零点则使用当时；仅当抓取时间早于新时点且新时点早于原周点时可作这次近时点对齐。一个在该原地址/窗口未见索引的来源原样 UNKNOWN，不换来源或因结果删行。

只用 BTC/USD Bitstamp 自己的 4h 重建观察前 56 个完整日，另取最近 14 日视角；价格窗缺失、零量或 OHLC 无效即 UNKNOWN。对已有存档读取原文件，不重发请求；只有已知最早快照尚未保留时才串行、正常 TLS 抓取一次，核 Memento 等于所选抓取。若重定向、抓取失败、非正文或任何时间越界保留 UNKNOWN，不换身份或对方明确拒绝后绕过。保留所有 13 点、原始来源、选择与后续文件哈希；对动态数据、图片和作者自己的数据截止时间不作确认。

这不是先于历史发生的设计，2025 行情和文章已接触，且研究者已经见过前后走势；对齐仅解决文字版本确认时点与日线观察时点相隔过长的部分问题。每行阶段、真实情绪、浪浪同期判断均 UNKNOWN，不因后面走势倒填。作者的背景、位置及资金线索与价格事实分开；标准采用原 v2，绝不把第三方定义写成浪浪真实规则。不能以此计算阶段准确率、漏判率或投资表现。不选币、入场、交易；任何平台 start/stop 前先告知。
