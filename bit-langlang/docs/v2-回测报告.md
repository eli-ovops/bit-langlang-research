# bit浪浪 风格策略 v2 回测报告（预判式承接 + 假突破反转）

> 代码：`backtest/v2/`（可复现，见 §11）；结果：`data/backtest_v2/`；
> 样本内 IS = 2022-05-24 ~ 2024-06-20；样本外 OOS = 2024-07-01 ~ 2026-10-25（**只跑一次**）。
> 所有时间为 UTC；10 个币：BTC/ETH/SOL/DOGE/PEOPLE/TRB/WLD/APT/ORDI/1000PEPE；初始资金 2000 USDT。

## 0. 结论（先行）

| 问题 | 答案 |
|---|---|
| **v2 是否优于 v1？** | **没有。** 每笔期望 IS -0.280R vs v1 -0.203R；OOS -0.420R vs v1 -0.286R；PF 0.71 vs 0.75（IS）、0.59 vs 0.66（OOS）。v2 的盈亏比更高（2.20 vs 1.62），但胜率更低（24.4% vs 31.6%），净结果更差。 |
| **是否过 G1？** | **不过。** 胜率 24.4%（要求 32–48%）、PF 0.71（要求 ≥1.5）；只有"成交笔数与 v1 同量级"这一项过（0.90×）。 |
| **是否过 G2？** | **不过。** OOS PF 0.588（要求 ≥1.1）；1.5% 风险下账户在 OOS 内被复利磨损到 ≈0（实质爆仓），MDD -100%。 |
| **在什么行情失效？** | 全线失效：10/10 币两个样本段全部为负；OOS 19 个月里只有 1 个月为正；**BTC 20 日趋势转弱/震荡、BTC 波动率低的阶段最差**（PF 0.48–0.56），2025 年最差（期望 -0.502R）。 |
| **根因（诊断）** | 机械化的"上涨赛季里买支撑"在 **T1@3R : 止损@1R** 这个赛道上只有 24–25% 胜率 ≈ 公平赔率（理论 25%），**扣成本前的毛期望已经为负：IS -0.070R、OOS -0.186R**；再加 0.21–0.23R 成本（手续费+滑点+资金费），必负。v2 的规则改的是"怎么进/怎么出"，没有解决"没有可测量的入场优势"。 |

> 一句话：**v2 修掉了 v1 的部分结构问题（追涨、止盈太近、8h 时间止损），但没修掉更根本的东西——
> 该入场在这个市场里没有统计优势，而成本是刚性的。** 这也与 `docs/交割单洞察.md §2`（他的入场
> 1–4h 无正 edge）一致：他的收益来自选币/情绪/执行，机械规则抽不出来。

## 1. 数据与口径

| 项 | 取值 |
|---|---|
| 行情 | `data/market/{sym}_{5m,1d}.csv.gz`，2022-01-01 ~ 2026-10-29；10 币 |
| 资金费 | `{sym}_funding.csv.gz`，逐次累计；单次 \|rate\|>0.3% 截断（TRB 有 -3% 异常记录） |
| 成交假设 | 信号 5m 收盘后**下一根开盘**市价成交；同一根 bar **先判止损再判 T1**（保守） |
| 成本 | taker 0.05%/边；滑点 BTC/ETH 0.03%、山寨 0.08%；资金费按持仓累计（T1 后名义减半） |
| 组合 | 最多 3 笔并发（满仓则跳过，IS 跳过 1025/2850、OOS 跳过 1748/4031）；杠杆上限 BTC/ETH 10×、山寨 5× |
| 风险分档 | 单笔 = 权益的 **1.5%**（C 档）与 **3.3%**（1/3 仓位×10% 本人口径）；复利 |
| 样本切分 | IS 只允许用来做"结构选择"（1 个二值项）与修 bug；OOS 一次性执行，之后不再改任何参数 |

**R 口径**：R = 入场价 − 初始止损价。`net_R = gross_R − (手续费+滑点+资金费)/stop_pct`。
两档风险的**逐笔 R 统计完全相同**（同一批交易），差异只体现在权益曲线（见 §4）。

**时间边界（重要）**：IS 首笔成交 2023-01-15、末笔平仓 2024-06-14——2022-05~2022-12 因 BTC 季节
关闭而 0 交易，所以 IS 的"有效样本"其实是 2023-01~2024-06（17 个月）。OOS 首笔 2024-07-18，
入场截止 2026-10-25，最后一笔平仓 2026-10-27（持仓跨过截止日 2 天）。

**防未来函数自检**（`python3 -m backtest.v2.sanity --split {is,oos}`，全部 PASS）：

| 检查 | 结果 |
|---|---|
| S1 日线特征只用 D-1 及之前（独立重算 75,720 个值） | PASS |
| S2 BTC 季节布尔与 D-1 重算一致 | PASS |
| S3 成交在信号后一根 5m 开盘（3,000+ 笔逐笔） | PASS |
| S4 stop<entry<t1、stop_pct∈[0.3%,2%]、exit≥entry | PASS |
| S5 R 口径自洽（gross/exit/net） | PASS |
| S6 成本 ≥ 双边费+滑点/stop_pct（资金费单列） | PASS |
| S7 单币无重叠持仓 / S8 持仓≤14 天 / S9 字段完整 | PASS |

## 2. v2 规则实现

| 层 | 规则 | 说明 |
|---|---|---|
| 方向 | 只做多 | 任务约束 |
| 季节 | BTC 日线：`close>EMA50 且 EMA50 五日上行 且 close>EMA200`，**shift(1)** | Spring/Summer 代理（规格 §2.1） |
| 标的趋势 | 标的自身 `close>EMA50`（shift(1)） | **IS 二值结构选择**：ON 优于 OFF（exp -0.280 vs -0.439R），选 ON |
| 支撑 | 前 10 日低 / 前 20 日低 / 前 24h 低 | "支撑/箱体下沿/前低"三种取法 |
| 入场 | 价格**仍在支撑上方 0.4%~1.85%**；5m 出现 A 假突破收回 或 B 承接止跌（阳线+收盘高于前收+收在当根上半区） | 预判式承接，不追突破 |
| 不追突破 | 信号根不创前 20 根 5m 新高；前 6 根累计涨幅 <2% | "尽量不做突破" |
| 止损 | 5m 摆动低点（前 5 根最低）与支撑 L 取更深者，再减 `max(0.15%, 0.3×ATR14)`；距离 ∈ [0.3%, **2%**] | 中位 1.30% |
| 空间 | 到最近日线阻力（前 20/60/120 日最高中价格上方最近者）≥ **5%** | 利润来自 5%+ 振幅 |
| 止盈 | **T1 = 3R 减半**；剩余止损推保本（含成本），再用 5m 摆动低点跟踪；最长 14 天；**无 8h 时间止损** | 中位持仓仅 3.1h（见 §4） |

### 2.1 关于"止损放在 5m 摆动低点下方"的两种读法（IS 一次性对照，非网格）

| 读法 | 含义 | 止损中位 | 单笔成本 | IS 期望 | PF |
|---|---|---|---|---|---|
| **above_support（交付）** | 价格尚未到支撑、仍在支撑上方 0.4–1.85% 时预判承接 | 1.30% | 0.213R | **-0.279R**（2850 笔） | 0.71 |
| at_support（字面） | 价格已跌到支撑处/轻微跌穿后收回 | 0.90% | 0.296R | -0.370R（3843 笔） | 0.64 |

选择 `above_support` 的唯一理由：只有它能让任务书的三条约束同时成立——
止损能落进 **1–2%**（"硬上限 2%"才不是空条款）、3R 目标 ≈ 3.9–4.5% 才与 **"到阻力≥5%"** 自洽、
**"持有 24–72h"** 才有物理可能。两种读法的完整结果都在 `data/backtest_v2/diagnostics.json`。

## 7. 为什么失败（IS 诊断，`tables/diagnostics_is.md`）

### 7.1 入场其实有"正漂移"，但抓不住

同一批 IS 入场（2850 笔）的前瞻收益：

| 持有 | 均值 | 中位 | 为正占比 |
|---|---|---|---|
| 24h | **+0.97%** | +0.70% | 57.6% |
| 72h | **+1.90%** | +0.50% | 53.0% |
| 7d | **+4.06%** | +0.66% | 52.4% |

但同一批入场的 **MFE24 中位 2.64R、MAE24 中位 2.67R**（几乎对称）——在 1.3% 的止损尺度上，
24 小时内的噪声是 ±2.6R。**漂移（0.97% ≈ 0.75R）比噪声（2.67R）小一个量级**，
所以"到 3R 之前先碰到 -1R"的概率 ≈ 25%，刚好等于公平赔率，扣除成本后为负。

### 7.2 3R : 1R 赛道的算术（组合成交集，1.5% 档）

| | IS | OOS |
|---|---|---|
| 成交笔数 | 1825 | 2283 |
| 胜率 | 24.4% | 22.2% |
| **扣成本前**平均赢 / 平均亏 / 盈亏比 | 3.00R / -1.06R / **2.83** | 2.91R / -1.07R / 2.73 |
| **扣成本前 PF** | **0.912** | **0.776** |
| **扣成本前期望** | **-0.070R** | **-0.186R** |
| 打平所需胜率（毛盈亏比口径） | **26.1%** | 26.8% |
| 单笔成本 | 0.21R | 0.23R |
| 净 PF / 净期望 | 0.709 / -0.280R | 0.588 / -0.420R |

- 关键数字：**即使把手续费、滑点、资金费全部设为 0，这套规则在两个样本段也都是亏的**
  （-0.07R / -0.19R 每笔）——问题不只是成本，而是胜率（24.4%/22.2%）低于毛盈亏比要求的
  打平线（26.1%/26.8%）；
- 成本再把期望各压低 0.21–0.23R，于是 PF 从 0.91/0.78 掉到 0.71/0.59。

### 7.3 换出场几何也救不回来（同一批 IS 入场，诊断，非交付）

| 出场方案（诊断口径，未计资金费/简化跟踪 buffer，只作相对比较） | 胜率 | T1率 | 持仓中位 | 期望 R | PF |
|---|---|---|---|---|---|
| **交付**：5m 结构止损 + T1@3R + 5m 跟踪 | 24.9% | 24.9% | 1.6h | **-0.329** | 0.67 |
| 持有 24h + 1R 止损 | 16.1% | — | 24h | -0.245 | 0.77 |
| 持有 72h + 1R 止损 | 8.9% | — | 72h | -0.194 | 0.84 |
| 持有 72h + 2% 止损 | 20.2% | — | 72h | **-0.059** | 0.93 |
| 2% 止损 + T1@3R + 5m 跟踪 | 25.0% | 25.0% | 8.7h | -0.118 | 0.86 |
| 5m 结构止损 + T1@日线阻力 + 跟踪 | 6.6% | 6.2% | 1.8h | -0.253 | 0.80 |
| 2% 止损 + T1@日线阻力 + 1h 跟踪 | 14.3% | 12.9% | 10.6h | -0.095 | 0.90 |

**所有出场几何的 PF 都 <1**；最好的（持有 72h + 2% 止损）也只是把亏损压到 -0.06R/笔，
而且已经违反"5m 摆动低点止损 + T1@3R"的任务约束。结论：**问题不在出场，在入场没有可测优势**。

### 7.4 成本口径的硬约束

- 止损中位 1.30% → 往返成本 0.16%（主流）/0.26%（山寨）＝ **0.12–0.20R**，加资金费约 0.01R；
- 若按"止损 0.6–0.9%"的 at_support 读法，成本升到 **0.30R/笔**（这正是 v1 被诊断出的问题）；
- 任务给的成本假设（0.05%/边 + 0.03–0.08% 滑点）已经比他的真实成交更乐观——他的真实手续费
  占毛利 13.5%，本回测 29–36%，说明机械版的"毛利"太小，费率相对更重。

| 币种 | **10/10 币全负**；BTC/ETH 最好（-0.18/-0.01R），APT/ORDI/1000PEPE 最差（≤-0.34R） |
| 年份 | IS 2023 -0.242R / 2024H1 -0.327R；OOS 2024H2 -0.312R、**2025 -0.502R（最差）**、2026 -0.350R |
| BTC 20 日趋势 | 越弱越差：IS 弱桶 -0.300R / 强桶 -0.204R；OOS 弱桶 **-0.454R** / 强桶 -0.300R |
| BTC 波动率 | 低波动最差：OOS 低波动桶 **PF 0.48**、高波动桶 0.80（仍负）——**高波动/主升时相对好，但从未转正** |
| 形态 | 假突破收回（n=189/207）比承接止跌更抗跌：PF 0.84/0.80 vs 0.70/0.59，但只占 7% 信号 |
| 月份 | IS 4/17 个月为正；OOS **1/19** 个月为正 |

**典型失效场景**：①BTC 日线"季节"仍开着但 20 日趋势转平/转弱（下跌初期，支撑被一根根打穿）；
②低波动阴跌（止损 1.3% 被反复扫、没有 3R 的行情）；③山寨集体退潮期（2025）；
④高波动急跌里"假突破收回"之后继续跌（止损被跳空/插针穿透，本回测按 K 线 low 保守成交）。
反过来，**这套规则唯一相对好的环境是"BTC 主升 + 高波动"**，但即便如此期望仍为负。

## 9. 与"复刻目标"的差距（诚实结论）

1. **机械规则没有复现他的收益**，也没有复现"胜率 40% / 盈亏比 2.5–3 / PF 2.29"中的任何一项（胜率 24%）。
2. 他的 4808 笔记录里有 **36.5% 做空、中位持仓 7 分钟、2024 年 2/5/6 三个月贡献 85% 利润**；
   本 v2 只做多、持仓数小时、利润无集中来源——**规则蒸馏掉了他的核心能力（选币/情绪/执行）**。
3. `docs/交割单洞察.md §2` 的结论（入场 1–4h 无 edge、24h 才有 +0.70%）在本回测里被**独立复现**：
   入场后 24h 平均 +0.97%，但按 1R 止损持有，抓不住。
4. 因此 **不应把本回测当作"可上实盘"的证据**；它证明的是"这一版机械化不可行"。

## 10. 下一步（明确标注为"未验证假设"，且不能用本 OOS 调参）

> 本报告的所有数字来自一次冻结的 OOS。**任何基于本 OOS 的改参都是自欺**；
> 下一轮必须在**新的、未使用过的时间窗口**（例如 2026-11 之后的前向纸面跟踪）验证。

按优先级排列的假设：

1. **重构"空间"与"止损"的尺度**：如果利润真的只来自 5%+ 振幅，T1 不该是 3R（在 1.3% 止损下 = 3.9%），
   而应是"到日线阻力/箱体投影"（≥5%），并把止损放宽到与 24–72h 持有期匹配的 1.5–2%。
   本报告的诊断（§7.3）显示这会改善但**仍不足以转正**，所以还需要第 2 条。
2. **入场优势必须单独被证明**：先做"选择器"（哪个币、哪种结构、哪个季节阶段），
   而不是继续改进出场几何。可检验的代理：相对强度（币/BTC）、箱体时长、距上方空间、
   回调深度与回撤速度；要求**同一套选择器在 24h/72h 前瞻收益上有显著正 edge** 再谈交易。
3. **接受"大部分时间空仓"**：真实交易时间 <5%；本回测有 107 笔/月，频率明显过高（噪声+成本）。
4. **做空/对冲**：他 36.5% 空单贡献 24% 收益；只多版本先天少一条腿。
5. **执行层**：滑点/资金费/插针的敏感性（G6/G8）在 PF<1 时不值得测；等毛期望转正后再做。
