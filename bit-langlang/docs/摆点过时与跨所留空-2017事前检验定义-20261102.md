# 摆点过时与跨所不一致：2017 事前检验

## 边界与样本
只研究 BTC 春天启动/下跌反弹、秋天衰退/正常回调，不选币、不做入场或交易、不执行平台策略 start/stop。价格、情绪、真实季节和 Bit浪浪本人规则互不等价；所有时间窗口及条件为研究假设。没有独立真人参考标签，不计算真实漏判率或识别准确率。

2016 盘面提示确认摆点可能早已被价格穿过、两所摆点可能相反；本轮在取数前把以下守则冻结。仅有“早已处于摆点外”留空属于此前已检验后得出的保护想法，不是未经任何历史观察的全新假设。2017-03-06 至 2017-08-28 每周 UTC 00:00 共 26 点，采集 2017-01-01 至 10-01 Bitstamp BTC/USD 现货 4h 和 Coinbase BTC-USD 现货 1h 聚合 4h；保留原始响应和 SHA-256，核验 OHLC、缺失和网格。定向检索 docs/verify 未发现该 2017-01–09 时段用于本摆点保护规则设计；此前 2018 研究的预热包含 2017-11–12，且公开历史可能为研究者或模型熟悉；不能称严格盲测、全然未见或前瞻。若缺柱或无法取得一个来源，该来源与跨所综合为 UNKNOWN，另一所独立事实仍可保留。不同交易所不得拼接补价。跨所相同 4h 极值偏离 >10% 为质量警报，问题柱所属 UTC 日在两所均标 UNKNOWN，相关历史/未来窗口各自留空；不能以此推断哪家错误。时间网格完整不证明交易真实。

## 单所结构与过时规则

旧 56/28/8 固定窗口及 2016 确认摆点定义不变：56 个完整日的日线 j 高（低）严格高（低）于左右各 2 个日线才确认，j+3 UTC 开始知晓；双向同一日、等值和缺口处理沿原定义。最近两个已确认高点与低点同向抬高为 SWING_UP、同向降低为 SWING_DOWN，否则 MIXED；历史不足为 UNKNOWN。保留各摆点发生/确认时间与价位。

对最近已确认高摆点 H：仅使用其确认时刻之后截至决策 t 的已完成日收盘；若任一日收盘严格高于 H，则该高摆点标 STALE_BROKEN_UP，包含先穿越再收回的历史，等于不破。对最近已确认低摆点 L，若任一后续日收盘严格低于 L，则 STALE_BROKEN_DOWN。若检查窗口缺日、H<=L、确认时刻非法或缺价则 UNKNOWN；若任一侧 STALE，不将该摆点方向当作当前有效状态。若两个摆点尚未被穿越且数据完整，原摆点方向可列 `ACTIVE_UP/DOWN/MIXED`，是未失效研究状态，不是季节真值；对价格后来收回原区域不自动重置摆点。摆点年龄本轮只记实际确认后天数，不设未经检验的天数上限；若两个摆点极其久远但未被穿越，仍可能误导，须揭示局限。

## 跨所、固定窗口和复盘

每所分别计算各自摆点，不做数值平均或互补。仅在两所均为 ACTIVE_UP 或均为 ACTIVE_DOWN 且各所的 56 日背景分别满足原来的 DOWN/INSIDE 对 UP、UP 对 DOWN 时，列 `JOINT_POSSIBLE_UP` 或 `JOINT_POSSIBLE_DOWN`；若任一缺数据、价格存疑、摆点过时，或两所方向不同/结构混合，综合输出 UNKNOWN，并保留两个各自事实。两所均明确 ACTIVE 但方向之外的背景不满足，记 `NO_JOINT_CANDIDATE`，不是非春非秋真值。合意一致减少分歧但可能漏掉及时变化；USD 交易所相互关联，一致不保证正确。

逐点保留原始旧候选、单所摆点和保护后状态、跨所状态、固定窗口结果；比较旧固定 spring_watch/autumn_watch 与可能转强/转弱，所有 26 点均报告。对每所已确认 H/L，若决策时 H>prev_close>L，才在未来 28 个完整 UTC 日按**首次严格收盘**越过 H/L 记录观察后新越界，并检查其后7个完整日是否日收盘严格回到界内一侧；若决策时已在界外，记 ALREADY_OUTSIDE_ASOF；恰在边界算有效起点并严格越界才触发。当前处于内部但历史上突破后收回仍单独记录原样事实，不把保护后 STALE 当成有效新候选。对于缺失或质量标记日，在事件前遇到未知则后续结果 UNKNOWN，已确定事件在此后缺口前的事实不抹去。同步分别评估旧固定 28 日区间 H/L，不跨所拼接。返回只是假突破价格代理，不是真实标签、概率或收益；周点重叠不能视为独立事件。

标注过时原因时记录真实发生时刻、摆点确认时间、检查截止；先冻结规则再取目标行情，结果不得倒填决策时间。对潜在漏看，分别列原有候选被保护过滤、两所分歧和只有单所候选，并用当时结构及后续事实对照；没有独立真人标签时只称待核查，不称真实漏判或误判。

## 验证
对全部来源/时间点和所有保护、固定窗口、历史过时日、事件与7日返回进行独立原始数据重算；保留数据、源码、定义 SHA-256。至少测试确认延迟、等值、突破后收回仍过时、跨所不一致、缺失、数据受疑、未来扰动及起点在边界外。完整性、跨所同向和一致性都不能证明实际成交真实、季节正确或可盈利。
