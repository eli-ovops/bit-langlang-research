# 回到浪浪的思路：周期、空间、情绪研究路线

## 研究目的与边界

目标是逐步检验研究者能否按现存资料表达的“周期、空间、情绪”形成可复查的市场判断，再研究其与浪浪交易方法的距离；当前先不选币、不设计入场、止损止盈或交易，不执行任何平台 start/stop。原截图中的身份及上下文完整性未独立认证，截图之外的观察流程、时间窗口和候选均是研究假设，不是浪浪已证实的量化规则。

过去大量历史已被项目研究，不能把重复观看说成独立验证。目标应分为：原话能证明什么；研究者怎样据此观察；此前已知历史能否构成反例；新冻结的资料与独立参考能否复核。任何层面证据不足保持 UNKNOWN。

## 一步一步研究

1. **原话台账。** 对周期、空间、情绪各取截图中的可核实回答，区分提问者和答复者；每一条列“明确说了什么 / 没说什么 / 来源页码”。例如“震荡尾声、主升启动之前”来自第 7 页提问者，浪浪的答复谈犹豫、假突破及回踩，不能从中推出特定的突破天数或阶段阈值。[术语归属](浪浪周期-阶段术语归属及突破条件审查-20261105.md)
2. **时间顺序复盘。** 对完整连续行情按日期逐段记录：大级别环境、当时已形成的位置、小级别变化、能够核实的情绪资料、支持及相反解释、看不清什么。先记录当时看得见的内容和会改变判断的条件，再单独记录后来事实；不以之后涨跌倒填当时标签。固定旧区域是记录工具，近期位置单列，不把两者混成一条线。后续不强迫每段都归入震荡末期、启动或主升。
3. **跨环境比较。** 复用已有连续季度作开发和反例研究，例如 2022Q4、2023Q4、2024Q4、2025Q4、2026Q1；完整保留没有上越、没有信号、数据缺口及相反走势。不把相邻日或两个交易所当成多个独立周期；已研究历史不称纯样本外。对明显过时的固定区域，保留原线，同时单列后续当时已形成的局部区间，并记录各自形成时间。
4. **明确验证问题。** 验证观察能否复述、证据是否在时点前可得、不同判读者是否给出相同依据，以及何种盘面会使解释失效。外部机构的同期材料可提供独立观点，但不是浪浪本人或市场真值；没有对应证据时不强行给情绪标签。后续价格只用于检验“价格是否发生所描述的事件”，不能把未来涨跌当作启动的定义。
5. **留出复核。** 候选观察方法与记录格式固定后，再使用未直接用于该方法设计的完整资料及独立参考，核查时间、来源、完整性、非触发和意见分歧；未知的历史暴露明确写 UNKNOWN，不能用已见数据冒充纯留出。若暂时无法满足，在现有数据上只报告探索，不以数量代替验证。逐步达到这些条件后，才讨论能否复刻阶段判断；更不能由此直接宣称盈利模式成功。

## 小示例：同一位置如何随时间跟踪

这不是新验证：2024Q4 已被项目看过，下面只示范记录顺序。Bitstamp BTC/USD 的 **2024-11-05 00:00 UTC**：此前 28 日参考范围 58,867–73,600 美元，最近完整日收 67,818；旧研究的长中尺度向上、短尺度向下。此前 21 次 Binance BTCUSDT 永续资金费均正，但这不是市场真实心理或资金流。可以同时保留“较大环境中回调”和“继续转弱”两种解释，不能先写启动。[原逐段资料](浪浪周期空间情绪-2024四季度逐段复盘-20261105.md)

单独记载后来事实：**11-07 00:00** 已完成日收 75,637，越过当时冻结的 73,600；**11-12 00:00** 已完成日收 88,770。两次事实只在各自收盘后可知。价格越过与继续上行支持对该路径的描述，但不证明 11-05 当时已经能够确认启动，也不是浪浪本人同期标签。[固定区域逐日演示](浪浪周期-固定区域持续跟踪方法演练-20261105.md)

对照中，2022 年四季度也出现过围绕参考区域的上越及收回，后续路径不同；不同区间和环境不能当严格配对试验，不能据此计算胜率。[2022/2023 对照](浪浪周期空间情绪-2022与2023四季度逐段研究-20261105.md)

## 下一次实际研究的验收物

按时间顺序交付一段完整区间中所有观察时点的当时记录、竞争解释、数据缺口和独立的事后事实；每个重要判断都能回到原话或明确的研究假设及行情来源。至少包含相反路径和无法判定的时点，说明是否存在历史暴露。验收问题是观察是否一致、哪些判断仍不成立以及能否被独立材料复核，而不是追求全部都能贴阶段标签或找到能赚钱的参数。
