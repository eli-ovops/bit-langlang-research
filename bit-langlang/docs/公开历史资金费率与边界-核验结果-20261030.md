# 公开历史资金费率与边界：核验结果

以 `[2024-07-01, 2026-10-25)` UTC 为范围，一次性读取 Binance USDⓈ-M 公开资金费历史，保存为带本地采集时间的 v2 快照。BTC 和 ETH 各返回 **2538 条**；与项目原资金费 CSV 按毫秒时间和 Decimal 费率逐项比较，两币均无缺失、额外记录或费率差异，接口返回的 `rateType` 均为 `Regular`。接口的时间范围、分页和响应字段见 [Binance 官方文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data#get-funding-rate-history)。

此前项目已经对同一来源做过历史费率比较；此次新增的是与影子工具兼容、记录完整查询范围及本地采集完成时间的快照，并不是新的独立交易所来源。快照为脚本解析后合并并重新序列化的 JSON，**不是逐页原始 HTTP 字节及请求回执**；来源、时钟与接口历史完整性仍未独立认证。采集目录中的 `20241030` 是命名笔误，实际采集时间以清单的 2026-10-30 为准；目录按原样保留，未移动或覆盖。

将该快照提供给双延迟影子模型后，资金费率区间形式状态为 `PARTIAL_PUBLIC_RATE_COVERAGE_UNVERIFIED`；125 笔历史交易和期末模拟权益 **2647.54 USDT** 与没有该快照的版本一致。模型仍以结算所在 5 分钟柱开盘价作为资金费金额代理，不把公开 `markPrice` 或费率匹配当作用户账户的真实结算。

对这份固定 125 笔账本作事后算术对照：按 5 分钟开盘价代理的有符号资金费净支付约 **76.938006 USDT**；按公开历史 `markPrice` 估算约 **76.936221 USDT**，差约 **-0.001785 USDT**。前者与账本逐笔资金费复算最大误差小于 `4.4e-15` USDT。比较仅固定既有数量与持仓时间，未重新计算资金、仓位或回撤，公开标记价不证明用户账户结算价。

另有 **12 笔**模拟持仓的入场或退出落在某次资金费结算前后 60 秒内；其中部分涉及同一结算时刻的同时仓位。若仅为敏感性演示，假定这些边界事件各自可计入或不计入，并固定其他仓位与费用，则上述公开标记价费用算术合计约落在 **76.73555 至 77.58191 USDT**。这不是交易所规则、真实费用区间或最大损失范围；实际结算先后 UNKNOWN，也没有重新模拟账户路径。12 笔计数与上下界已另用独立脚本核对。
