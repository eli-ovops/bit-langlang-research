# 上升背景、小级别下行：支撑事实事前检验

目标研究大背景向上、小级别向下时，价格相对已知支撑是否有助于区分正常回调和衰退。只研究 BTC/USD 现货；不选币、入场、交易或操作平台策略 start/stop。56/28/8 日、摆点及时间窗口均为研究假设，非浪浪本人明确规则。事实字段不直接赋予春秋标签，阶段及真实情绪 UNKNOWN。

在下载目标历史和查看逐日结果前固定 2019-10-01 至 11-30 UTC 00:00 每日共 61 点；取 [2019-08-01,2020-01-01) 的 Bitstamp 原 4h、Bitfinex 原 1h 自身聚合 4h，保留所需 56 日预热及最多 28 日后续。两所独立不混拼；原始网格、OHLC、缺柱及相同 4h 高/低比大于 1.1 或小于 0.9 的警报，按此前方法标相关整日和依赖窗口 UNKNOWN，后续缺口亦不能当作未发生。时间网格完整与无警报不是成交真伪认证。

已有研究在 2019 年 1–9 月、2019 年 11 月之后预热及 2020 年行情取过数据；本段与前述研究在输入和部分时段上重叠。定向检索未发现本次 61 个逐日点直接用于本次支撑状态的设计，但历史知识和间接接触无法排除，不能称严格盲测、无污染或前瞻；只选一段不保证覆盖所有环境。无论取数质量或结果如何都不事后更换目标期间。

## 事前固定状态

全部日期均保留旧 56/28/8 日背景、排除当前日的 28 日区间状态、旧春秋观察、每所确认摆点；重点组为 56 日 UP、28 日 UP、8 日 DOWN。所有其他日期也输出，不仅看候选。以上是窗口比较，不是已证实市场四季。

以各所 56 日日线左右各两日确认的最近摆低 L 作为候选支撑，仅当摆点算法取得足够摆高/摆低、L 及其确认时间可得，且 L 在当前完成日开始前已经确认（known <= t-1 日 00:00 UTC）才能作判断；否则 UNKNOWN/WAIT_CONFIRM。检查确认时刻至当前日前已完成的每个日收盘：若曾严格低于 L，历史状态 PRIOR_BROKEN，否则 PRIOR_UNBROKEN；任何所需日缺失 UNKNOWN。当前已完成日收盘 C 严格低于 L 为 BELOW、等于 L 为 EQUAL、上方为 ABOVE。保留“过去曾破”的状态，不能因当前回到上方把支撑重新当成完好。摆点参考在 t 发生变化时不能将不同 L 的状态误当成同一事件；L 未被市场验证为真实关键位，单个摆低也不证明有效支撑或衰退。两所独立标字段和可知时间；任一 UNKNOWN 不合并为确定结果，其他不同保留 DISAGREE。阶段依然 UNKNOWN。

对每所全部时点记录完整后续 7/28 日收盘变动，参考当时最后已完成收盘；如果该期缺数据或质量警报，后续值 UNKNOWN。对已经 BELOW 的点，将当时 L 冻结，自 t 起检查 7 日内是否首次严格日收上方（收回）；对 PRIOR_UNBROKEN 且当前 ABOVE/EQUAL 的点，在 t 后 7 日是否首次严格日收跌破（后续穿越）；边界相等不触发，先缺失则 UNKNOWN，先发生事件不被后续缺失推翻。记录事件结束时刻；返回或穿越只是价格事实，不能替代真实假突破、漏判或阶段。相邻日期和两所高度相关，不当独立样本计算预测概率。

检验重点组和非重点组、春秋旧观察 YES/NO/UNKNOWN 都保留，周一仅作频率覆盖对照；当日非重点或未触发但事后发生的价格事件只叫待核查案例，不是已证实真实阶段漏判。缺独立人工阶段参考不能计算真实准确率、假突破率或漏判率，也不凭后验收益标真假。独立从原 4h 复算背景、摆点、确认时刻、支撑状态和全部后续，Bitfinex 从原 1h 复核聚合；合成边界、确认时序、历史失守、缺口、未来扰动和返回测试必需。
