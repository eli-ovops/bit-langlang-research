# 多轮扫描与中断恢复：合成验证结果

根据 [事前定义](多轮扫描中断恢复-合成验证定义-20261030.md)，使用 205 天以上连续合成 BTC/ETH 行情，在隔离临时目录执行七轮单次扫描。接口响应、时钟、回执和信号决定均由测试构造；扫描中的冻结信号与快照计算使用项目实际函数。扫描命令行仍只使用本机当前时间，历史时刻仅通过测试调用的纯计算函数提供。

七轮各追加一根已收盘 K 线；每轮产生一条合成 ETH 候选，并记录合成信号与带原因的跳过。一次发布前人为模拟中断后，先核对已发布头部，再使用新运行目录恢复；已发布序号连续，未提交残留保留。归档重建后，已封存区间为 **4 个候选、4 条信号和 4 个决定**，另有 **3 个候选处于未封存尾段**。

删除已封存信号、漏掉一轮扫描和损坏归档差量的反例分别被拒绝或标为覆盖缺口。测试没有证明信号源真实、实际文件不会被篡改、采集时钟可信、连续盘口存在，或止损能够成交；没有运行真实的七轮采集。

额外回归：将上轮真实单次预检的现存行情、原生成时刻和冻结配置输入重构后的扫描计算函数，所得 JSON 与保存的预检扫描一致；没有重新请求行情。相关模块整套 76 项测试通过；结果只支持代码及合成证据链的一致性，不替代真实持续运行验收。
