# 纸面行情增量归档：阶段结果

已实现本地字节差量归档：首次保存原始快照，后续按 4 KiB 块保存相同位置的复制范围与变化字节；差量大于原件时自动保存完整文件。恢复时核对每份原始压缩文件的长度及 SHA-256，不重编码行情。扫描和本机回执原件也分别存档；恢复的字节可直接送入已有离线连续覆盖检查。

提交先写入新运行目录，再通过同一文件系统的互斥硬链接发布。合成测试模拟发布前中断：旧提交仍可恢复，未提交目录保留并列为残留；再次提交使用新目录，不覆盖残留。检查头部元数据不等于检查行情载荷，只有按序重建并验证才能确认所检查文件的字节。调用方提供预期头部可发现不匹配，但如果预期值没有独立保存，就不是可信外部锚。

一次本地测量使用既有 ETH 历史文件，追加一根**合成复制 K 线**，以相同参数重新编码两份数据后比较：第二份压缩数据为 13,643,741 字节，差量为 16,542 字节，恢复结果与第二份的 SHA-256 一致。两份行情载荷合计按差量保存约减少 49.94%；该比例不含扫描、回执、提交或文件系统分配开销。只测了一个币种、一次合成追加和确定性序列化，不代表实际实时文件、90 天存储或计算成本。记录见 `data/verify/scan-archive-benchmark-20261030-01.json`。

上述节省仅是**归档载荷的模拟对比**。本任务没有删除任何原始快照，归档会额外占用空间；尚未证明实际释放了磁盘空间，也没有建立可循环复用临时快照的长期采集流程。

另一组本地样本中，既有原始和重新暂存的压缩文件几乎从开头就出现差异；因此不能假定相邻真实文件总能取得上述节省，差量无优势时会退化为完整文件。
