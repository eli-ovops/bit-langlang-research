完全沿用 [2025Q4 扩展定义](浪浪周期广度-2025四季度年度位置反例事前定义-20261105.md)：922 个既存 Binance USD-M USDT 后缀非 BTC 归档目录（当前快照并非历史完整交易池），逐个取 2024-03、04、05、06 的 1d 月包及 checksum；每个 t 仅以前 29 个完整日线计算有效分母与 7/28 日上涨数，缺口或零量 UNKNOWN，不推断上币退市，不补价格。输出所有 91 日、全部对象和原始文件，不按涨幅筛选。倍数币/特殊合约可能重复，不等同唯一币数、全市场、实际资金流或浪浪本人名单。

BTC 背景复用 `data/verify/cycle-2024q2-phase-20261104-02/` 预先存留的 Bitstamp/Kraken BTC/USD 各自 4h 数据、每日 56/28/8 日结构。已知 Kraken 缺少 2024-04-14 04:00 UTC 一根 4h 柱；凡依赖该日的背景与后续窗口为 UNKNOWN，不能用其他所补齐。年度位置复用已保存的 Binance BTCUSDT 永续 365 日日线，费率取过去 7 日 21 次 BTCUSDT 永续结算，与现货分开；公开费率 API 在需要范围内重新核对原始时间与费率。BTC 现货、永续资金费、归档参与是不同产品和市场视角，不能直接当作真实情绪。

分歧条件不变：各所 BTC 56 日研究代理 UP、有效归档合约 28 日上涨占比 ≥80%、7 日上涨占比 ≤60%；候选内 365 日范围位置 ≤50% 为 LOW、>50% 为 HIGH，其余为 OTHER，缺数据 UNKNOWN。56 日、7/28 日、80/60/50% 均是经见样本后设的研究假设，不是浪浪规则或交易阈值。BTC 后续 7/28 日收变化与当时状态分开，不能当作真实阶段标签、真实收益或独立样本；同月日点和两所高度相关，不能计作独立胜率。

保留所有月包/哈希/404、每合约日点质量与每日日点、两所 BTC、背景/广度/年度位置/费率与后续事件。核验归档 checksum、时序、正量、OHLC、BTC 缺口影响、必要资金费和若干 API 对照及独立计算；新增差异先查明并报告，不因输出调参，不选币、入场、交易或平台 start/stop。
