# 固定规则的历史分段检验（运行前定义）

目的：不改变策略参数，考察 ETH 冻结规则和 BTC H1 的表现是否跨时间段一致；这是已知历史上的描述性检查，不是独立样本外、未来前瞻或选择策略的依据。

- 窗口（UTC，左闭右开）：2022-05-01~2024-07-01；2024-07-01~2025-10-01；2025-10-01~2026-10-25。2024-07 分界沿用既有历史交割单结束后的界限，2025-10 为后段近似平分，并非市场高低点判定。所有窗口均已被此前研究间接使用。
- 两类分别是 ETH 原冻结信号与 BTC H1 自相对强度豁免信号；每个时段每个币单独从 2000 USDT、无仓开始，不将两者作为联合组合。分段起点保留之前行情预热但不继承前段仓位，因此分段收益不等于完整策略净值的自然切片。
- 用同一 `verify.tph_ledger.replay`：单边手续费 5bp、单边不利滑点 2bp、逐仓 5x 代理、维持保证金 0.5% 代理、资金费率及 5m 开盘价格代理；0.15% 初始价格风险、每日/并发上限 3，最多持仓 30 天；窗口末开放持仓以末根收盘价格标记、不强平。
- 记录候选数量、已平/未平、净值、总收益、年化、5m 收盘权益最大回撤、模拟强平数、交易账本及可追溯哈希。5m 收盘不覆盖盘中浮亏；真实标记价、跳空成交、资金费时序、滑点、手续费及清算规则 UNKNOWN。
- 不调参、不筛掉负样本、不把本次数值作为预先独立检验或胜率。BTC/ETH 信号不等于用户原交易员的全部做法。任何平台 start/stop、真实资金、付费均不执行。
