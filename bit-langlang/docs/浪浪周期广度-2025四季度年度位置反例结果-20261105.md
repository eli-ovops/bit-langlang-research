# 2025 年第四季度：年度位置与参与分歧扩展结果

## 结论：本季度没有覆盖到该候选

按事前写入的这一版**研究候选**：BTC 56 日研究结构向上、较长期样本参与至少 80% 且短期参与至多 60%，2025 年第四季度 Bitstamp 的 92 个日点中**没有触发**。在 Bitstamp 56 日背景为 UP 的 12 个日点里，可核验合约的此前 28 日上涨占比最高只有 **36.00%**。因此本季度不能检验候选内部的“年度位置高低”分组；**不能因零触发声称候选正确，也不能估计其胜率或认定没有市场变化**。

这个结果暴露出候选的覆盖盲区：2025-10-07 00:00 UTC，Bitstamp 的 56 日研究背景 UP，Binance BTCUSDT 永续最近日收处于此前一年范围的 **97.65%** 位置；同期可核验归档合约中 **437/476（91.81%）**此前 7 日上涨，但仅 **167/476（35.08%）**此前 28 日上涨。由于达不到事后假设的 80% 长期参与条件，该日分类为 OTHER。Bitstamp BTC 在后续 7 个完整日末收盘较当时约 **-7.59%**；这是后来才知道的价格事实，不是策略收益或当时已确认的顶部。这里展现的是与之前假设不同的“BTC 位置偏高、合约短期普涨但较长期参与低”的组合；单凭它也不能断定阶段或构造交易规则。

## 方法与范围

计算前写入的[扩展定义](浪浪周期广度-2025四季度年度位置反例事前定义-20261105.md)固定 [2025-10-01,2026-01-01) 全部 **92 个 UTC 日点**、两所 BTC/USD 现货；2025 Q4 已参与项目交易及价格研究，时间和候选由之前已知反例启发，是回顾性方法探索，不是独立盲测、未参与设计的样本外、真实阶段标签或盈利评估。

候选只是一种研究假设：BTC 56 日双半窗研究代理 UP、当时有效归档合约 28 日上涨占比 ≥80%、7 日上涨占比 ≤60%；不足为 UNKNOWN、其余 OTHER。只有候选内才会进一步标记 BTCUSDT 永续当时 365 日价格范围位置 ≤50% 或 >50%；这些期限、80%、60%、50% 都不是浪浪的公式，不是应交易的门槛。由于本期零触发，LOW 和 HIGH 均无覆盖；不改门槛或事后挑其他月份冒充本期通过。

BTC 空间使用 Binance BTCUSDT 永续 t 前完整 365 日日线高低和最近日收的位置；这只是范围参考，不是已验证压力或支撑。此前 BTC 现货 56/28/8 研究结构使用 Bitstamp 与 Kraken BTC/USD 各自 4h，现货和永续分开，不混拼。情绪相关字段为 Binance BTCUSDT 永续 t 前 7 日 21 次费率，非资金心理或人数。所有 92 个 Bitstamp 日点均满足年度位置及费率质量条件。[当时与后续逐日数据](../data/verify/cycle-breadth-binance-archive-2025q4-20261105-01/btc-archive-year-asof-and-future.csv)包含全部非触发日。

## 两所数据缺口与行情例子

Kraken 官方 4h 历史缺少 **2025-11-01 16:00 UTC** 一根柱；因此其 56 日背景在 2025-11-02 至 12-27 共 **56 日**为 UNKNOWN，涉及该缺口的后续 7 日日收窗口 8 个、28 日日收窗口 29 个亦为 UNKNOWN。不得用 Bitstamp 替代 Kraken，也不能称整季双所完整。Kraken 剩余 36 日候选分类均 OTHER；只有两所均有数据时才能描述两所状态。

Bitstamp 本轮第二个历史 API 页在 TLS EOF 失败后，没有降低安全校验或反复重试；改用项目既存的**同一 Bitstamp**历史文件承接前期。两次获取重叠 **465 根 4h** 的 OHLCV 逐项完全一致，才按时间组合，来源和恢复原因记录在[价格数据摘要](../data/verify/cycle-btc-spot-2025q4-20261105-01/summary.json)和[恢复定义](浪浪周期广度-2025四季度Bitstamp历史重叠补充-20261105.md)。Bitstamp 所需 1,062 根四小时柱网格、OHLC 和正量检查通过，两所可比同柱未触发预设 10% 价格差提示；这不是成交真实性或 Kraken 完整性的保证。

2025-10-07 时 Bitstamp 最近完整日收 **124,728 美元**、之前 28 日参考上沿 126,272；永续年度范围位置 97.65%；上述归档样本此前七日上涨 437/476，二十八日上涨 167/476；先前 21 次资金费均为正。之后 Bitstamp 7/28 个完整日末日收分别约 **-7.59% / -14.58%**。同期 Kraken 在可用的 7 日窗口约 -7.70%，28 日窗口因上述缺柱为 UNKNOWN。资金费和合约参与不是对市场心理的证明；上涨数属于滚动历史窗口，与未来价格不能混同。

## 数据质量与复算

当前 922 个非 BTC USDT 后缀归档目录 × 四个月：**2,343 个 ZIP/checksum 通过并再次校验，1,345 个请求返回 404**；目录与 404 都不证明历史实际可交易全集或上退市。已得归档中 **73 个合约共 6,887 根零量日线**，依事前定义影响相关窗口 UNKNOWN。各日有效合约分母为 **474–524**，其余目录 UNKNOWN，不能称唯一币数或全市场。[全部日分母](../data/verify/cycle-breadth-binance-archive-2025q4-20261105-01/archive-daily-asof.csv)、[逐合约及未知](../data/verify/cycle-breadth-binance-archive-2025q4-20261105-01/contract-daily-asof.csv)、[归档回执](../data/verify/cycle-breadth-binance-archive-2025q4-20261105-01/archive-receipts.jsonl)、[零量/质量记录](../data/verify/cycle-breadth-binance-archive-2025q4-20261105-01/parse-problems.json)和原 ZIP/checksum 已保存。

从原 ZIP 使用独立向量化方法重算 92 日日分母及 7/28 日上涨数，一致；五个合约在两个已有 API 时间段内共 **295 根**重叠日线的 OHLCV 与 API 一致，不代表其余合约或逐笔成交都已验证。BTC 每所 92 日背景、年度位置、资金费和 7/28 日日收缺口处理从原数据独立重算；资金费公开 API 与本地 **294 条**逐项一致。BTC 184 个来源/日点的 as-of 字段、另 8 个归档合约/时点经过未来价格扰动检查。所有这些只是来源、计算和时间顺序验证，不验证浪浪的真实阶段、真实情绪或交易盈利。

没有选币、设计入场、交易或执行平台 start/stop。
