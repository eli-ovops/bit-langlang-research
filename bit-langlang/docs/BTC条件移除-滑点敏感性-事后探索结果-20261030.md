# BTC 条件移除：滑点敏感性事后结果

在已研究历史中，比较原 ETH 冻结规则和仅移除 BTC 风险开启条件的候选。每个情景独立以 2000 USDT 开始，单边手续费假设 5bp，资金费采用研究数据和价格代理；列出的滑点为每边相对 K 线价格的额外不利偏移。0bp 是理论比较，不代表能以该价格成交，也不是零成本。

| UTC 历史区间 | 规则 | 0bp 期末 / 收盘回撤 | 2bp 期末 / 收盘回撤 | 5bp 期末 / 收盘回撤 |
| --- | --- | --- | --- | --- |
| 2025-10-01 至 2026-10-25 | 原规则 | 1918.24 / -5.57% | 1915.08 / -5.69% | 1910.34 / -5.86% |
| 同上 | 移除 BTC 条件 | 1652.68 / -20.96% | 1640.23 / -21.36% | 1621.72 / -21.95% |
| 2024-07-01 至 2026-10-25 | 原规则 | 3029.15 / -20.51% | 2959.48 / -20.68% | 2920.81 / -20.93% |
| 同上 | 移除 BTC 条件 | 2532.00 / -32.29% | 2456.25 / -32.86% | 2398.55 / -33.70% |

这两段样本中，三种滑点假设下移除条件的期末权益均低于原规则；最近一段即使假设 0bp 额外滑点，候选仍低于初始资金。其不能证明实际滑点为任一数值，也不能证明未来一定如此。不同场景的触发、仓位或持仓容量可能变化；例如较长窗口原规则 0bp 时平仓 106 笔，2bp 时为 108 笔，因此不能把净值变化机械归结为相同订单上少扣或多扣的滑点。

12 个情景均无期末未平仓；2bp 结果与前一轮消融研究逐项对齐。共 1298 条跨情景平仓记录按数量、入出价、双边手续费和有符号资金费独立复算，最大单笔差异小于 `1.8e-13` USDT。各场景权益及输入、配置和代码哈希见[结果目录](../data/verify/remove-btc-risk-on-cost-20261030-01/summary.json)及[独立算术核验](../data/verify/remove-btc-risk-on-cost-20261030-01/independent_arithmetic.json)。
