# 周期、空间、情绪：人工判读草案 v2

## 定位

本草案根据已见资料和[术语归属审查](浪浪周期-阶段术语归属及突破条件审查-20261105.md)提出，写作时研究者已接触大量历史结果，**不是未受历史影响的事前注册，也不是浪浪给出的判别公式**。它不继承旧 56/28/8、80%/60% 或摆点阈值，也不修改[既有外部文章映射协议](浪浪周期-独立判读与新时段事前协议-20261105.md)。两个口径研究对象不同，不能将 v2 应用到旧结果后宣称原先就这样定义。

用户要研究“震荡末期、启动、主升”，其中“启动”是提问者的措辞，浪浪回答并未给出充分必要条件。以下是供审阅者观察、保留竞争解释的工作定义，不是可以客观确认的市场真值。

## 时点与记录顺序

每个观察点先定日期和来源，仅展示该时点已收盘行情；任何需未来 K 线才能确认的高低点都不能作为当时已确认事实。先分别记录、后提出阶段候选，任何一项不能单独强制决定阶段：

1. **背景**：较大尺度的上行、下行、区间或混合；标示明确的参考高低区域以及所用尺度。证据不够留 UNKNOWN。
2. **空间**：记录价格在参考区域上方、内部还是下方；基于当时可见结构说明区域如何形成，并保留其他合理画法。参考高低和可能支撑压力不是已经证实的阻力或支撑。
3. **局部变化**：写明较小尺度已完成的高低点及最近一段价格变化，包括区间内变化、向外试探、收盘越界或回到区域之内。没有未来确认的摆点仅写“暂定”，不能倒填。区间内部的变化也要记录，**不要求先突破才能观察启动候选**。
4. **情绪线索**：分别记录来源、发布时间、覆盖对象、客观指标与分析者解释；例如交易量、资金费、基金流和第三方叙述各有不同含义，不能单独断言市场心理。没有同期可靠材料就写 UNKNOWN；不可把价格上涨直接写成“资金愿意推动”。

时间尺度可以按审阅素材所展示的尺度观察，但制作素材、观察点和范围必须在审阅之前固定并留痕；不要事后为匹配某个结论改变。空间、局部结构或情绪信息不足，应保留缺项，不能用另一项冒充。

## 阶段候选：记录支持与反证，不强迫单选

| 候选 | 需要记录的当时现象 | 必须保留的竞争解释 |
|---|---|---|
| 震荡末期候选 | 可辨识的既有震荡范围，以及当时已经出现、可能使原有平衡变化的具体证据；写清证据所在位置与时间 | 普通震荡仍可继续、向相反方向离开；仅凭在范围内反复运行无法知道是不是“末期” |
| 启动候选 | 相对既有结构，出现新的方向性推动证据；说明这种推动位于范围内部、试探边界还是已越界，并记录持续性与回撤 | 区间内反弹、短暂试探、假突破或走势已经成熟；一次越界本身不能定性为启动 |
| 主升候选 | 写明相对大背景的持续上行结构、已推进的空间，以及局部回调或停顿；时间尺度需明确 | 大级别区间内反弹、上涨已进入后期或转震荡；短期回调不自动等于大级别衰退 |
| 其他阶段 | 具体证据支持下跌、普通震荡或其他不属于三类的状态时，记录理由 | 与信息不足的 UNKNOWN 分开，不能为凑覆盖率强行给其他阶段 |
| UNKNOWN / 多种可能 | 数据缺口、尺度冲突、证据不足或相反解释均合理 | 将支持和反证并列，不因后来价格回头修改 |

这些是人工语义与记录要求，不是可自动复现的严格分类算法。比如何种“变化”足以从普通震荡转为末期，资料没有明确界线，观察者之间可能分歧；若无法给出足够依据就留空。阶段名称不保证后续上涨或下跌，更不保证达到某个价格。

## 检验与防止循环论证

在每一批新材料读取之前，先冻结本草案版本、观察区间、数据源、材料截断方式和所有观察点；逐点保留没有候选、其他阶段和 UNKNOWN，不能按结果挑选日期。审阅与旧量化候选计算分别记录：输入只含当时信息；先记录支持证据和反例，再记录后续价格事实，禁止回填。

独立于旧量化参数不等于独立于开发者、已看过的历史或未来知识。应尽可能由未参与本草案的人只看当时材料独立判读，并保留分歧及认识盘面的情况；人工意见不是市场真值。若目前没有可证实未用于设计的足够完整历史区间，或没有独立参考，就只能做标明污染和限制的演示，不报告真实漏判率、误判率、准确率或浪浪复刻程度。

后续事实用于提出反例和竞争解释，而非单独定义对错。例如向上越界后返回可以记录为“越界后返回”，不能自动认证真假突破；当初留空也不因后来上涨或下跌变成错误。

本草案现未在新的合格留出数据上验证。既有五张相邻匿名练习图不构成多环境独立样本，用户评审仍待完成。没有选币、设计入场或交易；任何平台 start/stop 前须先告诉用户。
