# 匿名盘面 P01：用户练习判读

性质：已被项目研究过的单所历史盘面，练习使用，不计入独立样本或准确率。用户看到截至观察时刻的匿名日线与 4 小时线，不含后续。

用户原话：

> 筑底 完成，在等待一些情绪面的波动或者在等待当时 一个比较重要的会议结果？ 我倾向于横盘，等待消息的催化，决定 大方向  ，例如btc 上etf，或者美联储降息预期  非农数据 之类的大催化

> 出现大跌筑底 失败。出现大涨可能是消息催化

用户未指定大跌或大涨的百分比、时限、具体支撑或压力；消息催化只是可能原因，具体事件和因果 UNKNOWN。后续可分别观察价格是否跌破既有低点并持续在其下方、上涨是否越过附近压力及回踩表现；这些观察方法由研究方提出，不是用户已指定的精确标准，也不是浪浪本人已确认规则。

用户进一步明确筑底失败条件：

> 跌破之前的最低点 并且没有 收回来

当时尚未指定是影线还是收盘价跌破、用哪个时间级别观察，以及多少时间未收回才算成立。此条件为用户对练习图的判读，不是浪浪本人已确认的规则。

用户继续明确：

> 以日线收盘价为准，跌破之前的最低点后没有收回来，就认为筑底失败。

按日线收盘价判断跌破与收回；用户尚未规定最低点选取窗口、跌破后观察多久，以及收盘恰好等于低点如何处理，均不自行设定。这是用户的练习判读标准，不是浪浪本人已确认规则。
