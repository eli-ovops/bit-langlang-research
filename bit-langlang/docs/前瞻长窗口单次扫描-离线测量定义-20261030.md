# 前瞻长窗口单次扫描：离线测量定义

使用已保存的 BTC/ETH 历史行情，在 2026-10-25 00:00 UTC 假定检查时刻，分别调用本地 `forward_scan.build_snapshot` 一次，窗口为 3 天和 90 天；记录壁钟耗时、扫描 JSON 序列化字节数、候选数、窗口起点及输入文件哈希。固定按 3 天后 90 天的顺序，因此第二次可能受文件缓存影响；不以该差异断言窗口的单独计算开销。扫描数据结束时刻与配置、两币历史网格和研究输入哈希须核对。

该实验不连接网络、不启用任务或策略、不写真实前瞻事件；两个样本仅测一次，不能推断长期耗时分布或 90 天可靠性。扫描函数不包含行情拉取、压缩写盘、报价、资金费、回执持久化、增量归档和恢复，因此总耗时与磁盘开销仍 UNKNOWN。历史扫描快照不是在当时真实捕获，不是前瞻或可成交证据。
