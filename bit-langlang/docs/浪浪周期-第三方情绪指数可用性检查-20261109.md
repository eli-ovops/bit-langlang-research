# 第三方情绪指数：覆盖和使用限制

按[下载前检查口径](浪浪周期-第三方情绪指数可用性口径-20261109.md)，获取 Alternative.me 官方 BTC Fear & Greed API 的完整当前响应。API 返回 3,200 条日点；两段已研究历史中，2023 年第一季度 90/90 日、2025 年第二季度 91/91 日的 UTC 日期均有且仅有一条记录，数值均在 0–100。2023Q1 范围为 25–68，2025Q2 为 18–78；这些是当前 API 返回的历史数值，不说明当时一定已发布、未经修订或客观反映情绪。

对原有 26 个固定 UTC 观察点，逐条取时间戳严格早于该点的最近指数记录，26/26 均能找到。另从保存的 API 原文独立重算取值和时间并核对 SHA，保留[逐点表](../data/verify/cycle-fng-source-check-20261109-01/observations.csv)、[质量汇总](../data/verify/cycle-fng-source-check-20261109-01/summary.json)及原始响应。时间戳早不证明该值在观察点时已经发布，也不保证该历史值后来没有调整；所以所有点的历史可得性仍是 UNKNOWN，不作为用户盲评的同期事实。

[Alternative.me 官方说明](https://alternative.me/crypto/fear-and-greed-index/)称该指数包含 BTC 波动、价格动量/成交量、社交媒体、主导率及搜索趋势等，并注明调查部分目前暂停；这是**当前网页**的说明，不能无证据推断历史每一天的具体成分及权重。尤其波动和动量本身使用价格，不能把指数与 K 线视为两个独立证据；社会传播活跃也不是全市场实际情绪。该指标不是浪浪本人给出的情绪公式或阶段真值。

两季已被研究过，覆盖齐备不改变样本污染，也不提供震荡末期、启动或主升的独立标签。本检查不报告其预测能力或阶段准确率。未来观察若采集此指标，应实际保存当时 HTTP 响应及取得时刻，按数据提供者要求就近标注来源，并区分采集时可见、过去历史回补和实际市场情绪。未选币、设计入场、交易或执行平台 start/stop。
