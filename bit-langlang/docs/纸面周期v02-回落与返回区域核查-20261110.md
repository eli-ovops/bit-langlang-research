# v0.2 市场观察：回落幅度与区域返回

## 核查结果

按[预设口径](../data/verify/paper-v02-retreat-diagnostics-20261110-01/口径.md)检查此前全部 **149 个**已研究历史的 v0.2 候选日：只看突破完成后、各观察点之前已经结束的日线。以突破日日收为参照，之后日内最低点形成的最大向下距离中位数约 **2.27%**，5 个候选日小于 0.5%。幅度是从突破日收至截至观察点所见最低点，不是从后续峰值回撤、交易盈亏或市场情绪；相邻日高度重叠，不能当独立样本。0.5% 是为说明尺度而事后检查的研究数值，不是浪浪的规则或选择阈值。

追加逐点检查突破后的价格是否曾回到该候选的固定参考上沿 B 以下：

- **71 / 149 个候选日**，此前至少一根日线的日内低点低于 B；
- 其中从整个候选集中看，**40 / 149 个候选日**曾有日收低于 B，而观察时最新完整日收重新高于 B。

这暴露一个具体区别：v0.2 要求的是**最新收盘高于 B**，并不要求从突破后一直守在 B 以上。因此不能把 v0.2 标签解释为“一直站稳原区间上沿”。不能从日线高低断言盘中路径、执行价格或真实情绪，也不能把收回直接定义为假突破或阶段成功。

例：截至 2022-10-29 00:00 UTC，研究者的候选 B 为 20,500 USDT；10 月 27 日收于 20,285.5，低于 B；10 月 28 日收于 20,582.8，高于 B。以上两根日线均已在观察点之前结束。它仅是事后挑选的说明案例，不能外推预测。

## 对研究和模拟的影响

观察记录需要把至少三种价格事实分开：**仅曾回落；盘中回到 B 下方；日收回到 B 下方后重新收上来**。它们不能单独决定“正常回调、下跌反弹、启动”，也不等于浪浪给出的分类。此前候选受重复研究和事后选择影响，阶段真值、同期真实情绪及有效性均 UNKNOWN。
