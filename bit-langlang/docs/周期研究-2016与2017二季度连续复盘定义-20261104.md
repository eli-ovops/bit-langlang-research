# 2016 与 2017 二季度：连续周期证据复盘定义

在下载本轮 Bitstamp 4小时行情和读取新组合的逐段输出前，固定 BTC/USD 现货 [2016-04-01,2016-07-01) 与 [2017-04-01,2017-07-01) UTC 全部每日，按七日连续分段，末段截断。每段使用自己前57日预热、各自全季度和季度后28日：Kraken 取此前保留的官方XBTUSD_240成员、Bitstamp取官方历史4h API（按需分页），不跨所拼接或补价；原始响应、范围、散列、缺失和每4h成交量均保留。2016与2017在本项目此前都有周频/阶段研究，选期基于既有历史知识，已看过不少历史案例，结果不能称独立盲态、未参与设计、前瞻或样本外真实准确率。

沿用既有研究证据：前56日、前28日日线及前8日四小时两半高低关系，上一日收与前28日高低范围；观察时已知较早28日范围 [t-35d,t-7d) 以及最近7日中严格收盘越过该旧边界的次数和最近日收所在位置。两种28日边界不混淆，均为研究参考而非浪浪本人公式；长期下跌+短期上涨可能为反弹或转强，长期上涨+短期下跌可能是正常回调或转弱；其他混合状态如实描述，不能凭规则名称当作真实春秋。

观察点之后另以 t 前28日边界冻结、最多21个完整日找首次严格日收越界，检查第二个完整日是否仍同侧和随后7个完整日是否收回；等值不算严格越界/收回。事件必须在日线收盘后成为可知事实，不倒填观察时点；相邻段窗口和越界可能重叠，不是独立事件，不把收回等价真实假突破或统计漏判率。段末日收变化只是价格描述非交易收益。截图季节只是辅助语言，情绪、市场广度、真实阶段和浪浪同期判断缺失时保持 UNKNOWN。
