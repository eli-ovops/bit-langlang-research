# bit浪浪 风格策略规格 v0（待数据校准）

> 状态：草案。参数为公开资料反推的**初始值**，必须用你的交割单/K 线校准。
> 目标不是"高胜率"，而是**幂律凸性**：成本端极小额、可承受连续止损；收益端让极少数单子跑到 5R–30R，用尾部盈利覆盖全部试错。

---

## 0. 目标函数（先定义清楚，避免回测自欺）

设单笔风险暴露（该笔最大亏损）为 `r`（建议 = 账户 0.3%–1%）。

期望：`E = p·avgWin − (1−p)·avgLoss`，其中 `avgWin/avgLoss ≈ 3–10`，`p ≈ 0.25–0.45`。

**验收标准（全部满足才算"复刻成功"）**

| 指标 | 门槛 | 说明 |
|---|---|---|
| 单笔最大亏损 | ≤ 1.0% 账户 | 严格止损的硬约束 |
| 盈亏比 | ≥ 2.5 | 他自述 2.5–3 |
| 胜率 | 25%–45% | **不追求高胜率**，高了反而可疑（过拟合） |
| 最大回撤 | ≤ 20% | 他账户页显示 14% |
| **去尾检验** | 剔除最大 3 笔后仍盈利 | 防"一把梭幸存者" |
| **连亏测试** | 能扛 20 连亏不破 20% 回撤 | 分仓 + 小额风险的意义 |
| 样本外 | 最近 6–12 个月独立区间不崩 | 防 2023–24 单边牛市拟合 |
| 换币种稳健 | 换 3–5 个同规则标的结论不变 | 防单币过拟合 |

## 2. 策略模块（五层状态机）

```
[1] Regime 过滤      → 今天能不能做、能做多重
[2] Universe 选币    → 今天盯哪 4–8 个
[3] Setup 形态       → 现在是 6 个点位里的哪一个
[4] Trigger 扳机     → 5m 拐点确认，市价进
[5] Risk/Exit        → 止损、两道止盈、推保本、移动止损
```

### 2.1 Regime：市场季节（日线 / 4H）

用 BTC（或指数）定义 4 个状态，**只允许在 Spring/Summer 开多**：

| 状态 | 判定（可程序化） | 动作 |
|---|---|---|
| Spring | 日线收盘突破 N 日箱体上沿 + 20 日新高 + 量能放大 | 允许开仓，风险系数 1.0 |
| Summer | 日线在 20/60 日均线上方、ATR 上升、创新高频率高 | 允许开仓，风险系数 1.0–1.2 |
| Autumn | 价格高位横盘（20 日内振幅收窄、未创新高） | 只减不加，风险系数 0.3–0.5 |
| Winter | 收盘跌破 60 日均线且创新低 | **禁止开多**，空仓 |

> 注意：他不用均线，但**回测需要可程序化的代理指标**。均线只作为"季节代理"，不是他的原始方法；后续可用结构（高低点序列）替换，做敏感性对比。

### 2.2 Universe：龙头筛选

每日收盘后：

1. 取成交额/热度榜前 30（剔除 BTC/ETH）；
2. 过滤：上市 ≥ 30 天、日成交额 ≥ 阈值（防流动性陷阱）、**盘口滑点估算 ≤ 0.1%**；
3. 打分：① 日线箱体时长（越长越高）；② 距上方压力位空间（越大越高）；③ 近 30 日相对 BTC 强度；④ BTC 回调日的抗跌性；
4. 取前 4–8 个进入次日监控池。

### 2.3 Setup：三个可做点位（其余不做）

| 编号 | 定义（程序化） | 备注 |
|---|---|---|
| ① 启动 | 日线箱体（≥ 15 日，振幅 ≤ 25%）向上突破；或突破后回踩箱顶 ±3% 内企稳 | 不追突破，等回踩 |
| ② 小分歧承接 | 拉升 ≥ 15% 后首次回调 ≤ 8%，回调低点不破前一个 5m 结构低点 | 第 3 次小分歧起不做 |
| ④ 二波 | 大分歧（回调 ≥ 15%）后形成 ≥ 5 日箱体；二次冲箱顶不过 → 回踩箱体下 1/3 且不破前低 | 最优位置之一 |

**禁止**：箱体内部、逆势摸顶、下跌趋势中的反弹、距离上方压力位 < 2R 的突破。

### 2.4 Trigger：5 分钟拐点（唯一入场扳机）

```
在 5m 上：
1) 记录最近一个摆动低点 L（前 N 根内最低，N=5）；
2) 后续 3 根 5m K 线的最低价均 > L；
3) 第 4 根出现阳线，且 close > 前一根 high；
4) 且 close > 该 setup 的失效位（箱顶/回调低点上方）；
→ 下一根开盘市价进多。
若期间跌破 L → 重新寻找 L。
```

**过滤**：入场时 `R = entry − stop`；要求 `目标空间（到日线前高/整数位）≥ 3R`，否则放弃。

### 2.5 Risk / Exit

| 项 | 规则 |
|---|---|
| 止损 | `stop = L − buffer`（buffer = 0.15% 或 0.3×ATR5m）；R = entry − stop；**单笔风险 ≤ 账户 0.3%–1%** |
| 仓位 | 固定名义本金（不复利）：`notional = risk_amount / R%`；杠杆硬上限 BTC 10×、山寨 5× |
| 止盈 T1 | 第一个日线压力位 / 3R，减 50% |
| 保本 | T1 成交后，剩余止损推到 entry（+手续费） |
| 止盈 T2 | 第二个压力位 / 整数关口 / 前高；或 5m 结构破坏（跌破最近 5m 摆动低点）离场 |
| 移动止损 | T2 未到但趋势延续：每创新高，止损上移至最近 5m 摆动低点下方 |
| 时间止损 | 持仓 > X 根 5m（如 96 根 = 8h）仍未到 1R → 平仓（他的单一半 <10 分钟，拖太久说明逻辑失效） |
| 禁止 | 补仓、摊平、抗单、加仓、对冲、滚仓 |

## 3. 回测协议（防自欺的硬规定）

1. **成本**：taker 手续费 0.04%–0.06% 双边 + 滑点 0.05%–0.15%（按币种流动性分档）+ 资金费率逐 8h 计入。
2. **成交假设**：信号 K 线**下一根开盘**成交；止损用**标记价格**或 K 线 low 触发；同根 K 线先触发止损则按止损处理（保守）。
3. **样本切分**：训练/调参只用 2022-01–2024-12；**2025-01 至今为样本外**，只跑一次，不许回头改参。
4. **参数敏感性**：对 5m 摆动窗口 N、buffer、RR 门槛、风险% 做网格，报告**参数高原**而非最优点。
5. **去尾检验**：剔除盈利最大的 1/3/5/10 笔后重新计算收益与回撤。
6. **连亏压力**：统计最大连续亏损笔数、最长回撤天数；模拟"连亏 20 次"的资金曲线。
7. **换币稳健**：同一套参数跑 5 个不同标的（BTC、ETH、SOL、一个主流山寨、一个次新龙头）。
8. **报告必须包含**：交易笔数、胜率、盈亏比、期望 R、最大单笔盈亏、亏损分布直方图、持仓时长分布、去尾后收益、最大回撤、样本内外对比。

## 5. 已知失效场景（必须在报告里写清楚）

1. **长期震荡市**：假突破频繁，连亏放大——这正是他"秋冬休息"要规避的。
2. **只做多**：熊市无信号，资金闲置是正常结果，不要为了"有交易"而降门槛。
3. **小币流动性**：滑点吃光利润，需硬性过滤。
4. **单一品种**：山寨季结束后无标的可做。
5. **尾部依赖**：若收益 80% 来自 1–2 笔，必须明示"这是彩票型分布，实盘可能连续数月不赚钱"。

### 7.2 止损/止盈的真实尺度（用于实现参数）

- 亏损单的"止损距离"（|收益率|/杠杆）：P10 **0.08%**、中位 **0.45%**、P75 0.95%、P90 1.62%、P99 3.36%；
- 盈利单的"盈利距离"：中位 **0.75%**、P75 1.96%、P90 4.14%、P99 14.53%；
- 亏损占保证金比例：中位 4.9%、P90 16.3%、P99 35.9%；
- 盈利占保证金比例：中位 7.6%、P90 42.3%、P99 150%。

→ 与规格 §2.5 一致：**止损 0.2%–1%（5m 级别），目标 1%–4%，RR 中位约 3**。

### 7.3 收益的时间集中度（样本外风险）

| 年份 | 笔数 | 收益 | 胜率 |
|---|---|---|---|
| 2022 | 1745 | 124,213 | 40% |
| 2023 | 2120 | 724,493 | 40% |
| 2024（1–6 月） | 943 | **4,687,785** | 44% |

**85% 的利润来自 2024 年 2/5/6 三个月**。去尾检验：剔除最大 1 笔剩 435.6 万，剔除最大 20 笔剩 134.2 万（仍为正，但缩水 76%）。

→ 复刻版本必须接受：**大部分时间不赚钱，靠少数月份爆发**。

### 7.4 对"只多不空"的影响（用户约束）

历史多空收益比 ≈ **3.2 : 1**。只做多会放弃约 **24%** 的收益与一部分对冲能力；需要靠更严的季节过滤（只在 Spring/Summer 开多）来补偿。

### 7.5 账户参数（2000U 版）

| 方案 | 每份保证金 | 单笔风险 | 说明 |
|---|---|---|---|
| **A. 忠于原版** | 667U（3 份之一） | ≤10% 该份 = **67U（3.3% 账户）** | 与原规则一致，但单笔风险偏高 |
| **B. 保守版** | 200–400U | **0.5%–1% 账户**（10–20U） | 回撤小，但需要更大盈利倍数才好看 |
| **C. 折中（建议先跑）** | 500U | **1.5% 账户**（30U） | 兼顾"输得起"和"能看出收益" |

杠杆：BTC/ETH ≤10×、山寨 ≤5×；单笔名义 ≤ 5,000U（B 方案下）。

### 7.6 必须写进回测的摩擦

- 双边 taker 0.05% + 滑点 0.05–0.15%（山寨取高档）；
- 资金费率逐 8h；
- 历史手续费占比 13.5%，**回测若忽略手续费会显著高估**；
- 5m 信号在下一根开盘成交。
