# 标记价历史文件缺口及补充方案

在执行事前定义的数据完整性检查时，已校验 SHA-256 的官方 2026-06 月度文件缺失 UTC 2026-06-29 全部 288 根 5 分钟 K 线，首次核验因此失败；不是缺少成交价文件，也不应以内插值填补。尚未计算任何触发比较结果。
