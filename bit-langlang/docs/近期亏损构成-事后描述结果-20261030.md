# 近期亏损构成：事后描述结果

对已有 ETH 冻结信号、按模拟权益调整规模的历史分段 `2025-10-01 ≤ t < 2026-10-25` 做账面描述。分段独立以 2000 USDT 空仓开始，假设每边手续费 5bp、每边不利滑点 2bp，并按历史资料计算资金费；该窗口已反复研究，非独立样本外。

22 笔均为模拟止损退出，成交价已含假设滑点的毛盈亏均为负。账本合计：毛盈亏 **-68.1113 USDT**，双边手续费 **16.1860 USDT**，有符号资金费 **+0.6272 USDT**（表示净支付），净盈亏 **-84.9245 USDT**；期末权益约 **1915.0755 USDT**，无未平仓。逐笔复算净盈亏的最大差异为 `6e-16` USDT（使用十进制解析账本中存储的数值），与原汇总的平仓数及期末权益相符。

这个样本的亏损不只是手续费把原本盈利的成交价毛盈亏变成亏损：22 笔的成交价毛盈亏均已为负。上述毛盈亏本身已经包含模型假设滑点，不能再将滑点重复扣减，也不能据此拆出真实市场价差或实际滑点。所有止损是模拟退出，不能证明实盘会在该价格成交。

这是事后描述，不是因果诊断；如果取消成本或改变止损，权益、持仓容量及后续入场可能变化，不能仅将已记费用加回来当作该策略的新回测。也不能据此推断未来止损率或否定交易者本人方法。事后定义见[分析定义](近期亏损构成-事后描述定义-20261030.md)，哈希及机器可读结果见[数据文件](../data/verify/later-b-loss-decomposition-20261030-01.json)。
