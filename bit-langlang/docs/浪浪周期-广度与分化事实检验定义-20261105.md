# 全市场阶段线索：广度与分化事实检验定义

依据[公开录屏与原话材料](浪浪周期-公开录屏线索与层级修正-20261105.md)所提示的“整体参与与分化”线索，检查此前只保留上涨数量是否足以描述样本的价格分布。录屏源为转载并有机器转写错误；不能把以下指标、时间窗口、统计方法说成浪浪公式。本研究只观察聚合市场资料，不选交易币、不设计入场、不交易、不操作平台 start/stop。

在读取本轮分布结果前，复用已保存的五组 Binance USDT-M 非 BTC 合约归档逐合约数据：2022-11、2023-11、2024Q2、2024-11、2025-08、2025Q4、2026-01 全部不重复 UTC 日点。其价格、BTC 背景和部分上涨数量早已被本项目研究；本次是**已见历史的事后诊断**，不能称未参与规则设计的独立样本外或盲测，也不是市场真实阶段或情绪标签。

每个观察时点仅使用既有记录中 `quality=OK` 的合约此前 7 日、28 日收盘变化，分别记录有效数、上涨数、10/50/90 分位和上半分布差 `P90−P50`、下半分布差 `P50−P10`。分位采用 pandas/NumPy 线性插值，是描述相对分布的技术选项，不是阶段阈值。相同上涨比例与不同分位差只能说明分布信息不同，不能直接断定某条领先币、资金流、热点集中、情绪、浪浪原意或预测效果；同一底层资产可能由多个归档合约重复计数，价格变动不是资金收益或交易规模。

每日保留全部有效与 UNKNOWN 分母，不按单日表现选择观察点；未来数据、后续收益、个别交易币名称均不输出或用于任何判读。先写出全体 335 日，再以事先已讨论的四个对照日期 2023-11-17、2024-11-19、2025-08-05、2026-01-16 展示（2023 有已知六合约成交量差异，须单独标记）；这四个日期是已知结果选例，只能演示数据结构，不得推断概率或作为阶段真值。不同期分母与合约成分不同，分位可能因新旧目录、停盘或样本变化而异。

通过独立 pandas/NumPy 方法复算全部日点的有效数、上涨数和分位，检查每日期限一致、唯一合约、非有限数处理、时间顺序。对 2023 11 月差异日可使用此前排除六合约的敏感性假设，仅作为事后比较，不覆盖原结果。保留源数据哈希和逐日结果；若输入缺失或字段不一致则保留 UNKNOWN 并说明。仅计算历史分布，不进行胜率、收益或阶段分类。
