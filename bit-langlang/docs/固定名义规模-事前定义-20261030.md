# 固定名义规模对照：事前定义（2026-10-30）

研究问题：现有 ETH 历史回放按模拟账户权益的 0.15% 设定价格风险，利润和亏损会改变下一笔规模；改用固定初始资金基数后，既有历史结果对规模方式有多敏感？

来源线索：用户 PDF 第 4 页对是否将利润滚入下一笔的提问回答“固定金额，固定仓位”，第 21 页称其系统不支持复利回撤；第 17 页自述将部分总资金放在合约钱包后使用全仓。历史截图不证明真实账户持仓或账户资金流。此对照仍用逐仓强平代理，不能称为对其全仓操作的还原。

预先固定的两种研究口径：

- 基线：维持现有 `verify/frozen_config.json` 和回放，按可观察的模拟总权益 × 0.0015 设置目标价格风险。
- 对照：仅将风险计算基数换为初始 2000U，因此目标价格风险固定 3U；固定 0.4% 价格止损下，对应 750U 名义、5 倍时初始保证金 150U。若余额不足则按现有现金上限缩小或跳过。固定风险与固定名义在此固定止损模型中等价，不代表回答中的“固定金额”一定指哪一种，也不是交易建议。
- 其他条件完全不变：相同信号与历史数据、下一根开盘的假设入场、每边手续费 5bp、每边不利滑点 2bp、5 倍逐仓代理及既有资金费/出场处理。差异只能解释为本模拟中的规模规则变化，不能推断真实账户。
- 预先使用现有已研究窗口 2022-05-01~2024-07-01、2024-07-01~2025-10-01、2025-10-01~2026-10-25，以及 2024-07-01~2026-10-25；每段独立 2000U 初始，记录逐笔和期末未平仓、净权益、5 分钟收盘回撤、交易数量、费用、资金费及输入/配置哈希。所有窗口都已被研究，不是独立样本外。
- 不按结果优化参数或覆盖原始输出；数值对账与输入时间网格检查未通过则结果无效。结果受交易序列、资金上限和浮盈亏影响，固定规模与自适应规模不一定逐笔一致。统计盈利不证明前瞻盈利、真实成交或真实强平。
