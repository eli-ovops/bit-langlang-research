# 单次行情扫描归档：预检结果

本地单次工具 `verify.paper_scan_once` 将基线校验、公开行情、已收盘 K 线追加、冻结信号扫描、本机回执和增量归档串联。它不启动定时任务、平台策略或纸面前瞻，不访问账户和订单。公开行情接口的使用方式见 [Binance USD-M 行情文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)。

2026-10-30 的一次只读预检读取了之前暂存的 BTC/ETH 历史数据。公开服务器时间请求及两币 K 线请求各一次，均返回 HTTP 200；两币基线最后一根与返回数据的 OHLC、成交量及成交额核对一致，每币追加 35 根已收盘 K 线。两币最终一根的**开盘时间**均为 `2026-10-30T04:55:00Z`，本机保存回执为 `2026-10-30T05:03:57.980362Z`。这只是当时的快照，不是当前行情或持续覆盖证明。

当次三日扫描两币候选均为 0；原扫描的 `validation_status` 仍是 **INVALID**，不能据此声称策略通过。扫描、回执及归档均保存在 `data/verify/one-shot-preflight-20261030-01/`。随后对保存的原始响应和文件进行另一段核对：逐行比较新增数据与公开响应，确认原 CSV 前缀保留、收盘时间对齐，以及归档恢复后的两币文件与输出逐字节一致。该核对复用了项目的 OHLC 与归档读取代码，不能称为完全独立实现；所有文件和头部仍位于本机，不是独立来源或外部锚。

随后收紧了时间戳和数值字符串校验，拒绝非整数时间戳及包含换行等非规范字符的数值；使用已保存的同一组响应和当前代码在本地重建，两币各 35 根的解压后 CSV 与预检输出一致。该重建没有再次请求行情，也复用生产代码，不是独立来源验证。

合成测试另覆盖未收盘过滤、原尾根修订、行情缺口、时钟偏差、接口拒绝、不重复覆盖、无新数据，以及归档发布前模拟中断后先核对已发布头部再恢复。测试中的模拟接口和扫描不是实际前瞻；不能由一次预检推断后续连续运行、盘口捕获、止损执行或账户成本。

该运行没有产生正式纸面起点、信号决定、仓位或订单，也没有启动/停止平台策略。实际交易所、手续费档位、保证金和真实成交仍 UNKNOWN。
