# 2025Q3：BTC 大背景与五币短期参与分歧

## 核心发现

2025 年第三季度对前一轮的“BTC 大背景仍向上、较长期参与较高，但短期参与下降”候选给出了**双向结果**：相同候选条件下，有些观察点之后七天 BTC 收盘较低，也有观察点较高；不能把它当作确定转弱或入场信号。即使短期和较长期参与均高，也出现了随后一周 BTC 下跌的情况。

这一候选受已看过的 2026 年 1 月案例启发；2025 年价格也曾被项目研究，时间选择、五币和假设均非盲态独立样本。它不是浪浪本人规则、不验证真实阶段、不支持真实交易或盈亏结论。

## 条件与完整覆盖

按[组合计算前写入的定义](浪浪周期广度-2025短期分歧候选事前定义-20261105.md)，2025-07-01 至 09-30 共 92 个 UTC 日点；BTC 大背景是之前项目的 56 日双半窗口研究代理，Bitstamp、Bitfinex BTC/USD 现货各自计算；非 BTC 参与是 Binance BTC 之外固定存量五个 USDT-M 永续合约的方向计数。五币按以前已知覆盖而选择，含选择与幸存者偏差，不能代表历史全市场或浪浪名单。

每个 t 前 29 个完整日线均有效时，统计五币最近 7 日及 28 日收盘相对更早收盘的上涨数。**分歧候选**是 BTC 56 日研究窗口向上、28 日上涨为 4–5/5、7 日上涨为 0–3/5；**同向参与对照**是相同 BTC/28 日条件且 7 日上涨为 4–5/5。阈值是本次研究假设，不是阶段、真实情绪或交易规则。其余数据有效但不符合条件标 OTHER，数据不足标 UNKNOWN。BTC 与合约不同产品，不拼价。

两个 BTC 交易所在这 92 个日点的分组数相同：分歧候选 **14 日**、同向参与对照 **6 日**、其他 **72 日**、UNKNOWN **0 日**。分歧的 14 日中有 13 日连续，不能当作 14 次独立验证；全部相邻日和 7/28 天后续窗口也高度重叠。

## 核验及保留事项

五个合约的 2025-06-02 至 09-30 公共 1 日 API 响应各 121 根，与本地 OHLC 和成交量逐时间戳一致；响应、请求和哈希保存于[核验摘要](../data/verify/cycle-breadth-disagreement-2025q3-20261105-01/summary.json)对应目录。另使用原 API 响应独立核对 **460 个合约/观察日**的 7/28 日变化；从两所原 4h 价格重算 184 条 BTC 背景和分组、368 项 7/28 日后续收盘变化，一致。BTC 背景重算复用了原研究的 `asof` 函数，只是输入一致性检查，不是背景算法独立实现。输入通过技术核验不代表交易所原始成交或全市场情绪得到证实。
