# 已确认摆低回退：2014 二季度事前研究定义

目标修复支撑研究中最新摆低直到当前完成日结束才确认、因而原算法 WAIT_CONFIRM 时，仍可能存在更早已确认摆低却被忽略的问题。仅研究 BTC/USD 现货春秋背景、支撑和价格事件，不选币、入场、交易或平台策略 start/stop。摆点、窗口、支撑及真假突破代理均为研究假设，不是浪浪本人确认的量化规则；真实阶段与情绪 UNKNOWN。

## 事前固定回退和时序

沿用 [已冻结摆低定义](上升背景回调支撑-2019四季度事前定义-20261103.md) 和 56/28/8 日背景、已完成日 D 相对排除 D 的 28 日区间、7/28 日事件。UTC 判断时 t 为午夜，D=[t-1d,t)。旧算法首先以截至 t 的 56 个完整日判断最新确认摆低；如这个摆低确认时间晚于 D 开始，会标 WAIT_CONFIRM，因为不能将它当成 D 开始时已知。

新算法只在旧状态为 WAIT_CONFIRM 时，以 D 开始的时刻 t-1d 为截至时间重新运行完全相同的 56 日确认摆点算法（左右各 2 日，严格高低且同日双摆点不取，至少两个摆高和两个摆低，否则 UNKNOWN）；因此回退实际需要最早 t-57d 的完整行情。选择该时刻已确认的最新摆低与自身确认时刻，再用旧支撑函数检查其确认后至 D 前历史是否失守，并检查 D 收盘相对该低点的位置。如任何必要历史缺失、价格无效、旧摆点不足或确认后历史不可查，则 UNKNOWN，不默认原摆点有效；若较早摆低本身已被收盘跌破，仍如实记录 PRIOR_BROKEN，不把它叫完好。旧状态非 WAIT_CONFIRM 的点必须原样保留，包括 UNKNOWN；不在所有日期另换支撑，不修改原代码或平台。

该回退只恢复当时可知的价格事实，并非证明这是浪浪的关键支撑或“修复成功”的阶段预测。回退窗口与截至 t 的旧窗口错开一日，可能纳入更早的一天；保留两个窗口边界、原/新摆低及可知时间，并在报告揭示。所有日期按旧状态和回退后状态配对，统计原 WAIT 中的可计算、仍未知及跨所分歧，所有未触发和非重点日期保留。两所各自独立判断，不做跨所补价。

若回退有效，按 2019 原口径冻结所选摆低并检查 t 后 7 个完整日首次日收严格穿越或收回、及后 7/28 日收盘变化；等于边界不算；先缺失才发生的事件 UNKNOWN，已发生事件不因后续缺失抹去。未来仅供事后描述；收回不是已证实假突破，非触发后变化不是已证实真实漏判；相邻观察和两所相关，不计算独立成功率。

## 新时期及验收

在读取本轮区间与回退计算结果前固定 2014-04-14 至 05-31 每日 UTC 00:00 共 48 点，行情为 [2014-02-16,2014-07-01)，分别取 Bitstamp BTC/USD 4h 和 Bitfinex BTC/USD 1h 自身聚合 4h，包含 57 日预热与 28 日后续。选择 04-14 起是为了避开前次已知 2014-02-10 跨所异常对 57 日预热的影响，属于按已知数据质量选段，不是随机样本；不能根据本轮结果另换日期。此前 2014 年一季度实验使用部分四月后续，2014 年六月后的研究使用四五月预热；虽未发现本次逐日点用于本次回退规则设计，也不能排除间接接触、选择偏差或历史知识，不称严格盲测、绝对无污染或前瞻。

检查时间网格、OHLC、缺口及同 4h 高/低比 >1.1 或 <0.9 跨所质量警报。问题柱所在完整 UTC 日、依赖该日的旧/新输入及后续留 UNKNOWN；无警报不是逐笔成交认证。分别保存原始响应和哈希，绝不跨所补价。任一阶段或人工依据不明留空，不凭未来涨跌填标签。

独立从原 4h 复算所有时点的历史摆点、回退确认时刻、支撑位置和失守、回退后 7 日事件及双所结果；分别复核旧固定层和 1h 聚合。合成测试覆盖最新摆低当日才确认、合格旧摆低、旧摆低先前失守、找不到旧摆低、窗口边界、缺柱、等值及未来扰动。此前已看过的 2020-05-13 可作为修复动机的事后开发案例，不作独立验证；缺未参与规则设计者的独立人类阶段参考时，真实漏判率、假突破率、准确率仍 UNKNOWN。
