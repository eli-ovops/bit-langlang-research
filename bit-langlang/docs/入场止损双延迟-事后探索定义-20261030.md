# 入场与止损双延迟：事后历史情景定义

已有研究分别考察额外 5 分钟入场和触损后下一根开盘退出；此处在已看过它们的同一段历史上，描述两种延迟共同出现时的假设效果。不是独立样本外，不把结果当作真实盘口或成交。

冻结 ETH 信号与 BTC/ETH 原行情和 ETH 资金费；UTC `[2024-07-01,2026-10-25)`，四组各自以 2,000 USDT 空仓开始。入场为下一根开盘或再晚一根开盘（不重新验证信号）；止损以成交价 K 线最低价代理触发，按同根假设止损价或下一根开盘退出。两者形成 2×2 情景，其他参数统一：每边手续费 5bp、滑点 2bp、既有保证金和清算代理。延迟执行期间可继续发生浮亏；末尾未平仓以末根收盘标记，不强制平仓。

记录每组候选、平仓/未平仓、权益、收盘回撤、费用、资金费、清算代理，保存逐笔账与哈希。检查候选总量与平仓/持仓/跳过的数量平衡，并独立复核逐笔净损益与权益；原始和单一延迟情景核对已有研究口径。不同情景因资金及并发限制可能出现不同交易，不将收益差解释为逐笔因果效果。入场、止损与实际盘口方案不等价；下一根开盘可能优于或劣于实际成交，并非损失上限。任何资金、费用、滑点、触发与强平条件均为模拟，不能声称交易所验证或修改冻结策略。
