# 批量对账与未平仓盘口会话联检定义

在现有批量账本对账中，可选引入已保存公开盘口会话，复用未平仓盘口事件终态检查；入场信号、事件、报价和账本仍须通过原有共同事件对账。每份会话按原始消息、归档、快照、时序和盘口形式核对；不自动捕获、不下单、不控制平台。

同一批次可同时有单次报价资料和盘口会话资料：若任一有效渠道观察到未平仓触损，批次标 STOP，同时保留另一渠道 INVALID 和缺口；若没有已知触损但任一渠道明确无效，则 INVALID。未提供盘口会话不得视为完整观察。已平仓净 R 在联合风险的已平仓报告中保留；STOP 是纸面检查状态，不触发平台操作。无未平仓而提供盘口会话为 INVALID，不能将无记录等同账户空仓。

盘口事件仅核对终态及本机时间，真实信号、行情来源、批内价格、全部会话起止及真实执行、资金费和强平均 UNKNOWN。合成测试需覆盖已有信号→纸面入场→一笔平仓、一笔未平仓→会话触损，冲突优先级、空/坏文件和命令行输入；模拟数据不得当作正式前瞻。
