# 用户指定的重点观察币池

用户于 2026-10-31 指定 PEPE、UNI、SOL、HYPE、AAVE、SKY、ENA、LINK、LIT 作为本轮表现较强的参考币。去重后 9 个。LIT 按用户既有确认指 Lighter Protocol，不能与旧 Litentry 直接拼接。PEPE 与 `1000PEPE` 行情的合约面值及价格换算须逐笔核对；HYPE、SKY 的确切项目/交易所/合约映射和可用历史以原始数据核实，未核实时为 UNKNOWN。

用户的币池属于事后指定，作为研究参考，不证明在 2025-10 起每个时点均被事先选出或强于市场。回测应披露事后选币偏差，并另外构造当时可获得数据的动态选币对照；不得将事后币池当作实时全市场排名或独立样本。

## 现有历史交割资料的直接覆盖

以 `data/processed/trades_clean.csv` 原始清洗记录行计（不等于合并仓位，不认证交易者身份或真实订单）：PEPE 255 行，SOL 107 行，UNI 23 行，LINK 25 行，AAVE 4 行，共 414 行；现有表未见 HYPE、SKY、ENA、LIT 对应代码记录。已有历史十币面板中 `1000PEPE` 有 230 条合并仓位，SOL 有 106 条；UNI/AAVE/LINK 的历史逐笔对照另有资料，但不在该十币面板内。未知止损和止盈委托不得由平仓记录反推。

下一步研究优先使用可对应的原始交割记录与当时行情复核实际入场、持仓和退出；对没有交割记录的币只可做明确假设下的候选策略检验，不得声称复刻了浪浪本人。对不同币的上币时间、交易所、数据完整性、点值与资金费用单独核对。任何平台策略 start/stop 之前先告知用户。
