# 盘口有限深度重建：离线验证结果

新增 `python3 -m verify.depth_book_replay --trace <已有JSON>`，在序号检查通过的前缀内按十进制数量更新本地有限深度；数量为零删除价位。若链条断裂，停止在已核验的前缀并报告 GAP；若已观察到研究阈值触及，后续异常不会抹去之前的结果。

买一跌到初始快照所覆盖深度之外、卖一涨到覆盖深度之外，或某侧价位耗尽时，相应价格标 UNKNOWN；无效价量、重复快照价位或交叉盘口标 INVALID。输入和定义文件记录 SHA-256。重建规则与输入格式见[事前定义](盘口有限深度重建-离线定义-20261030.md)。

盘口重建和序号检查的 6 项合成测试通过，覆盖删除、替换、有限深度耗尽、阈值、断链、异常数据与命令行哈希。尚未使用真实 WebSocket 数据；同批增量内部价格路径、快照与消息来源、真实盘口、持仓关联、成交及前后完整覆盖均为 UNKNOWN。即便离线输出 `PARTIAL_BOOK_UNVERIFIED`，也不能证明没有漏触损或启动正式纸面前瞻。未启动或停止平台策略。
