# 成本与盈利能力：历史表述勘误

旧文档将“0.4% 止损、20bp 往返成本，成本约 0.5R”直接推断为“必亏”，并称 0.52–0.84R 的成本不可能被任何优势覆盖。这些是错误的绝对判断；成本相对初始风险的比例本身不能决定期望收益。

反例仅用于数学说明：假设每次毛盈利为 +3R 的概率是 40%，毛亏损为 -1R 的概率是 60%，且每次另扣固定成本 0.5R，那么假设平均净收益为 `0.4×3 + 0.6×(-1) - 0.5 = +0.1R`。该构造不代表本项目或实际交易能达到这些概率与价格；实际费用、资金费、滑点和损失分布仍需验证。

旧文档中“成本不超过 0.2R”可以作为研究者自己选择的风险或筛选约束，不能说成盈利的数学必要条件。固定费用或成本比例亦不保证亏损有上限，跳空、强平和其他费用另计。
