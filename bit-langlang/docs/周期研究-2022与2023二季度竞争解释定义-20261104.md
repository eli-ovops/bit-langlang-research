# BTC周期：2022、2023 二季度竞争解释研究定义

固定 [2022-04-01,2022-07-01) 与 [2023-04-01,2023-07-01) UTC 自然季度所有日点、每7日连续分段，最后不足7日截断。2022 使用原有 Bitstamp 与 Bitfinex BTC/USD 现货；2023 使用原有 Binance 与 KuCoin BTC/USDT 现货，不跨交易所或报价币拼接。此前两段在本项目分别用于其他研究，2023春秋逐周案例已被看到；本轮是事后复盘和方法探索，不能声称未参与设计、独立样本外或盲测。

沿用此前 56日、28日、8日两半高低窗口结构；判断只使用当时完整K线。前28日高低及前一日收作为可复核价格参考；这些窗口和“四季”映射是研究工具，不是浪浪原始公式。保留所有日点和分段、各所输入及分歧；量、情绪、广度、真实阶段、真人标签未知时标 UNKNOWN。

在不使用后续资料的情况下，记录竞争解释的可见依据：长期 DOWN 与短期 UP 表示“下行背景里短期上行”，既可能是反弹也可能转强，阶段 UNKNOWN；长期 UP 与短期 DOWN 表示“上行背景里短期下行”，可能是正常回调也可能转弱，阶段 UNKNOWN；其余按事实描述但不硬塞分类。边界高低、距位置及结构持续不能单独证明启动或衰退。对每段将完整段内的首次严格日收突破当时固定28日上下沿、是否在该段结束前收回另列为后续事实；同时追踪观察点之后28个完整日的该固定边界首次越界及其后7个完整日收是否返回，时间顺序和信息可见时间分开，发生缺口标 UNKNOWN。后续不能倒填相位、返回不等于真实假突破，未触发不等于真实漏判；相邻样本重叠，不算独立事件。

检查各所自身原始网格、OHLC、相同时间高低极值差 >10% 的警报及输入哈希；2022 来源保留量及小时最低量并检验正数，2023 项目既有标准4h文件不包含量，标 volume UNKNOWN 不伪造零或通过。若数据异常标受影响窗口 UNKNOWN；不宣称时间网格证明成交真实性。验证所有段未来K线扰动不改变 as-of 事实；抽查并复核事件时点及延迟。作为 BTC 背景研究，不选币、入场、交易，也不执行任何代理 start/stop。
