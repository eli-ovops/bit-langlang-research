# 公开盘口采样进程中断与重建：单次预检定义

目的：在无持仓、无账户连接的公开预检中，真实强制终止本次创建的采样进程，检查逐条归档是否保留可校验前缀，并在单独新会话中重新获取快照和增量。只杀本测试拥有的子进程，不启动或停止平台策略；不是自动交易或正式前瞻。

第一段运行现有 `depth_capture_preflight --journal`，首次快照文件存在且至少有 20 条事件文件后立即发送 SIGKILL；最长等待 7 秒。如果在人为终止前网络拒绝、异常退出、超时或未达到条件，停止，不运行第二段或绕过失败。记录可校验前缀、是否有半写入、保存的原始快照哈希；未封存绝不能当作完整会话。如果归档整体 INVALID，只保留检查器确认的前缀，不自动修改或删除残留文件。

第二段为新目录、新进程和新连接，限 8 秒或 500 条、一次公开快照，仅在第一段确实被本测试进程强制终止且有有效前缀和可读快照后执行；不是对网络失败自动重试。两段都只在本机保存本次实际收到的消息，记录最后可校验消息与新会话首条消息的时间差，并标 `UNKNOWN_UNOBSERVED`。第二段必须独立执行快照桥接和序号/盘口检查，不能复用第一段订单簿假装连续。

本机时间、来源及外部锚点未知；进程 SIGKILL 不是系统断电或实际网络中断，重新运行一个采样进程不是后台自动重连。文件和摘要使用新目录、独占写入。该预检不证明无漏包、批内价格、真实止损或成交，绝不产生纸面交易。
