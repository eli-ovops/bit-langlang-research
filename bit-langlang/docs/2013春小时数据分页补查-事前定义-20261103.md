# 2013 春候选：Bitfinex 小时行情补查事前定义

原定 [候选筛查](双所完整支撑对照-2013春事前筛查-20261103.md) 请求 2013-01-15 至 07-01 的 Bitfinex 1h，返回原始小时首条为 2013-03-31 23:00，虽然此前该所 4h 响应在 2013-01 有少量记录。现有大区间请求为何未返回此前小时 UNKNOWN；不得直接推断早期无小时行情。为核查潜在的范围/分页问题，在获取新响应之前固定按 UTC 月边界分四个连续范围：[2013-01-15,2013-02-01)、[02-01,03-01)、[03-01,04-01)、[04-01,07-01)，均为同一官方 1h 接口、limit=10000、sort=1；保存每个原始响应、请求、时间和哈希，不用其他交易所补价。对返回各自范围严格检查、重复时间去重仅允许相同 OHLCV，任何冲突整根保留 UNKNOWN。四小时必须由四个连续、各自有效的小时聚合；缺失不补、保留全部缺口。

以分段结果形成单独新快照，不覆盖先前大区间响应、原研究或预注册。比较相同 1h、4h 重叠值并记录差异，任何不一致不得自动选择更好数据；再按原候选样本和预先固定质量口径重新评估各时点及 57 日日线窗口。若未补齐或出现警报，按受影响窗口 UNKNOWN；不得因补查后结果选择只报好日期。此动作是同一交易所请求分段核查，不是两所混价。2013 历史及部分输入早已被其他项目研究接触，补查不使其成为无污染盲测。无独立真人阶段参考时，仍不能验证真实阶段、漏判或假突破。
