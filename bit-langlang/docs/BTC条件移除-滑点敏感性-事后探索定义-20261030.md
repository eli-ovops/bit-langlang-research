# BTC 条件移除：滑点敏感性事后定义

在已知 BTC 风险开启条件移除结果后，检查研究结论对假设滑点的敏感性，而非寻找最优参数。两个固定信号版本为原 ETH 冻结规则与仅移除 BTC 风险开启条件的候选；两个已有窗口为 2025-10-01 至 2026-10-25 和 2024-07-01 至 2026-10-25（UTC 左闭右开），各自从 2000 USDT 空仓起算。所有窗口与部分结果已看过，因此本分析是事后探索，不是独立样本外。

单边手续费均假设 5bp；每边额外不利滑点分别取 0、2、5bp，按成交价格计入，不重复扣除；资金费按现有研究数据和价格代理计入。0bp 仅作为理论下界假设，不代表真实可成交价格。其余入场、止损、风险、持仓容量、资金费与强平代理全部不变；每个场景独立动态重放。记录平仓、未平仓、期末权益、5 分钟收盘权益回撤、费用及资金费，逐笔勾稽，2bp 场景须与先前消融结果完全对齐。

不同滑点可能改变止损触发、仓位、现金和后续信号容量，不能将静态交易净收益直接相减解释为因果影响。实际点差、价格冲击、手续费档位、资金费和强平费用 UNKNOWN，历史 K 线价格相对买卖报价的位置未知；未来成本分布与收益亦未知。结果不作为变更冻结策略、启用平台策略或真实交易的依据。
