# 2011 年一季度候选：区间与质量审查预定义

在请求该候选的价格、交易、覆盖结果或观察模型输出前，预先选择 BTC/USD 现货 [2011-01-01, 2011-04-01) UTC 的全部 90 个每日观察点，数据需求为 [2010-10-09, 2011-04-29)，分别满足前 84 个完整日、季度和最后点的后续观察。按自然季度选取，不以实际信号或涨跌选取；选择较早年度是因为近年历史已反复接触。用户要求历史完整，任何该段缺失应记录，不通过选取有数据的子段掩盖。

本地定向检索 docs/verify 仅见 2011 年 11–12 月作为 2012 检验预热，未发现本季度直接用于项目规则设计；检索有范围限制，不能证明未间接接触、研究者或模型无历史知识。当前选择发生在此前多个已见样本之后，存在自适应选择，不能声称独立盲测、前瞻或无条件样本外。

人工判断标准固定为 [独立判读方案](周期研究-独立判读与留出检验方案-20261105.md)，包括 84 完整日和最近 28 完整日的图、无未来及信号、两名未参与设计的人独立标签、UNKNOWN 与分歧保留。该方案先于本候选选择。按既有方法保留全部日点，使用同一研究版本 56/28/8、84 日及确认摆点；如数据未通过，不制作看似完整的结论，不把缺失柱填为前收。季节与浪浪真实规则不由程序推断。两个独立人类评审、预测映射、可用行情均尚未获得。

计划先核对公开 Mt. Gox BTC/USD 历史可用性及授权与来源说明，候选数据商 Coin Metrics 公开 API；原交易所已经结束运营，第三方整理非交易所原始响应。先只做数据可用性和 OHLCV 时间网格核查，不看价格走势和未来事件，也不计算阶段信号；任何需要付费的获取不执行。每条来源保存公开请求及哈希、不跨所补价。每根 4h 若无成交、缺失或无效，相关时点及依赖窗口标 UNKNOWN；OHLC 成立、成交量正值也不证明数据可靠。若源不可访问、无权限或没有全期完整交易，原样记录失败，不根据结果替换区间，不能称已完成完整历史验证。若完整性成立、再准备只含当时信息的匿名审阅包；没有独立评审不称人工验证，也不估计真实漏判、误判或盈利能力。

**注意**：2011 年代交易基础设施及市场结构与当前大不相同，单一交易所和第三方数据不代表总体市场，也不可证明可迁移；不获取有个人信息的泄露账户数据库。本轮无选币、入场、交易或平台 start/stop。
