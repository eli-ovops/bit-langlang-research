# 同期文章时差影响核查口径

冻结原来两季度 26 个全部周观察及其已匹配文章，在查看本轮计算结果前固定本核查：有文章的周点从官方页面 `article:published_time` 所在 UTC 日的**次日 00:00**作为保守基准，取该时刻刚结束的日线收盘；取项目周点前最后完整日收作为终点。使用保存的 Bitstamp BTC/USD 4h 自身数据，每日必须六柱完整、OHLC 与量有效；区间任何日缺失则该周点价格变化 UNKNOWN。记录绝对与百分比变化、区间日内高低、持续完整日数；无匹配文章的两点保留 UNKNOWN。只描述文章发表日结束以后至周点的价格，不代表文章准确性、方向预测、市场情绪或阶段真值。

发表时间为当前页面元数据声称，虽早于该保守基准但不能单凭它认证历史正文；对保存的观察前存档状态另列。被研究者接触过的 2023Q1 和 2025Q2 是污染历史；时间差及案例选择不构成独立留出、独立评审或准确率检验。输出不得读取或合并既有回踩信号、未来价格，不据此决定选币或入场；阶段、真实情绪和浪浪同期判断均 UNKNOWN。目标是量化旧文章可能过期的尺度，并识别不能直接拿旧文章给后续周点贴标签的实例。
