# 双季度同期市场列表预定口径

沿用此前固定的 2023Q1、2025Q2 各 13 个周观察，不按行情、回踩事件或结果选点；这些历史、A01 价格和 A01 市场列表均已被研究，不是未参与设计的留出。目标是检查能否对全部周点获取第三方历史市场快照及其覆盖，不计算阶段准确率或制定交易信号。

对于每个 UTC 观察点，查询 CoinGecko 官方首页在**此前完整 UTC 日**的公共存档 CDX，选择状态 200 的最早抓取，若时间晚于观察点、响应或 Memento 与选定值不一致、页面表头/排名不符合要求、前 30 行显示缺失，均分别 UNKNOWN，不换时点补成功。重复使用已验 A01 存档，但重新核查 CDX 和 Memento。其余请求逐个正常 TLS 串行，记录实际状态和原响应；遇网络或访问失败停止后续联网，未尝试行保留 UNKNOWN。

各有效页只取原页面排名前30行显示的“7d”涨跌，统计显示为正、负、零和缺失，不按资产挑选、不排除稳定币或包装资产，不做选币。必须核查排名顺序、页面表头与 30 行的原始显示；CSS 导致不同类型的表解析失败即 UNKNOWN。记录数据采集时间 UNKNOWN；存档抓取时间、价格数据截止、观察点是三个不同概念。该集合是大市值排行样本，不是全市场广度或实时情绪。季节、浪浪同期判断均 UNKNOWN；该百分比不是策略或胜率。
