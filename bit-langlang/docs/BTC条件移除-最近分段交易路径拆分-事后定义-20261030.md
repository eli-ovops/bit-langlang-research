# BTC 条件移除：最近分段交易路径事后拆分定义

以已有 2025-10-01 至 2026-10-25 两份独立重放的已平仓 ETH 账本为对象，按 UTC 入场时间将交易分成两组共有、仅原规则和仅移除 BTC 条件。每组分别报告数量、模拟净盈亏和出场原因；对移除条件组额外核对信号 K 线时刻的上一日 BTC 风险开启状态，区分条件关闭时与开启时被该路径选中的交易。既有结果、样本及此比较目的已经被观察，因此是事后描述，不是事前注册或独立样本外。

信号 K 线时间为模拟入场前 5 分钟；按原行情和当前信号代码重建上一日 BTC 条件，核对输入哈希、时间网格、入场时间唯一与信号实际符合对应规则。资金、数量及容量各自随路径变化，即使入场时间相同也可能有不同仓位与后续结果；各组净盈亏仅描述已实现的模拟账面分量，不应把仅候选组直接称作移除过滤器的因果损益，更不能静态相减当成无该组的重放。

统计净盈利/亏损笔数、出场原因、毛盈亏、手续费与带符号资金费。滑点已经体现在入出场价中，不再扣一次。记录原始文件哈希及每组金额和全样本勾稽；5 分钟收盘回撤、逐仓强平和成交均为代理，实际成本和账户 UNKNOWN。不据此修改策略或执行订单。
