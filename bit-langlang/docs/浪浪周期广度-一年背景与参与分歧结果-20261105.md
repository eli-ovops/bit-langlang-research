# 一年背景、空间与参与分歧：已见案例对照

## 结论

给 BTC 加上更大时间范围后，先前看似相同的“56 日研究背景向上、较长期样本参与高而短期参与减弱”出现了明显位置差异：**2023-11-17，BTC 永续最近日收处于此前一年价格范围的约 90% 位置；2026-01-16 则约为 41%，距此前一年高点约 24%。**两者在这套研究条件下之后出现不同走势，因此仅看“方向向上”会丢掉重要的大级别位置和此前回撤信息。

不过，2025-08-05 在同一方法下也处于一年范围约 89% 的位置，此后 28 日现货收盘仍低于观察时约 5.05%。**位置差异值得继续研究，但不能把接近一年高点或范围百分比当作已经验证的主升、启动或交易规则。**
