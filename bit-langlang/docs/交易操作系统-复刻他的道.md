## 1. 三条世界观（他所有动作的源头）

1. **市场是周期的，不是随机的，也不是可预测的。**
   震荡 → 震荡中期 → 震荡末期 → 主跌/主升 → 主升中期 → 主升后期 → 转震荡 →（二波/更大级别震荡），周而复始。
   对应四季：春（启动）→ 夏（主升，找龙头）→ 秋（补涨，难做）→ 冬（熄火，休息）。
2. **只赚"空间"里的钱。**
   没有上方空间（到阻力 < 3R）就不做；利润来自少数 5%+ 空间的大单，短线小空间扣费后是亏的。
3. **概率游戏：胜率 40% + 盈亏比 3 倍即可活。**
   所以重点不是"看对"，而是：**错的时候亏得少、对的时候拿得住、并且一直活着。**

## 2. 交易对象与边界（先做减法）

**做**：
- 只做**多**（复刻版先只做多；他的空单是进阶项）；
- 只做**龙头**：BTC/ETH 定环境，山寨只做当前最强、日线结构好、跟涨过、抗跌的 1–3 个（他盯 4–8 个，新手减半）；
- 只做**流动性好**的币（盘口浅的币，重仓会被自己砸穿）。

**不做（红线）**：
- 不做逆势单、不摸顶、不抄底；
- 不补仓、不摊平、不加仓、不滚仓、不做马丁；
- 不用高杠杆（BTC ≤10×、山寨 ≤5×，新手再减半）；
- 不跟单、不代单、不熬夜盯盘。

## 3. 盘前流程（每天 30 分钟，收盘后做）

1. **看季节**：BTC 日线——在 EMA50 上方？EMA50 向上？在 EMA200 上方？最近 20 日波动率分位？
   - 春/夏：允许开仓；秋：只减不加；冬：**今天不看盘、不开仓**。
2. **选标的**：热度榜 + 次新 + 相对强度，选出 1–3 个（最多 8 个）放入自选。
3. **写交易计划**（每个标的 5 行）：
   ```
   标的：____   方向：多
   季节判断：春/夏/秋/冬
   关键位：支撑 ____ / 阻力 ____ / 无效位 ____
   空间：到阻力 ____%，≥3R？ 是/否
   计划：入场区 ____，止损 ____，T1 ____，仓位 ____
   ```
4. **设警报**：关键位设价格提醒（他的原话：用警报代替盯盘）。**没有警报就不看盘。**

## 4. 盘中流程（只在警报响后执行）

### 4.1 开仓五问闸门（全"是"才下单）

1. 现在是春/夏吗？（秋/冬 → 不做）
2. 上方空间 ≥3R 吗？（<3R → 不做）
3. 位置是三类之一吗？——① 箱体突破回踩；② 第一次小分歧承接；④ 大分歧后二波回踩。（箱体内部、逆势、追高 → 不做）
4. 止损放哪？——5 分钟级别拐点/最近高低点下方，且单笔亏损 ≤ 该份资金的 10%（账户口径 ≤1–1.5%）。
5. 这笔亏了，我明天还会按同样规则做吗？（不会 → 不做）

### 4.2 执行细节（他的原话）

- **开仓必带止损，开单前就挂好**；止损用**标记价格**触发（防插针）。
- **能市价就市价**；一次打满该份仓位，不分批开。
- 入场后：**没触发止损，不因情绪提前下车**。
- T1（约 2–3R 或第一压力位）减半，剩余止损推到成本；剩余用 5m 摆动低点跟踪。
- 卖出：到阻力/整数位分批；"不要太格局"只适用于箱体/逆势单。

### 4.3 盘中禁令（触发任何一条，当天停手）

- 改止损、撤止损、扛单；
- 补仓、摊平、加仓；
- 反手（亏了立刻反向开）；
- 连续开 3 单以上不休息；
- 盯盘超过 2 小时。

## 5. 盘后流程（每天 20 分钟，必须做）

每笔交易记录 8 项：`日期/标的/方向/入场/止损/出场/仓位/理由`，再加 3 个复盘字段：

| 字段 | 取值 |
|---|---|
| 体系内亏损 | 有逻辑、按纪律、仍止损 → **接受，重复做** |
| 逻辑错误 | 无逻辑、逆势、箱体内、追高 → **从开仓条件里删掉这类** |
| 纪律错误 | 改止损、补仓、提前砍、反手、超仓 → **用机制约束（分仓/停机/不盯盘）** |

**每周一次复盘**：把同类结构摆在一起，问"如果重来，我会不会做同样的单？"——会，就是对的；不会，就改规则。

## 6. 纪律机制：把人性关进系统

| 机制 | 具体做法 | 目的 |
|---|---|---|
| **分仓** | 资金分 3 份，只把 1 份放合约账户 | 爆仓也只爆 1/3 |
| **固定仓位** | 每笔固定名义（如 1 份 = 1 万 U 的 1/3） | 心态平稳 |
| **利润提走** | 赚了提出去，亏了补回来 | 保持固定仓位、不复利 |
| **单笔风险上限** | 账户 0.5%–1.5%（按你的承受力） | 连亏 10 次也不死 |
| **连亏停机** | 连亏 8–10 笔 → 停 1–3 天，只复盘 | 防上头 |
| **单日/单周亏损上限** | 日 -5% / 周 -10% → 停手 | 防连续犯错 |
| **关机规则** | 心态乱、连续止损、错过行情 → 关电脑 | 他的原话："关机，离开盘面" |
| **不盯盘** | 只靠警报；每天看盘 ≤2 小时 | 防频繁交易 |

1. **不马后炮**："它出现了 100 次里的 10%，剩下 90% 呢？"
2. **不急于回本**："接受亏损，不要想着回本。"

4. **连续止损时问自己**："是否坚持了原则？坚持了，止损不一定是错。"

## 12. 验证协议（"能不能算复刻"的唯一标准）

> 规格 ≠ 验证。必须按顺序通过 4 关，任何一关不过，都不能说"复刻成功"。

| 关卡 | 做什么 | 通过标准 | 当前状态 |
|---|---|---|---|
| **V1 行为一致性** | 模拟盘/极小仓，按纪律卡执行 30–50 笔，逐笔记录 | 遵守率 ≥90%；五问完成率 100%；零逆势/补仓/马丁 | **未开始** |
| **V2 执行可行性** | 同一批单记录计划价 vs 实际成交价、滑点、错过率 | 滑点 ≤ 计划止损的 10%；错过率 ≤20%；每日盯盘 ≤2h | **未开始** |
| **V3 成本与期望** | 小资金 0.5% 风险跑 100 笔，统计扣费后每笔期望 | 净期望 ≥ −0.1R；若 < −0.2R，说明"只有纪律没有 edge=慢亏" | **未开始** |
| **V4 样本外 edge** | 用未来 3–6 个月的真实交易（不是历史回测） | 净期望 > 0，且不依赖单一笔/单一币 | **未开始** |

**判定规则**：
- V1/V2 是"行为复刻成功"；V3/V4 才是"策略有效"。
- **V1/V2 通过 ≠ 能赚钱**。他的钱来自规模+行情+尾部，纪律只保证"不死"。
- 任何一关失败：回到规格修改，**不要加资金**。

### 已知会导致 V3 失败的因素（必须提前认）

1. 他的入场 α≈0：按同样流程做，入场并不比随机好；
2. 出场 α +0.094%/笔，但可能是"平仓冲击"或手工执行优势，普通人难复制；
3. 手续费 5.7bp 是生死线：换手高、费率高的账户会直接把薄优势吃光；
4. 没有 2024-07 后的样本：今天是否还是"薄优势可放大"的市场，未知。
