# 历史市场广度资料：交易对目录检查

## 结论

历史资料里确实存在后续移除的交易对，因此从当前交易对清单直接反推过去的市场，会有遗漏风险；另一方面，交易对并不等于独立资产，同一资产可以有多个报价币种，直接数交易对又可能重复。两种偏差都不能靠此前固定的五个幸存合约样本解决。

一个事后选择的数据源验证例子：Binance [官方公告](https://www.binance.com/en/square/post/693476806441)列出 2023-12-15 停止 BTC/BUSD 等现货交易对；官网仍可取得该对 2023-02 的历史日 K 文件。本轮取得的 ZIP CRC 通过，含 28 个连续 UTC 日点，各日 OHLC 和量的基本一致性、正值通过，SHA-256 和原文件见[例子记录](../data/verify/cycle-historical-universe-20261109-01/example-summary.json)。这证明**一个已被公告移除的历史交易对仍有归档文件**，不证明该资产当时没有其他交易对，不证明所有退市对象均保留，也不能以单例推算完整市场广度。

## 阻断与下一步

[币安官网公开数据说明](https://github.com/binance/binance-public-data/blob/master/README.md)介绍按交易对和月度或日度保存的历史文件；官网首页提供的公开目录存储接口，本次按正常 TLS 访问时出现 `curl 35 SSL_ERROR_SYSCALL`，未获得 HTTP 状态，原因 UNKNOWN，已停止重试。首页本身和标准文件 URL 正常返回，不证明目录接口可用。故目前**没有取得完整历史对象列表，也没有获取可比的当时币池**；不把失败称作拒绝或数据不存在。

后续可在接口恢复时按固定时间和产品、计价币种枚举历史对象，记录所有日点的文件存在、质量、币与交易对映射和缺失，同时研究上市/退市与更名证据；但目录保留策略、未留档资产及历史更名仍须独立核实。样本归档存在不证明该日市场交易状态完整，市值加权及跨交易所代表性也需额外数据。

本检查只验证数据来源可能性。所引历史为既见案例，不是独立留出，不能验证阶段或浪浪盈利模式；情绪、全市场广度及阶段真值依旧 UNKNOWN。没有选币、设计入场、交易或执行平台 start/stop。
