# 盘口逐条归档与恢复：离线定义

问题：单次预检将消息留在内存，结束后才保存；进程或机器在结束前中断时不能依赖该文件。先以本地合成数据和已保存的真实公开样本验证独立归档模块，不启动采集、监控或平台策略。

新目录包含会话元数据和从 0 开始的逐条文件。每条文件独占创建，保存原始文本字节的 base64、其 SHA-256、给定的本机接收时间、前一条文件的 SHA-256 及本次会话哈希；单写者依次 fsync 文件和目录。检查器验证无缺号、每条原始文本哈希及链关系；独占 seal 文件包含条数、末哈希并同样 fsync。中断后没有有效 seal 必须标 `INCOMPLETE_UNSEALED`，不能声称观察完整；末尾被截断必须标 INVALID。若提供独立保存的期望末哈希或 seal 哈希可额外比对；没有外部锚点时哈希不能证明未整体伪造、截断或重写。

受损记录不自动跳过、不覆盖也不自动重连；单写者使用，不宣称多写者安全。落盘时间、fsync、消息先后与连续性均需真实采集验证；归档中记录本机时钟与网络来源未独立认证。完整 seal 也不代表真实连接期间无漏包或无止损，增量序号与本地订单簿需独立复核。

测试包括正常封存、未封存中断、截断、修改、缺号、seal 后拒绝追加，以及用前次真实公开样本离线逐条归档和回读哈希。真实采集时的性能、崩溃时点、断线重连与交易绑定尚未验证。
