# 近期走弱后重新越过高点：八个季度逐段对照

## 结论

在已研究的不同历史环境里，近期走弱之后，价格有时会重新以日收越过当时已形成的近期高点；但越过后有的持续在其上方，有的很快又收回。**重新越过近期高点提供了新的价格事实，不能单独证明这是真正启动或浪浪所说的主升。**

本轮还发现一个方法缺陷：所选“当前日收不高于此前 28 日高点”几乎是构造上的必然，因为此前 28 日包含最近已完成日线，而该日收盘不可能高于同一日的最高价。实际检查的 109 个段首全部符合这一项，因此它没有独立筛选出“回踩”；本轮所谓候选主要由“此前 7 日永续收盘下降”决定。**不能把这 50 个点称为已确认的回踩样本，更不能把这一条件说成浪浪规则。**

## 数据范围与已知局限

按[本轮定义](浪浪周期-八季度近期高点逐段对照定义-20261105.md)，使用 2022Q1、2022Q4、2023Q4、2024Q2、2024Q4、2025Q3、2025Q4、2026Q1 共八个完整自然季度，Bitstamp BTC/USD 现货，按季度起点每 7 日一个段首，末段不足 7 日截断，共 **109 个段首**。各季所有段首、非触发、后续不完整和已知缺口均保留；本轮是一所现货价格观察，不将其他所当成独立行情。

各季度和部分后续结果此前已被项目研究，且该次观察方法由已知 2023、2025 路径启发；这是**事后、适应性复盘，不是独立留出、阶段准确率或盈利验证**。此前 7/90 日变化来自 Binance BTCUSDT 永续日线；28 日高点来自 Bitstamp BTC/USD 现货。不同产品分别计算，不混拼价格。所有期限与条件是研究假设，不是浪浪原话；资金费只是有限代理，不等同真实心理或现货资金流。

对研究条件符合的段首，固定当时此前 28 个完整日现货最高价，观察此后最多 28 个完整日的日收是否严格高于该线；等于或低于不算上越。首次上越后，再看最多 7 个完整日收是否回到该线或下方。数据不足就留 UNKNOWN 或 INCOMPLETE；结果只在各自收盘后才知道。固定季度区域与新冻结的近期高点为不同参考，不能混用。

以下“后来发生”只在对应日线收盘时可知；每行背景和费率均是段首之前信息，90 日与 7 日变化来自永续，固定高点和后续价格来自现货。

2022、2023 两例长尺度代理不同，2025 年例子此前 90 日方向也不同；它们提示有必要并列观察大背景、空间、小尺度和情绪证据，但**样本是事后选择且其他变量同时变化，不能推断长周期或任一指标造成结果**。返回线内也不自动等于假突破或趋势结束；之后站在高点上方更不自动证明浪浪认可的启动。

## 对下一步研究的影响

可以把“近期高点在观察前已形成、其后是否被日收收复及是否回落”作为**按时间记录结构变化**的方法，但当前不能把它单独升级为识别反弹或真正启动的规则。本次第一个条件存在包含当日高点的冗余问题，且 7 日日收下降既可能极小，也并不保证实际回踩形成；如要提出更贴近结构的回踩定义，必须另开研究版本，明确已确认的参考高低与确认时间，不能修改本次口径后称已通过。

仍缺独立人工阶段参照及未参与设计的足够历史；所有时点真实阶段、浪浪本人同期判断和真实市场心理均为 UNKNOWN。后续 7/28 日方向只是后来发生的事实，不是阶段真值或复利结果。

## 核验与缺口
