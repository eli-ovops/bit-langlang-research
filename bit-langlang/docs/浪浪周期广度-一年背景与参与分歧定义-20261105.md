# 一年背景、空间和参与分歧：回顾性比较定义

在看过多个阶段、归档参与和候选反例后，进一步研究同一个“较长周期向上、短期参与减弱”的统计条件，是否发生在不同的更大级别位置。5 个观察月复用已保存的 2022-11、2023-11、2024-11、2025-08、2026-01 全部 152 个 UTC 日点，不看结果后改选月份或剔除失败。所选月份、BTC 后续和 7/28 日参与数据已知，是**事后归因**，不是独立样本外、无偏检验、浪浪本人同期判断或交易策略。

## 当时背景与空间

在每个 t 使用 BTCUSDT USD-M 永续 [t-365d,t) 的 365 个完整 UTC 日日线高、低、最近日收，且每根 OHLC、量正值、时间网格与去重通过；当时所在区间位置为 `(最近日收 - 窗口最低)/(窗口最高 - 窗口最低)`，到此前最高价的百分比距离、最高和最低出现的最近日期及其距 t 的天数分别保存。后者等于历史窗口极值，是可见的空间参考，不是已验证压力或支撑，也不是浪浪本人给定时间尺度。窗口缺失或价格不合法为 UNKNOWN；2022 月的必要背景可延伸至 2021 年，但实际观察月仍在近五年。

在该滚动 365 天内将前 182 天和后 183 天按完整日的高低比较，双高低抬高为 UP、双高低降低 DOWN、后半内包 INSIDE、其他 MIXED；仅为辅助描述，不代表大盘阶段。每个 t 的最近完成日收及窗口高低都必须在 t 之前结束，未来日期不得参与；不因之后价格高低重画早先范围。由于数据范围不同，这个年度背景是 Binance BTCUSDT 永续价格，原 56 日窗口和后续事实是 Bitstamp BTC/USD 现货，不可把相同价位数值相互替代或拼接。

## 参与与情绪代理

原 152 个归档参与候选与分类保持不变，不根据 365 日结果调整 80%/60% 阈值；BTC 永续过去 7 日的资金费率，要求 21 次独立 8 小时排程、实际时间严格早于 t、允许排程时间误差不超 60 秒；输出正负/均值。费率和归档合约价格参与均不等于真实情绪、买卖人数或资金流，归档不证明全市场或历史上币/退市完整；2023-11-10 六合约成交量归档/API 差异保留此前敏感性结果，不覆盖。

## 来源、验证与禁止

从 Binance 公开 USD-M BTCUSDT 1d 接口获取覆盖 2021-11 至 2026-01 的全部所需日日线，分段保存原请求、原响应和哈希，检查重复、时间、OHLC、正量；与本地重叠的 `BTCUSDT_1d.csv.gz` 逐时戳对账，差异或缺失单列，不能自动覆盖，缺口相关日 UNKNOWN。费率已有项目历史公共 API 原始响应，多期分别校验；本次只用本地已核对的费率数据并保留哈希。段时点全部价格/背景均独立于后续，分别附此前已保存的 7/28 日后续 BTC 日收变化；BTC 两所现货价格及归档比例来源和缺口另列。校验未来扰动、独立重算 365 日窗口、输出每日日点、UNKNOWN 和所有候选/非候选，不筛成功点。

结果最多支持分析这些已接触历史中的竞争解释，不能证明因果、真实阶段、命中率或盈利，也不据此选币、设计入场、交易或执行平台 start/stop。
