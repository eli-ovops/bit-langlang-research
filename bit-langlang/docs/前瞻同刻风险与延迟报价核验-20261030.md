# 前瞻同刻风险与延迟报价：核验记录

## 同刻入出场

旧计算把同一时间戳的退出都排在入场之前，仅给出较低的并发与初始价格风险；无法从时间戳证明实际顺序，因此不能据此确认限额没有触及。已平仓报告现在同时给出已记录交易的并发上下界和顺序不确定标志；联合已平/未平仓的风控还给出初始价格风险峰值上下界。下界已经超限返回 STOP；同刻顺序不明且无更高优先级问题返回 `AMBIGUOUS_ORDER`，同时注明并发上下界是否跨限额。持仓事件对账传播该不确定状态。

合成案例：三笔退出和另三笔入场同刻时，记录支持的最高并发为 3–6 笔、初始价格风险峰值为 2.4–4.8 USDT；下一秒入场可消除该处顺序歧义，提前一秒入场则确定并发超限。上述数值为合成测试，不是实际前瞻交易。价格风险不包括手续费、资金费、滑点、跳空、真实强平，也不覆盖漏记仓位。

## 延迟报价候选

新增 `verify.paper_delayed_signal_reconcile`，按 [事前定义](延迟报价入场-信号与账本对账-事前定义-20261030.md) 将快照重算信号、人工事件、账本、风控、公开一级报价和纸面保证金形式关联。独立的候选状态最多为 `PARTIAL_CANDIDATE_NOT_REGISTERED`；底层原执行模型依然是 `EXECUTION_MODEL_MISMATCH`。缺报价、复用一次报价、深度不足、缺纸面保证金或顺序/账本问题不能当作通过。

验证使用构造的行情和事件：包括单元逻辑、组合风控边界、原扫描及持仓事件链、入场报价和账本合成闭环、缺证据/风险边界以及命令行结果。合成报价与事件不是实际前瞻。历史盘口、连续采集、实时信号完整性、EMA/到期出场、费用完整性、真实交易所与账户依然未获证明；当前不能按该结果宣布已开始或准备完成正式前瞻。
