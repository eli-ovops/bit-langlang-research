# 固定区域与参与线索：2024Q2、2025Q4 全日对照

## 发现

2024-04-22 与 2025-11-12 两个已见时点，归档样本都出现“此前 7 日上涨的合约占多数、此前 28 日上涨的合约较少”，但 BTC 所在的大背景并不相同：前者现货位于其季度固定区间内，后者位于其固定区间下方；两者永续此前一年范围的位置也不同。这个现象值得作为**不同时间尺度的参与分歧**观察，却不能独自认定“震荡末期”“启动”或“主升”。

这两个日期和后续结果已经被项目看到，本次是事后解释；它们不能作为独立检验或归因证明。BTC、归档合约、费率来自不同产品和样本，归档样本组成也不同，不得把它们拼成真实资金流或市场心理。真正阶段、浪浪本人同期判断和真实情绪均 UNKNOWN。

## 完整范围和读取方法

按[本轮定义](浪浪周期-双季度区域参与全日对照定义-20261105.md)，全量记录 2024Q2 的 91 个和 2025Q4 的 92 个 UTC 日点，共 **183 个日点**；从季度起点每 7 日取段首，分别为 13 和 14 段，2025 末段 1 天。每段的数值均截至段首之前已完成数据，数据、区间和例子已被研究，非盲测或独立留出。

固定区间为各季度起点前 28 个完整日的 Bitstamp BTC/USD 现货高低：2024Q2 **59,313–73,794** 美元；2025Q4 **108,652–117,968** 美元。固定线贯穿该季度，不跨季度混拼；该时点之前新形成的较近 28 日范围另记。长/中/短是研究者的 56/28/8 日双半窗代理，不是浪浪公式或真实阶段。此前一年范围位置为 Binance BTCUSDT 永续最近完整日收在此前一年高低中的坐标，不是剩余空间；现货和永续不拼价。

下表“7 日上涨/28 日上涨/已知”是同一段首、同一批可核验 Binance USD-M 非 BTC 合约的两个观察窗口方向数量；不是唯一币数、全市场情绪或独立资金流。现有目录为当前归档快照，可能不含所有已退市品、包含倍数包装，且每日可用对象变化；对未知对象不推断上架状态或填零。资金费为同期 Binance BTCUSDT 永续前 7 日结算的正/负次数，同样不是人数或真实心理。[全部 183 日](../data/verify/cycle-fixed-breadth-quarters-20261105-01/daily.csv)

已知样本中 7 日上涨分别约 81.23% 和 76.02%，28 日上涨分别约 9.58% 和 14.81%；分母、资产构成与市场环境均不相同，不能当成可严格配对的全市场数据。2024-04-22 的历史归档有已知成交量字段差异：事后排除那 5 个合约后为 210 / 25 / 256，这不证明其他归档没有问题。[原敏感性检查](../data/verify/cycle-breadth-binance-archive-2024q2-20261105-01/volume-mismatch-sensitivity.csv)

**之后才知道的价格事实：**分别在该时点之后 28 个完整日末，Bitstamp BTC 日收约 +2.04% 和 -10.02%；7 日末约 -2.85% 和 -9.81%。它们不能倒填当时观点，不定义阶段，也不是交易收益。单凭这两个已见例子，不能断言大背景差异导致后来路径差异，也不能设置参与率阈值。

值得继续保留的竞争解释是：短期更多样本上涨，可能出现在较长尺度弱势的反弹中，也可能出现在其他阶段。即使同时给出固定位置、一年范围、长中短结构和费率，目前仍没有浪浪本人同期标签或独立人工参考，无法可靠命名阶段、计算漏判/误判率或证明盈利模式。
