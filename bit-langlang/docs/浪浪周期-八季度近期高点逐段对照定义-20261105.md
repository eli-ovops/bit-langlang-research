# 近期走弱后固定高点：八个完整季度逐段回顾定义

用户要求研究回踩后能否重新越过近期高点，以及如何区分反弹和真正启动。本轮在计算组合结果前，使用已有完整逐段的 2022Q1、2022Q4、2023Q4、2024Q2、2024Q4、2025Q3、2025Q4、2026Q1；每季从季首每七日取一段，全部时点、非触发、期末不足和 UNKNOWN 保留，BTC/USD Bitstamp 现货是大盘代理，不选交易币。期初季度固定区域、当时此前 28 日高点、旧长中短结构、永续费率分列。

所有季度及部分后续已被项目反复研究，且本研究受到已知 2023/2025 两例启发；即使本组合计算在本文之后，它仍是适应性回顾，不能称未参与设计的独立留出、真实阶段验证或盈利回测。

## 可观测条件与事件

逐段 t 上，使用 Binance BTCUSDT 永续截至 t 前最近 7 个完整日收变化严格小于零，且同一时点 Bitstamp BTC/USD 最近完整日收不高于该所此前 28 个完整日最高价，作为“近期走弱、位于近期高点下方”的**宽泛研究代理**。两个产品分别计算；这不保证存在浪浪所称回踩，不是他的阈值、交易信号或真正启动标签。7 日变化缺失、近高缺失或价格缺失则 UNKNOWN；其他时点 NOT_ELIGIBLE，均不删行。2022 年早期采用已保存的 API 日线，2026 年部分晚期曾标 LOCAL_PARTIAL；价格与费率资料质量单独保留。

对 ELIGIBLE 段，冻结当时此前 28 日的 Bitstamp 高点，从 t 后第 1 至第 28 个完整 UTC 日收逐日跟踪；首次严格日收高于该水平为 RECLAIM，若此前存在缺失而后上越则首次时刻 UNKNOWN；完整 28 日无上越为 NO_RECLAIM；季度末不足或任一缺失无法作否定结论时为 INCOMPLETE。期末之前已观察到上越可记 RECLAIM，实际观察长度另列；等于或低于高点不是上越。不存在任何真实压力、阶段、真假突破的自动确认。

对首次上越后另外七个完整日收，若任一日收返回固定高点或以下记 RETURN_WITHIN_7；完整 7 日始终在其上记 NO_RETURN_7；不满七日或缺失导致无法判断时 UNKNOWN。后续 28 日末现货收盘相对 t 前最近现货日收变化，只有完整观察窗口才算，作为之后才知道的价格事实，不能定义真假启动、推断交易回报、倒填阶段或据此事后改条件。未来窗口可能跨周段、多次重复观察同一事件，两所及相邻段不当独立样本，不计算胜率。

各段保留当时固定季度位置、年景代理、旧长中短结构、费率、90 日变化（无则 UNKNOWN）、近期高点、未触发原因及数据来源，真实情绪和浪浪同期判断全部 UNKNOWN。逐日截断于季度末，不跨季填值；将输入和输出 SHA、全部日点/周段、条件/事件/缺口与实际后续覆盖长度保存。独立复算首次越界、后七天回收及日期边界，抽核参考 28 日高点的原始四小时数据。不得选币、不设计入场、不交易，任何平台 start/stop 前先告诉用户。
