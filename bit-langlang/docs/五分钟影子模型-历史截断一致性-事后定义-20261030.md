# 五分钟影子模型：历史截断一致性事后定义

在已反复研究的 ETH 历史数据中，固定影子模型起点为 2024-07-01 00:00 UTC，分别以 2025-01-01、2025-07-01、2026-01-01、2026-07-01 和 2026-10-25 的 00:00 UTC 为右端不含的截止时间。每次从同样的 2000 USDT 和空仓重新计算，数据在计算信号前截到各自截止时间；资金费使用已保存的公开历史快照与费率文件。

将每个较早版本中退出时间严格早于其截止时刻的已平仓记录，与最终截止版本相同交易编号的全部经济字段逐笔比较；另检查最终版本中该时刻前已平仓的交易是否在较早版本出现。恰好在截止时刻退出的记录单独计数，不在此项中断言其状态；截尾未平仓单独列出，不强制平仓。检查输入、配置和代码哈希一致，并记录各次的资金费覆盖状态。

目标只是检测给定时间点、给定历史文件和模型是否存在未来数据导致的已平仓结果变化，不证明所有截止时刻或所有市场情景均无前视，也不能证明数据真实性或实际成交。区间和模型在既往研究后选择，结果是事后分析，不是样本外或真实前瞻；不启动平台策略。
