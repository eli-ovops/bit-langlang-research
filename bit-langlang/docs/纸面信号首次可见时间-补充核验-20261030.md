# 纸面信号首次可见时间：补充核验

对已有离线连续覆盖检查的复核发现：旧检查只要求一个候选在收盘后六分钟内出现在某次保存的扫描中，且人工信号与决定按序记录；没有比较人工信号发生时间与保存扫描的首次回执。信号事件若早于首次回执，后来扫描重算出相同信号，也不能证明人工事件在当时依据该扫描作出。旧的扫描覆盖合成样例中，信号发生在收盘时，首次回执则在收盘后约 32 秒，因此原样例不支持这项时序结论；它仍可作为当时其他格式检查的历史测试，不是真实前瞻证据。

现补充保守检查：为每个已在扫描出现的信号记录该候选首次扫描回执时间。人工信号事件发生在回执之前或恰在同一时刻时，列出对应信号与时间，`signal_availability_status` 为 `UNKNOWN`，整体在没有更高优先级的待封存、顺序模糊或执行模型不一致状态时为 `UNKNOWN_SIGNAL_AVAILABILITY`。如果仍有尚未在扫描出现的事件，可见性同样为 UNKNOWN；没有信号事件标记 `NO_SIGNAL_EVENTS`。即使事件晚于回执，也只标 `ORDERED_BUT_UNVERIFIED`，不证明人工实际读取了该扫描，不能排除其他信号来源、时钟误差或回填。

这一补充是对既有检查的事后修订，不改变旧的[事前定义](纸面信号连续覆盖核验-事前定义-20261030.md)或其历史哈希。合成样例已调整为信号发生在对应扫描回执之后，并新增先于、等于回执及与执行模型不一致并存的测试。结果不是正式前瞻、真实成交或持续监控证据；不启动任何平台策略。
