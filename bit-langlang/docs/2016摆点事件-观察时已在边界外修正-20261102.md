# 2016 摆点事件的观察时状态修正

执行已冻结规则后发现：最后确认的摆点可能是较久以前的点，观察时前一完整日收盘可能已在该摆点边界外；原事前定义简单从观察后数第一根边界外收盘，会将“已经在边界外继续停留”误读成“之后发生新突破”。原始文件与结果保留，不能事后改写。

补充一张修正事件表：如果 t 前最后完整日收盘严格高于 Hs 或低于 Ls，记录 `ALREADY_OUTSIDE_ASOF`，原事件仅叫「观察后边界外首收盘」，不计新跨越或该次新突破的7日收回；不会暗示真实此前首次突破的日期，除非另有已验证记录。等于边界视为不在边界外，随后严格越过可按原定义；t 前该日不完整则 UNKNOWN。仅对摆点事件执行这一信息时序修正，固定 28 日边界从其过去窗口极值构造，理论上不应存在先前收盘严格在外，否则抛异常。保留原 pivot 结构及候选，不改固定规则、日期或数据。此补充发生在查看结果后，不得称事前冻结的“新突破”指标，也不能用于追溯调参或说明获利。
