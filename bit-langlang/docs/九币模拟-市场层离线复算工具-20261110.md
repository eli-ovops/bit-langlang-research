# 九币模拟 v0.1：市场层离线复算

新增[市场层工具](../verify/paper_nine_market.py)：读取调用者事先保存的 BTCUSDT 永续日线原始响应、请求回执和观察时间，按冻结 v0.1 规则计算 CANDIDATE / NO_CANDIDATE；缺失、数据异常、来源哈希与回执不一致、未来或滞后时间一律返回 UNKNOWN。该程序不联网、不获取行情、不写账本、不选择币种、不下单、不启动定时任务。

核心检查：只使用请求返回时已经收盘的日线；观察时刻必须不早于响应取得时间、不晚于本机当前时间；最新完整 UTC 日线必须可用；核对最近 35 根时间网格、正量和 OHLC。突破日的参考高点只取其以前 28 个完整日，不能混入突破日之后的数据。代码输出明确保留阶段与情绪 UNKNOWN，并提示 v0.1 的“七日最高高于现价”不证明突破后回踩。

使用首次观察的实际文件**离线重算**为 NO_CANDIDATE，已收日为 2026-11-09，收盘 75,327 USDT；[离线结果](../data/verify/paper-market-module-check-20261110-01/replay.json)不是新增实时观察、不是新纸面交易，也不证明持续运行。它与原始 `INITIAL_NO_ENTRY` 观察一致，仅证明该文件在所测逻辑下可复算。本机回执和哈希不能独立证明来源、时钟或实际成交。

`python3 -m unittest verify.test_paper_nine_market verify.test_paper_nine_accounting verify.test_paper_nine_initial_bridge`：**18 项测试通过**；新测试覆盖人工候选、原记录复算、数据缺失/重复/零成交、未完成未来日线的隔离、回执不一致和超过日界后的数据陈旧。人工样例和文件内部检查均不证明模型阶段准确性或收益，未测试全部潜在异常。

该工具仍只是**一次性离线复算接口**：没有实时行情采集、审计事件写入、自动持续运行或下游选币/成交链路。调用示例：

```bash
python3 -m verify.paper_nine_market --response <已保存的公开日线JSON> --receipt <对应回执JSON> --as-of <实际UTC观察时间>
```

不能把历史读取当成实时观察，未收集就是 UNKNOWN；未来要采集仅能使用公开数据且须留实际完成时刻。新程序及本说明为持久成果；未修改旧策略和现有纸面账本，未访问真实账户或执行平台 start/stop。
