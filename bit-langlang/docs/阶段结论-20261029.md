# 阶段结论（2026-10-29）：数据重建 → 选择器 → 非马丁基线

> **后续**：这三步没有回答“为什么他能赚钱”。该问题已由 [第一性原理](第一性原理-他为什么赚钱.md)、[PnL归因](PnL归因.md)、[进出场机制](进出场机制.md) 回答——
> **钱 ≈ 薄凸性优势 × 换手 × 规模放大 × 2023–24 行情；入场无 α，出场有 α，94% 美元来自规模。**

## 步骤 2：选择器 edge（已完成，结论 No-Go）

> 报告 `docs/选择器研究.md`；代码 `scripts/v2_selector/`；产物 `data/selector/`。

- 覆盖：10 币 2,499/4,651 仓位（53.7%），特征可对齐 2,421。
- 目标 R（=pnl/0.1·margin）：23 个入场可观测特征，train 最大 |IC|=0.041；test 最强单格按日聚类 |t|=1.54，**Bonferroni 后全部不显著**；5 特征模型 test AUC 0.530。
- 目标 C 的"表观信号"被证伪：naive IC 0.08–0.11 来自币种身份/市场 β；按币去均值后 within-coin IC 0.003(train)/0.066(test)。
- 真样本外（2024-07~2026-10 行情）：冻结信号无差异（t=0.29/0.58），top10% 随机分位 0.8%。
- **结论：选币/择时无可测量 edge，不要继续调选择器参数。**
- 局限：交割单止于 2024-06-20，任务书要求的 2024-07 后真实交易样本为 0；10 币覆盖偏 BTC（40% vs 全样本 21%）。

## 总结论

**三条路线（机械复刻 v1/v2、选择器、马丁/非马丁平台回测）都没有产生可上资金的正 edge；当前唯一确定的结论是"风险可控 ≠ 能赚钱"。**

- 数据：已可审计、可复现、口径明确。
- 选择器：无 edge。
- 平台：马丁会归零；非马丁只是小亏；提现无法验证。
- **资金建议：继续 0 资金纸面阶段。**

## 下一步（按价值排序）

1. **转向出场/仓位/事件驱动**（选择器报告建议）：同一入场，比较不同出场几何（跟踪止损、时间止损、分批止盈）与风险预算；这是唯一还没被系统证伪的维度。
2. **用真实逐笔/权益曲线**：需要持久化 run 或自建数据管线；否则"提现/月度/复利"永远无法验证。
3. **补 2024-07 之后的真实交易样本**：没有它，"选择器/策略"的样本外只能靠行情代理，不能验证他的真实执行。
4. 若三步都无法给出正 edge，应接受"这套体系不可机械复刻"，停止投入。
