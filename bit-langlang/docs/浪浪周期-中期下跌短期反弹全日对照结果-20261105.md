# 中期下跌、短期上涨：六个完整季度的逐日对照

## 主要结论

在本次已见历史中，即使同时满足“BTC 永续此前 90 日收下降、此前 7 日收上升”，且 BTC 现货日收位于季度期初冻结区间内部，之后 28 日日收也能出现上涨和下跌。**这组事实本身无法可靠区分下跌反弹与真正启动。**

例如 2022 年四季度的两个时点都满足上述条件且在同一个固定区间内：10 月 9 日之后 28 日日收约 **+9.69%**，10 月 30 日之后约 **-20.97%**。但它们的小级别变化、已走空间及费率不同，且均为已知历史，不能断言哪一项决定了后来结果。后续价格变化不是当时已知，不是交易回报，也不等同真实市场阶段。

## 范围和口径

按[本轮定义](浪浪周期-中期下跌短期反弹全日对照定义-20261105.md)，对 2022Q4、2023Q4、2024Q4、2025Q3、2025Q4、2026Q1 六个完整季度的 **550 个 UTC 日点**逐一检查，不只挑首次突破或某些成功案例。每个季度 Bitstamp BTC/USD 现货相对于该季度开始前 28 日日线形成的固定区间，记录在区间上、内或下；每季区间各自固定，跨季度不拼成同一区间。只用一所现货是为避免把不同所的同一日重复算作独立行情，不代表本轮完成双所验证。

此前 90/7 日变化使用 Binance BTCUSDT 永续已完成日收；条件定义为 90 日变化严格小于零且 7 日变化严格大于零。它只是研究者提出的描述条件，不是浪浪的规则或交易信号。现货价格和永续价格各自计算，不拼价；21 次资金费来自该时点前七天的永续结算，不等同整体资金流、人数或真实心理。

六季度此前均被研究，90/7 条件由两个已见案例启发，因而本次是**适应性回顾，不是未参与设计的独立检验**。28 日后续仅在该季度数据足够且无缺口时记录；不跨季度填补，末尾数据不足留 UNKNOWN。价格变化只是后来的事实，不能定义真正启动、假突破或阶段对错。

## 固定区域内部的反例

同一季度、同一冻结区间的 2022-10-09 和 2022-10-30，Bitstamp 价格均在区间内，永续此前 90 日都下降、7 日都上涨：

| UTC 时点 | 永续此前 90 / 7 日 | 原研究长 / 中 / 短结构 | 此前 21 次费率正 / 负 | 之后 28 日现货日收变化 |
|---|---:|---|---:|---:|
| 2022-10-09 | -6.94% / +0.53% | DOWN / INSIDE / INSIDE | 21 / 0 | +9.69% |
| 2022-10-30 | -10.71% / +8.34% | INSIDE / UP / UP | 17 / 4 | -20.97% |

旧长中短结构是既有 56/28/8 日窗口代理，非浪浪真实公式。两点此前走过的空间和短期推进不同，不能当成只差一个变量的实验；资金费不同也不证明实际情绪或原因不同。两行结果是事后极值示例，挑选时已知道未来结果，不能据此制定阈值或推定任何可获收益。

全体条件成立且位于季度固定区间内的 2022Q4 有 25 点、均有 28 日后续，后续价格范围约 -20.97% 至 +9.69%；2023Q4 有 3 点，后续约 +26.34% 至 +27.43%；2025Q4 有 7 点，后续约 -24.22% 至 -17.78%。这些日点相邻且相互重叠，只说明已见路径不唯一，不是三组可比较的胜率或真实阶段标签。[全部日点](../data/verify/cycle-rebound-full-quarters-20261105-01/daily.csv)、[全部季度及区域分组](../data/verify/cycle-rebound-full-quarters-20261105-01/groups.csv)。

## 数据限制与核验

全部 550 条过往期货窗口均满足 91 个完整日时间网格、OHLC 与正成交量检查；其中 **492 条**的全部期货日柱与已保存交易所 API 响应的重叠字段一致，**58 条**包含 API 响应未覆盖的本地后段，只能称 LOCAL_PARTIAL，不能冒称已与交易所逐日核验。六季度全部 550 个日点的此前资金费窗口满足 21 个互异排程质量条件；市场真实情绪仍 UNKNOWN。

独立读取本地期货原日线，用差值公式重算全部 550 个点的 90/7 日百分比与 YES/NO，并对原固定区域表重算可对齐的后续变化；全部 24 个季度/区域分组的成立数和后续可得数一致。期末边界来自原季度固定区域源表；源数据、输出哈希见[核验摘要](../data/verify/cycle-rebound-full-quarters-20261105-01/summary.json)。本轮未逐笔核验成交、没有独立人工阶段参照，不能声称已识别真正启动或证明浪浪盈利模式。
