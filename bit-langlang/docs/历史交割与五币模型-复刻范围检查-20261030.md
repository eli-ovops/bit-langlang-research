# 浪浪历史交割与五币模型：复刻范围检查

结论：用户指出的复刻验收缺失成立。此前五币模型是用户指定新币池与 2025–2026 行情上的研究者代理模型，**没有先证明它能复现所提供历史交割记录**，不能用其亏损评价浪浪本人方法。下面是只读覆盖检查，不是逐笔入场复现率或策略收益验证。

## 检查对象和方法

- 已清洗历史成交：[trades_clean.csv](../data/processed/trades_clean.csv)，包含 4808 行，文件内原始入场时间范围 2022-05-24 至 2024-06-20。数据来源为第三方整理交割单，账号身份、时区、完整性、合并规则和交易所价差并未由本检查独立认证。每行是清洗记录，不可默认等于 4808 个彼此独立的交易机会。
- 对照对象：[五币复利模型定义](五币浪浪思路复利回测-事前定义-20261030.md)，标的 UNI、AAVE、LINK、ENA、Lighter LIT，仅做多，模拟区间 2025-10-01 至 2026-10-25。Lighter LIT 不是历史 Litentry 的同代码代币。
- 直接读取清洗 CSV 的 `base`、`side` 和 `entry_time` 字段，逐行统计，不以历史结果进行参数调优。

## 覆盖结果

历史 4808 行中，3053 行记为多、1755 行为空。若仅检查字符串币名集合 UNI/AAVE/LINK/ENA/LIT，命中 52 行；其中 UNI 多 19、空 4；AAVE 多 3、空 1；LINK 多 20、空 5；ENA、LIT 没有命中。再加上模型只做多这一限制，仅剩 42 行（0.87%）。这是忽略时间、价格、信号和交易所后的**宽松范围上限**，不是实际匹配；另外的 4766 行仅因币种或方向即不可能由该五币多头模型覆盖。

更根本的是两份记录的时间不重叠：历史交割止于 2024-06，五币运行从 2025-10 才开始。因此该次运行对历史入场的实际命中数和漏报数均**未测**，不能凭范围统计说真实复刻率为 0.87% 或 0%。历史资料中的 2022–2024 年交易亦不能被当作 2025–2026 年的真实交易。

已有 [trades_panel.csv](../data/entry_exit/trades_panel.csv) 对 10 币历史成交做过行情对齐，2470 行，其中 1467 行多、1003 行空；[对齐报告](../data/entry_exit/alignment.json)是旧程序的汇总，时间按北京时间转 UTC、跨交易所行情等假设需要逐项复核，不等于账号/市场/时间的独立确认。被用户指定的五币均未出现在该已有面板的 `coin` 字段里。

## 适当的下一步验收

1. 保留已给出的五币结果为**仅验证代理规则**，并对其未通过“浪浪复刻”验收作显著说明。先核对原交割源、时间、方向、币种映射与交易所行情，记录不能对齐的情况。
2. 单独做“历史复刻对照”，使用真实历史交易时可用的同币种和当时信息，不把 2025–2026 的五币清单硬套为其历史全部币池。先定义可检验的允许匹配时间窗、方向、同一信号与多条成交/加减仓合并方式；逐笔保留时间差、能否判断、未覆盖和相反方向，不能看到结果后调整窗口。
3. 同时报模型信号匹配比例、历史入场覆盖比例、未匹配信号、每币/多空/时间分布及不可评估比例；加上同币同日随机或简单规则对照，避免高频触发被误当成复刻。出场、仓位和资金曲线是独立层，入场命中不等于完整复现。
4. 缺历史行情、交易时间或账号真实性不足的条目保留 UNKNOWN。过去已反复研究的交易只能用于诊断和构造假设；即便历史复刻好，也需隔离的新时段及成本/真实执行检验才能评价策略可用性。
