# 前瞻三份报告：独立行情核验关联

本地 `verify.paper_evidence_link` 现在可同时读取扫描归档覆盖报告、逐笔批量报告和 `paper_scan_source_independent` 的交叉核验报告。除既有观察区间、事件文件和扫描哈希检查外，还核对独立报告与扫描归档的头部一致、锚点状态，以及已提交周期全部有顺序一致的 `MATCHED_UNVERIFIED` 结果。

即使前两份报告形式匹配，没有第三份独立行情报告也不再给 `PARTIAL_LINK_UNVERIFIED`，而是 UNKNOWN；头部不一致或独立报告无效返回 INVALID。已有 STOP、执行模型不匹配等状态仍会保留，不能被缺报告包装为通过。旧归档缺基线或公开响应时也不能成为完整的局部关联。

```sh
python3 -m verify.paper_evidence_link \
  --coverage <扫描归档审计JSON> --batch <逐笔批量报告JSON> \
  --source-check <独立行情交叉核验JSON>
```

七周期合成测试使用真实本地扫描归档审计、独立行情交叉核验和包含一笔合成止损交易的批量报告：三份报告的归档头和输入形式一致，行情交叉核验被标为 `MATCHED_UNVERIFIED`；整体依然是 `EXECUTION_MODEL_MISMATCH`，因为模拟延迟报价与冻结下一根开盘口径不同。无入场的合成链路仍为 UNKNOWN。另测试缺报告、头部不同、未完整重建与无效报告。

报告与预期头由本机文件提供，形式一致不能认证来源、时钟、未封存尾段、连续盘口或实际成交；独立检查仍使用项目归档加载器。本工具不启动扫描、定时任务或平台策略。没有真实前瞻记录或 90 天连续运行证据。
