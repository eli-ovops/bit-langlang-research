# 同期榜单：成分变化与同一对象的方向变化

## 结论

上轮提到的两个相邻观察：2023-02-12 对应前 30 行显示 **5 涨、25 跌**，下一周对应的页面为 **25 涨、2 跌、3 行显示零**。按 CoinGecko 页面内的数字资产 ID 对照，两次前 30 行中 **28 个 ID 相同、2 个进入、2 个退出**；在 28 个共同 ID 中，有 **22 个**的页面显示由前次 7d 下跌变为后次 7d 上涨，另有 1 个由涨变跌。说明这两个页面之间的分布变化不仅来自换榜，也存在共同对象的方向变化。

这是两个不同抓取时刻的滚动 7 日页面读数，两次抓取间隔约 **168.77 小时**；页面底层报价及 7d 指标的具体截止时刻未知。涨跌值是页面显示的数值，显示 0.0% 按单独类别计，不代表精确零。页面样本含稳定币、包装资产及 BTC，数字 ID 不保证是经济上彼此独立的 28 项；不能直接把它等同全市场资金流、真实情绪或浪浪的某个季节。
