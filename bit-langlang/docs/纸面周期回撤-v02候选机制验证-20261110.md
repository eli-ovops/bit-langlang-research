# 回撤时间顺序：v0.2 候选与历史机制检查

## 改动与结果

提出[独立候选口径](../data/verify/langlang-paper-pullback-v02-audit-20261110-01/口径.md)：先确认某个完整日收突破当时此前 28 日最高，后至少再有一个完整日，其日内低点低于突破日收盘；最新日收仍在该次突破对应的原高点上方。它只表明突破完成后曾发生价格下探，**不代表碰到原高点、不证明完整回踩结构或主升**。只使用截至观察时点已完成的数据。

同一已研究历史区间 [2022-02-05,2026-10-30) UTC 的 1,728 个日点，v0.1 市场候选 228 个，v0.2 候选 149 个；减少的 79 个均因最近突破发生在最后一个完整日，尚无突破后的完整日而被排除。本数据内，其余 v0.1 候选都满足 v0.2 的低点条件；这不意味着低点条件在其他数据或所有路径上必然成立。候选是日点，不能当独立行情或交易次数。

这是**时间语义的修正，而不是收益改进**。它自然漏掉突破当天观察及持续快速上涨可能产生的机会；如果在最近七日中出现更新的收盘突破，规则以最新突破日重新计时，也可能重复延后。反过来，低点短暂小于突破日收盘也未必构成有意义的回撤。不能由此认定正常回调、下跌反弹或真实启动，更不是浪浪的原话或已证实交易规则。
