# 九币纸面实验：独立账本算术检查 v0.1

针对[旧检查器与九币规则的冲突](纸面模拟v01-旧版账本检查器兼容性审查-20261110.md)，新增[独立工具](../verify/paper_nine_accounting.py)，不引用或修改旧 TPH 冻结配置，不调用交易所、真实账户、订单接口或调度器。只接受调用者提供的 JSON 记录并输出检查结果。

## 已覆盖

- 验证九个公开合约代码、只做多、唯一 ID、带时区的实际记录时间、无未来观察点、止损低于入场。
- 按本实验虚拟权益的 0.5% 检查初始价格风险、按入场前权益检查名义不超过一倍；两笔仓位的时间重叠或同刻先后不明按 INVALID 保守处理。
- 假设双边分别 0.05% 验证输入费用，并据模拟成交价计算毛盈亏，扣除两边费用和**有符号**资金费得到净盈亏和净 R；不重复扣滑点。缺资金费时不能计算净盈亏、净 R 或完整余额，返回 UNKNOWN，不默认零。
- 平仓前后逐笔按完整账本且无出入金的假设对账入场前权益；未平仓按提供的时间和来源计算条件性估值，超过 15 分钟明确标 STALE。输入价格不证明可成交、已触损或真实止损有效。

[七项合成样本测试](../verify/test_paper_nine_accounting.py)覆盖九币 SOL 的费用与净 R、缺资金费、重叠持仓、仓位和手续费边界、过期估值、非法时间和空账本；`python3 -m unittest verify.test_paper_nine_accounting` 本次 7 项通过。所有测试交易均为虚构，不能当作实际纸面观察或收益。

## 限制和下一步

该工具只核对提供的记账算术，**返回 UNKNOWN，不产生 PASS**：无法证明信号或报价来源、下单价格可得性、连续覆盖、漏记、真实成交、仓位路径、触损时序、假设手续费来源、资金费是否漏记、可用保证金或真实强平。单笔名义价值等于权益时，费用及保证金同时占用能否成立尤其未知；要推断可执行性须另定义现金/保证金模型。它没有检查新市场规则是否复刻浪浪，旧 v0.1 的回撤语义缺陷仍未替换。

新工具使用独立 JSON 形状，当前[首次观察账本](../data/verify/langlang-paper-research-20261110-01/ledger.csv)为 CSV 且只有空仓事件，**尚未完成两者的数据桥接或真实纸面样本端到端验证**；不应手工补造成交。使用例子以测试文件中的合成输入为准；如需 CLI，可运行 `python3 -m verify.paper_nine_accounting --file <调用者JSON>`，但输入本身不证明来源。当前无后台调度或持续行情，纸面资金和连续性以原记录为准。

本次新增两个源码文件和本说明，均为持久研究成果并保留；未修改现有账本、旧配置或其他项目，没有访问真实账户或执行平台 start/stop。

## 持仓估值触及研究价位检查补充

在提供的未平仓估值中，工具另输出假设的 `entry + 2 × (entry - stop)` 目标价，以及**所提供估值时刻**价格是否位于研究止损价或目标价之外。即使估值触及，仍只提醒“模拟成交 UNKNOWN”，不会创建平仓、扣退出费或断言交易所触发；估值过期时仍须看 STALE 提示，不能当成当前价格。[新增合成边界测试](../verify/test_paper_nine_accounting.py)覆盖止损和目标两端，且验证触及不会令结果变成 PASS。与首次空仓桥接测试合计运行 `python3 -m unittest verify.test_paper_nine_accounting verify.test_paper_nine_initial_bridge`，13 项通过。它仍未验证连续路径、真实标记价、资金费覆盖或完整实际纸面交易。
