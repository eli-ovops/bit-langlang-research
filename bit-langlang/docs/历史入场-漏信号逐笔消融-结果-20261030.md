# 历史入场漏信号逐笔诊断

状态：样本内研究，未通过独立样本验证，不能认定已经复刻浪浪，也不是纸面或实盘信号。未修改或启停平台策略。止损、止盈委托均未记录，状态 `UNKNOWN_NOT_RECORDED`。

## 方法

按[预先定义](历史入场-逐笔门槛消融-定义-20261030.md)，重建十币多头候选的完整行情信号；每条历史持仓在假设北京时间 UTC+8 下，寻找同币且不晚于入场、最多早 15 分钟的模拟执行时刻。仓位是交割合并结果，不一定等于原始每笔订单。只分析有足够暖机数据的 1358 条多头；空单、其他币和不足暖机的记录不能视作验证通过。每个模拟时刻使用其自身 UTC 日背景，BTC 不与自身做强弱排名。各条件使用候选时刻可得的数据，模拟时刻仍不等于真实可成交价格。验收采用完整信号重建、逐仓位匹配、同币同日偏移对照、现有测试和实际案例独立重算；Owner 是本地研究脚本，不涉及交易平台。

## 逐层筛选：哪些位置丢失

| 累计条件 | 1358 条中仍在窗口内出现至少一个候选时刻的条数 |
| --- | ---: |
| BTC 20 日中点背景代理 | 867 |
| 加七日相对 BTC 排名前二（BTC 自身豁免） | 652 |
| 加假设的 5 分钟回踩确认形态 | 291 |
| 加 4 小时范围中点 | 248 |
| 加旧模型 20 日高点空间条件 | 184 |
| 加旧模型 2R 空间条件 | 144 |

这是固定顺序下的描述，门槛会重叠、次序会影响各层数字，不能说每层减少数量就是单一根因。20 日中点不是已经证实的浪浪周期，有限十币排名也不是完整市场强势币池；回踩形态是模型假设。逐笔窗口及各条件布尔值见[逐笔明细](../data/verify/historical-entry-ablation-20261030-02/rows.csv)，其中 `panel_row` 是交割面板零基行号。

联合移除两项未经订单证实的目标/风险代理后，时间重合增加 104 条、模拟信号增加 9103 条（33.84%）；仅移除高点条件效果很小，是因为剩余 2R 条件仍依赖相同高点。新增命中并不证明这些入场盈利或者能够按浪浪方式止损止盈；近时段对照未控制波动、形态或同日聚集，不能解释成统计显著性。更重要的是，去掉代理条件不等于放弃风险控制：在真实止损未知时，不能计算真实交易回报或将此候选直接投入交易。

## 可复核案例

交割面板第 34 行（零基）BTC 多单，原时间 2022-06-08 07:06，记录价格 31151.55；假设 UTC+8 则为 2022-06-07 23:06 UTC。独立使用原 Binance 5 分钟数据逐根重算，该窗口 22:50 UTC K 线符合本模型的形态和四小时中点条件，模拟时刻 23:05 UTC；其旧模型高点条件通过，但旧模型 2R 条件失败，所以原模型未重合而移除两项代理后时间重合。仅说明可能被模型过滤，不能说明浪浪是依此入场或该价格可成交。实际止损和止盈 UNKNOWN。

## 验证与边界

完整重建的每个币原始信号数组均与前轮保存数组逐项一致；1358 行原模型状态全部一致；联合移除覆盖原模型全部 144 条并新增 104 条。8 项既有相关测试通过，独立按原始 K 线重算上述案例；汇总和数据 SHA-256 见[结果](../data/verify/historical-entry-ablation-20261030-02/summary.json)。第一次输出 `-01` 未将暖机单独并入逐层状态；正式版 `-02` 已补正并保留两份，不覆盖历史产物。

该样本已经多次用于研究和调整，附近时间对照并非独立样本。账户归属、原交易所、时区和 5 分钟 K 线跨所可比性均未完全认证。不能把匹配数量当作信号准确率、订单成交、净收益或前瞻可行性。下一步需要能溯源的盘中截图/多交易所订单历史及未参与筛选的数据，对不同周期条件与同币持仓去重进行检验，并建立事前约定的风险和执行假设，而不是声称知道历史止损止盈。
