# 双延迟影子：公开标记价资金费对照事后定义

在已取得公开资金费快照并看到影子历史结果之后，对同一份 125 笔已平仓双延迟账本进行事后固定持仓算术对照：对每笔持仓 `[entry,exit)` 内的公开资金费记录，分别按 `数量 × 费率 × 结算所在 5 分钟柱开盘价` 和 `数量 × 费率 × 公开记录 markPrice` 计算金额；与账本已记资金费逐笔核对前者，并计算后者差额。对接近入场或退出 60 秒以内的结算单独计数，保留顺序 UNKNOWN，不作账户结算断言。

持仓数量与入出场路径固定，不根据替换的资金费重新计算可用资金、后续仓位或回撤；因此结果不是按公开标记价重新运行的回测或可兑现盈亏。快照取得时刻晚于历史交易，属于历史数据核验，不是实时前瞻；公开 `markPrice` 不是用户账户的实际结算证据。价格、费率、滑点、强平、资金费结算先后及账户交易所均有未知，任何一项都不能据此用于实盘。
