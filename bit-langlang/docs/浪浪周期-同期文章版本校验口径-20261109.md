# 同期文章版本校验口径

固定先前 26 个周点中有对应 URL 的全部 24 篇 Glassnode 官方周报；两个无符合期限文章的周点保留，不因有无存档选取部分样本。逐篇读取当前官方 HTML 的 `article:published_time`、`article:modified_time` 和主正文；同时对旧 `insights.glassnode.com` 原始文章地址查询 Internet Archive 公共 CDX，窗口自该文发布日期 UTC 零点至观察时刻，保留所有 HTTP 200 索引并剔除观察时刻及以后的抓取；有多份时固定选择距离观察时刻最近的一份公开抓取。

仅对索引存在且抓取时间严格早于观察时刻的条目，普通只读获取 Internet Archive `id_` HTML，检查 HTTP、返回地址、Memento-Datetime、原始 HTML 主正文选择器、标题及非空正文；两份页面的正文统一抽取 `.gh-content`、空白归一化后对比，分别保存哈希和差异段落数量。图片、动态内容、数据仪表盘和正文之外推荐内容不用于文本比较。记录文章页面的发布与修改时间由站点声称，并不证明没有其他修订；存档时间早于观察点能证明存档版本在那时已被记录，但不能证明更早发布的确切正文，也不能证明捕获的数据及作者观点是真实的市场阶段。

按来源区分 `ARCHIVE_MATCH`、`ARCHIVE_DIFF`、`NO_CAPTURE_BEFORE_ASOF`、`UNKNOWN`；目录、请求、失败、页面与 HTML 的 SHA256 和正文摘要可追溯。网页访问失败、非 HTML、正文缺失、Memento 与所选时间不一致或 CDX 不完整时留 UNKNOWN，不试图绕过限制。正文不同须保留，不把发布日期早于观察点当成内容等同。脚本只访问公开文档，不访问账户或交易接口。

该版本审查只减少部分文本时间不确定，不能把过去已见行情变成独立留出，也不提供独立评审、阶段真值或准确率。作者没有被委托按本项目盲判；继续不选币、不设计入场或交易，任何平台 start/stop 前先告知用户。
