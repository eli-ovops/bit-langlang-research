# 盘口逐条落盘回执：单次在线预检定义

先在合成测试中将 v2 事件/回执双链接入现有单次公开预检：一条消息的事件文件和目录 fsync 返回后记录本机回执时间，再持久化回执；单条失败停止采样并保留残留，禁止自动补齐或封存。保留旧 v1 读取与既有预检兼容。v2 封存须绑定事件链、回执链及数量，离线会话核对须核对接收时间与回执的顺序、摘要和原始内容。

测试通过后仅进行一次 8 秒或最多 500 条的 ETHUSDT USDⓈ-M 公开深度采集，一次连接、一次公开 REST 快照，无账户或订单，不启动或停止平台策略。保留原始文本、快照、v2 双链、回执、本机时间、封存和各文件哈希；网络拒绝或失败不自动重试。

`event_fsync_returned_at_utc` 是本机事件文件及目录 fsync 返回后读取的时间，只表示程序的本地顺序，不是交易所时间、实际成交时间、回执自身 fsync 时间或物理持久化的独立证明。本机或服务器时钟、消息批内价格、首尾完整性、真实触发与成交均 UNKNOWN。只预检，不建立持仓或启动正式前瞻。
