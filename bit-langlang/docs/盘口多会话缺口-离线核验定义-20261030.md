# 盘口多会话缺口：离线核验定义

按提供顺序检查已保存的独立公开预检目录，不连接行情、不自动重连、不控制平台策略。每个目录先核查 manifest、消息与原始快照文件哈希、逐条归档链及 seal，确认归档消息与原始文件一致、派生 trace 与快照及消息内容一致；随后重跑序号与有限深度形式检查。只依据信息推断形式一致性，不认证来源、时钟或外部锚点。

本机接收时间必须有效、有时区且不倒序；不同会话必须按时间先后且不得相互重叠。仅使用前一会话最后一条本机接收时间至后一会话第一条本机接收时间，报告局部时间差并标 `UNKNOWN_UNOBSERVED`；即使该差为零也不能宣称无缝。会话首条之前、末条之后及消息批内的行情均未知。跨会话 `u` 不能单独证明无断档，重连需要重新快照与桥接。

缺 manifest/文件、无效哈希或篡改标 INVALID；归档未 seal 标 `INCOMPLETE_UNSEALED`，不冒称成功；单个形式有效会话最多 `PARTIAL_SINGLE_UNVERIFIED`，多会话报告 `GAP_UNOBSERVED_BETWEEN_SESSIONS`。任一缺口不得由后来快照回填为无触损。本次使用两份独立的短时预检，它们不是一次连续连接的实际断线或恢复实验。

测试合成正常、未封存、篡改、顺序错误和跨会话缺口；另只读检查两份既有公开预检，保存派生检查文件及输入哈希。结果不证明持仓、交易或实时行情可靠性。
