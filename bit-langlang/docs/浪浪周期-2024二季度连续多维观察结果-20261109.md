# 2024 年二季度：连续13点的周期、空间与局部变化

## 研究结论

在已见历史的这13个周点里，180日日线先展现明显上行，后续逐渐进入旧高下方的大范围波动；其间多次发生四小时或日线回落及恢复。**大背景曾强势，并不意味着此后每一周都处于主升；短期反弹或页面7日多数上涨，也不能单独证明新一轮启动。**

特别是 2024-06-10 观察点对应的前一日页面，BTC行的7d显示 **+2.7%**，但前30行是 **8涨、20跌、2行显示零**；其中包含BTC、稳定币和包装资产，不能把20行都称为山寨或代表全市场。这个例子支持分开记录BTC与样本分布，而不是把BTC上涨自动等同市场整体热。页面内部数据采样时间 UNKNOWN，不能当成观察点完全同步的情绪。

## 对阶段研究的含义

1. **震荡末期**：一段高位反复本身不足以证明已经是末期；4月至6月多次横向或反复，必须将“仍延续区间”和“开始离开区间”并列。
2. **启动**：05-20 前后的短级别推动可以作为恢复候选，但当时既有更大区间与上方旧高；仅凭一段推动或一个样本读数不能确认新周期启动。
3. **主升与局部回落**：04月此前已有较长上行，06月仍能在180日窗口看到这段上涨；但期间局部结构和市场样本变化不一。上行背景不能取消短期转弱，短期转弱也不能自动认证更大周期结束。
4. **情绪**：页面上的价格涨跌是参与的有限代理，不是对人气、资金意图或全市场情绪的直接测量。同期可追溯资金数据在本表未提供，真实情绪留空。

本报告所涉2024Q2在草案前已由项目研究，研究者也已见后续，不是未参与设计的历史留出；市场榜单只通过10/13点，剩余3点不可选择性忽略。不能计算阶段准确率、漏判率、真假突破率或盈利。用户此前要求不选币、不设计入场和交易，本研究未做这些，也未执行平台 start/stop。
