# 五分钟影子模型：资金费覆盖补充定义

影子回放仍按既有引擎以 5 分钟开盘价作为资金费计算代理；真实账户的资金费、结算标记价、仓位和费率折扣 UNKNOWN。除原有费率 CSV 外，允许另提供 `paper-funding-snapshot-v2` 公开快照：检查快照结构、文件哈希、采集时序，并逐项比较研究区间 `[start,end)` 内的 ETH 结算时刻与费率；完整覆盖且完全匹配时标 `PARTIAL_PUBLIC_RATE_COVERAGE_UNVERIFIED`。快照缺失或无法覆盖完整区间标 UNKNOWN，不将空 CSV 自动认定为没有费用；覆盖完整但费率或时刻与 CSV 不一致时拒绝计算结果。

快照必须在本次检查时间之前已采集、查询的服务器时间不晚于检查时间，且快照自身起止范围覆盖影子区间。快照和费率文件在研究前后重新核对哈希，防止执行过程中输入变化。校验仅说明所提供本地文件形式吻合，不证明交易所来源、时间可信或真实账户结算完整；即使公开快照包含标记价，影子回放仍采用 5 分钟开盘价作为原既定代理，不将其冒称交易所结算价格。

该检查仅覆盖模型使用的 `[start,end)` 费率时间序列，并不解决真实持仓在结算时刻附近的先后歧义；已有逐笔资金费工具的 60 秒模糊区间与账户实际结算仍需另外核对。

该补充不启动前瞻、不更改原模型配置、资金费率和成交假设，不以覆盖结果生成 PASS；后续仍须独立评估成交、风险、数据连续性和账户条件。
