# BTC 条件移除：早期收益集中度事后定义

已观察到 2022-05-01 至 2024-07-01 的独立重放中移除 BTC 条件的期末权益高于原规则。本次针对该已知结果，分别描述两份已保存平仓账本的盈利笔数、单笔净收益分布、最大一笔和前三笔盈利占正收益之和的比例，并静态计算从账本净盈亏中减去这几笔后的数字。该观察为事后分析，不是独立样本外或事先设定的交易规则。

两组账本分别按自身账户及仓位动态生成；静态扣除已知盈利单不会重算后续资金或成交路径，不能称为排除这些交易之后的回测、期末权益或可执行筛选。只计算账本所列已平仓记录，核对原汇总的期末未平仓为零、单笔净盈亏及账本哈希。手续费、滑点、资金费及止损成交均是研究假设，无法证明实际成交或未来收益。
