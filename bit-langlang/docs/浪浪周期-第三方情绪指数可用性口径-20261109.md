# 第三方情绪指数可用性检查口径

目标是在现有已见历史上检查 Alternative.me 的 BTC Fear & Greed 历史数据是否可用作辅助线索；不是交易信号、真实情绪、浪浪规则或独立的阶段标签。当前官方说明将 BTC 波动、价格动量/成交量等纳入，故它与价格不是独立证据；方法及权重过去是否变化仍 UNKNOWN。

在下载指数数值前固定：一次获取官方公开完整 JSON，保留原始响应、UTC 获取时间和哈希。只检查此前已有图包的两个完整季度（2023Q1 和 2025Q2）全部自然日，不按行情或指数选点；检查日期网格、唯一性、数值范围及原始时间字段。对 26 个已有 UTC 观察点，仅展示索引时间严格早于该点的最近记录，并保留缺失，不把时间戳当成已证明的实时发布时间；未经历史版本和当时实际发布时刻核验，一律标为“现今 API 回溯值、当时可得性 UNKNOWN”，不放进用户盲评输入，也不能用于声称当时就知道。限制和指标变化不得写成浪浪本人观点。

数据质量通过与否和阶段判断分开，不做准确率、预测或盈利计算。收集失败则记录失败，不绕过访问限制。数据已由 API 返回不证明源数据真实性、实时性或历史版本；这两季早被项目研究，并非独立留出。暂不选币、不入场、不交易，任何平台 start/stop 前告知。
