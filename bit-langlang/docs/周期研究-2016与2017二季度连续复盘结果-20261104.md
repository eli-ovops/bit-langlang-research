# 2016 与 2017 年二季度：不同市场背景下的连续复盘

## 结论

2016 和 2017 年均能看到区间整理、价格扩张和随后波动；但小级别转强之后的首次日收越界及收回，可能因交易所的历史区间边界不同而在不同日期出现，甚至得出不同结果。跨所极值质量警报也可能使较长背景不可判断。这些事实使“启动还是反弹”“正常回调还是衰退”不能依赖单一价格或机械信号完成裁决。

两个季度以前都被项目研究过，这次是在已知历史和多次研究结果之后的连续复盘，不是未接触的样本外、盲测或对浪浪本人阶段判断的验证。市场情绪、广度、独立人工阶段标签、真实漏判及真假突破未知。春夏秋冬、56/28/8 和区间参数都是研究表达，不是浪浪本人确认的公式。

## 观察口径

依据[事前定义](周期研究-2016与2017二季度连续复盘定义-20261104.md)，两个 BTC/USD 现货季度分别保留全部91个 UTC 日点，分成13个连续七日观察段。每段首先记录判断时已结束的 56 日日线、28 日日线和8日四小时高低结构，以及前一完整日收与前28日高低边界；每项只表示价格事实。段首之后最多21个完整日，观察日收首次严格越过当时冻结区间的哪一侧，越界后下一日是否仍在同侧，并观察其后7个完整日是否日收回到界内。越界和返回在日线收盘后才可知，不能倒填。单次或连续收盘越界都不能证明真正的周期阶段或假突破。

先检查 Bitstamp 与 Kraken 原生四小时各自行情；2017 原组合触发多根跨所极值差警报后，按[补充定义](周期研究-2017二季度-Bitfinex补充定义-20261104.md)再取 Bitfinex 原生1小时数据并自身合成4小时，与 Bitstamp 单独组成第二配对。这是见到质量警报后的事后补充，不改变或撤销原组合 UNKNOWN。
