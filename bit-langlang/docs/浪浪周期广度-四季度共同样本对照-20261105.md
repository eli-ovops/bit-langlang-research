# 周期与参与度：四个近年季度的共同小样本

## 结论

跨币短期上涨数量能补充描述 BTC 背景，却不能单独确认震荡末期、启动或主升。此前记录的 2026 年 1 月样本短期参与下降与 BTC 之后回落值得继续研究，但对照中也有此前参与很低、BTC 随后上涨，以及此前参与很高、BTC 随后下跌的例子。**现在不应把参与数量阈值当成交易信号或浪浪本人规则。**

## 方法与限制

基于先前固定的九个历史存量 Binance USDT-M 永续日线样本。2022/2023 四季度是在看过 2024/2026 统计后追加，不能称盲测或无偏样本外。[补充范围定义](浪浪周期广度-2022与2023补充定义-20261105.md)。每个时间点以前 29 个完整日线同时计算样本过去 7 日和 28 日方向；缺口或质量不足为 UNKNOWN，不填补、不能因文件没有记录就断言当时未上市/退市。

九个样本中，2022Q4 有效数每天 5 或 6 个，2023Q4 每天 8 或 9 个，2024Q4 和 2026Q1 均是 9 个。由于分母变化会影响比较，在看到各季度可用性后，事后固定所有四个季度均连续有数据的 **DOGE、ETH、PEOPLE、SOL、TRB 五个合约**，另作分母敏感性检查。[五币事后定义](浪浪周期广度-四季度共同子样本补充定义-20261105.md)。这不是交易币选择，也不是对其品质、流动性或当前适合买入的评价；它们过去被项目选择并幸存，交易所与题材均偏，不能代表全市场、真实情绪、资金流或用户希望选取的强势龙头。

BTC 背景与后续价格使用此前 Bitstamp/Kraken 现货复盘，五个合约为 Binance 永续；不能拼价或视为同一产品。7 日和 28 日均为观察当时之前的价格方向；下表事后 BTC 变化是**后来 7 个完整日的收盘变化**，不是观察当时已知、不是收益或独立阶段真值。

## 同一固定分母下的对照

| 观察时点 UTC | 当时已知：5 个样本过去 7 日 / 28 日上涨数 | BTC 当时观察 | 之后 7 个完整日末 BTC 日收变化，Bitstamp |
|---|---:|---|---:|
| 2022-11-05 | 5/5；5/5 | 较长研究窗口区间内，中短窗口向上，接近过去参考上沿。 | **-19.60%** |
| 2023-10-15 | 1/5；2/5 | 中长研究结构向上、短期向下；更大背景有交易所分歧。 | **+11.44%** |
| 2024-11-05 | 0/5；2/5 | 中长研究结构向上、短期向下。 | **+30.89%** |
| 2026-01-15 | 5/5；5/5 | 三层研究结构向上，价格已在两所旧参考上沿之外。 | **-7.81%** |
| 2026-01-16 | 3/5；5/5 | 三层研究结构仍向上，两所均已连续三日收在旧上沿之外。 | **-6.40%** |
| 2026-02-19 | 5/5；0/5 | BTC 较长研究结构向下，短期回升。 | **+2.36%** |

这些时点是看过历史后选出来便于解释的例子，不代表所有区间，不是同一个受控场景：各自 BTC 背景、位置、参考边界和市场状况不完全相同。2026 年 1 月 15 至 16 日，五币短期上涨数从 5/5 变 3/5，而较长 28 日仍 5/5，属于当时可观察的尺度分歧；不能凭此一个案例声称该下降有预警能力。2026-02-19 则五币短期全涨、较长窗口全跌，提示需要区分局部反弹与更大级别变化，但不能直接判断为启动。

## 数据差异与验证

2022/2023 共 18 次 Binance 公开历史日线请求。本地和响应在可重叠部分逐项一致，但 2023Q4 的 ORDI 接口还返回 **2023-11-07** 一条更早日线，本地文件从 11-08 开始，因此该季度 ORDI 的总体核验结果标记 **MISMATCH**。没有覆盖或改写本地文件：涉及缺失日的观察依旧 UNKNOWN，完整 29 日窗口直到本地能覆盖后才计入；结果不能解释为已核实的精确上币日期。[原始响应、逐项核验与差异](../data/verify/cycle-breadth-archive-2022-2023-20261105-01/summary.json)。

对 2022/2023 的 **1,266 个有效币种/日点**直接从保存的 API 响应独立复算 7/28 日变化和全部日分母，结果与本地输出一致；2024/2026 的 1,638 个币种/日点也已从 API 响应独立复算。四个季度共同五币共 366 个观察日均有五个有效对象；另在四个日期和五个对象上改变观察时刻之后的数据，验证当时输入不变。这些只验证统计和时间截断，不验证交易、市场真实阶段或情绪。
