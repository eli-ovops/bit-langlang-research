# 未平仓与盘口会话风险核对：事前定义

目标：将已保存且形式核验通过的 ETHUSDT 公开盘口会话，与给定的纸面未平仓账本关联；只发现入场之后、本机接收时刻不晚于检查时刻的可确认有限深度买一不高于账本止损的**观察值**。该观察是研究模型的 bid 阈值提示，不是标记价触发、订单成交或账户状态证明。

先核验已有联合风险和各会话的原始文件、单写者归档、快照、序号与有限盘口；会话归档结束时间不得晚于检查时刻。快照本身的准确产生和接收时点不能定位至持仓前后，因此不当作入场后的触损样本；只检查可映射回原始消息的事件最终状态。按会话内本机接收时刻对每个 ETH 多头入场后观察值，与其账本 stop 比较。买一超出有限快照深度或缺失时 UNKNOWN；连续时间路径、同批内部变化、真实时钟、来源、滑点与成交始终 UNKNOWN。

只要一个有效会话观察到触损，或联合账本风控已 STOP，整体返回 STOP；同时保留其他会话无效、缺失或顺序错误等告警。否则，如会话无效则 INVALID；没有足够观察则 UNKNOWN；即便所有检查均通过，也最多 `PARTIAL_DISCRETE_UNKNOWN_PATH`。不得从后一会话的快照回填两次会话之间缺口；缺口与单会话首尾之外均 UNKNOWN。检查只读文件，不创建策略或订单，STOP 是报告状态。

合成测试覆盖正常未触损、确认为触损、损坏会话与有效触损并存、入场之前事件不算触损、结束时间晚于检查时刻和两会话缺口；以先前真实公开采样加明确标注为合成的本地账本进行端到端验证，不得伪称真实持仓或前瞻。
