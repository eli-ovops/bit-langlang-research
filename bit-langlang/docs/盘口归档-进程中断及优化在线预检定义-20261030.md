# 盘口归档进程中断及优化写入器：预检定义

先对新写入器进行两种本地子进程测试：三条成功落盘但未封存后强制终止，恢复检查应返回 `INCOMPLETE_UNSEALED` 且可读三条；第二条或后续记录仅写入部分 JSON 时强制终止，检查应返回 INVALID 并保留此前可校验前缀。只结束本测试创建的进程，保留平台策略状态；这模拟 SIGKILL，不是系统断电或文件系统持久性保证。

测试通过后，依原[单次在线预检定义](盘口逐条归档-单次在线预检定义-20261030.md)用优化写入器再进行一次独立的 8 秒、最多 500 消息的公开 ETH 深度预检：一次连接、一次快照，无订单与账户访问，不自动重试。记录原始消息、快照、序号/盘口结果、归档末尾和封存哈希、本机写入耗时。采集结束后独立核查归档与消息记录一致；无真实持仓，不把本次输出用于正式前瞻。

该短样本和进程中断测试不验证断电、长期吞吐、断线重连、全行情覆盖或真实成交；未知项保持 UNKNOWN。任何平台策略 start/stop 前先告知用户，本次不执行平台策略 start/stop。
