# Kraken 历史档案的 BTC/USD 可行性检查

2022-04-04 远支撑已知结果且使用 Bitstamp/Bitfinex；此前案例分钟补取了 Kraken/Bitfinex。为检验 Kraken 是否能提供它自己的完整历史 K 线、进而在后续事后对照中复算背景，先只检查 [Kraken 官方拆分 OHLCVT 归档](https://support.kraken.com/articles/360047124832-downloadable-historical-ohlcvt-open-high-low-close-volume-trades-data) 的公开 HTTP 字节范围与 ZIP 目录：对五个公开 part 各请求单字节以记录总长度，对末 part 获取尾部至多 65536 字节并检查 ZIP 目录。若服务器不支持准确 206/Content-Range、目录非标准/不完整、访问拒绝或范围不可核实，立即标 UNKNOWN，不下载整包、不更换身份、代理或绕过限制。

若能确定官方 ZIP 中 BTC/USD 本所 240 分钟 OHLCVT 成员的位置、长度、压缩类型与 CRC，另事先书面限定需要的成员范围和大小上限后再考虑读取。仅目录不是行情，分块读取若未校验整包 SHA 不能称整包已验证；即使成员 CRC 通过也不等于成交真实、未来数据完整或未参与设计。此为公开来源可行性检查，不选币、不入场、不交易、不操作代理 start/stop。
