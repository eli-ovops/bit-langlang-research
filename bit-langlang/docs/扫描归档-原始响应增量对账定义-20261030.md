# 扫描归档：原始响应增量对账定义

针对已绑定公开请求及原始响应的扫描归档，按提交序号重建行情快照。自第二次提交起，取前一次已恢复行情，按本次保存的服务器时间、BTC/ETH K 线分页响应重放现有 `load_base` 与 `advance`，逐币比较重放所得原始 CSV 字节与当前已恢复行情解压后的字节；检查请求分页参数、请求时间顺序、服务器时间与本机采样时间的 2 秒门限，以及请求结束不晚于扫描生成时间。

首次提交只保存采集后的行情，没有绑定采集前的初始基线，因此首个过渡标 `UNKNOWN_INITIAL_BASELINE`，不伪造验证。旧提交缺原始响应时该过渡标 `UNKNOWN_SOURCE_MISSING`；后续如同时有上一快照和本次响应，仍可独立核对后续过渡。响应哈希不匹配、时间或分页不合规、重放 CSV 不一致返回 INVALID。

这是一项本地字节与流程一致性检查：重放复用采集器本身的解析代码，不是独立实现；哈希、响应、服务器时间与本机时钟均未独立认证，也不能证明 API 数据正确、持续覆盖、持仓或成交。即使所有可验证过渡一致，最多报告 `PARTIAL_SOURCE_REPLAY`，同时列出首个未知及是否提供预期归档头部；不启动采集或策略。
