# 2023 年 11 月归档与 API 差异：事后敏感性定义

在扩展归档参与统计之后，以先前九个合约的公开 API 做重叠日抽核时，发现六个合约的 2023-11-10 日成交量在归档与 API 中不同；这是一项**看见原结果和差异后新增的事后敏感性检查**，非事前冻结或独立验证。两端 OHLC 相同、双方成交量均为正；差异原因未知，不能认定哪一方正确，也不能擅自覆盖原始文件。

保留按 checksum 有效归档计算的原始结果。作为保守敏感性，凡观察日的此前 29 根日线依赖 2023-11-10 时，从归档有效集合中额外排除六个已知成交量不一致的合约；其余所有合约保持原值。逐日记录修正前/后的有效数、7/28 日上涨数、固定假设下分类及变化，不篡改原始数据，不将排除解释为未上市、无交易或下跌。只有额外排除相关日，不把抽样只查出的六个问题说成其他全部合约无差异。

把当前已核对的九个合约全部重叠日 OHLCV 差异及不一致日记录；来源 API 与月归档即使同属 Binance，也是不同发布时间和接口，不能确定差异发生时间、原因或哪端正确。真实市场广度、真实情绪及浪浪本人阶段仍 UNKNOWN；本项仅研究数据质量对聚合结果的影响，不选币、不入场、不交易、不执行 start/stop。
