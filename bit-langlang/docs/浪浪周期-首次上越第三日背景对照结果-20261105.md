# 首次上越第三日：大背景、位置与资金费的回顾对照

## 主要发现

把大级别位置加回以后，相似的局部上越呈现了不同背景：**2024-10-18 与 2026-01-16 的此前 21 次资金费都为 19 次正、2 次负，第三个日收也都在各自固定上沿上方；但 BTCUSDT 永续最近日收在此前一年范围内的位置分别约 85.85% 和 40.79%。**两个日期之后 28 日日收分别上升和下降。大级别位置值得与局部结构分开看，但这一事实不能证明位置导致不同结果，也不能反推某个观察时点的真实阶段。

2025 年两次观察的年度位置都接近各自范围高端，而后续 28 日价格分别接近平盘和下跌；这也提醒我们：**一年位置高低不是单独足以判断启动或反弹的规则。**所有比较点、历史和部分后续事先已知，是事后解释，不是独立留出、真实阶段准确率、交易收益或浪浪本人判读。

## 样本与口径

保留[上一轮](浪浪周期-区间上越后连续收盘对照结果-20261105.md)六个季度的全部两所来源级记录：每季只看首次从固定区域内/下方日收上越后的第三个已完成日收，2022Q4 两所无上越，保留 NO_CROSS，不将其当没有行情。上越后三次日收不全在上方的 2023Q4 仍保留。各期和后续结果已被研究，六季度非独立试验；相邻日及两所不是独立事件。

针对其余十个来源级时点补充 BTC/USD 现货此前 28 日价格范围和旧 56/28/8 结构；另以 Binance BTCUSDT 永续**此前 365 个完整 UTC 日**的最高、最低和最近日收计算相对范围位置 `(收盘−最低)/(最高−最低)`，以及距高点百分比。年范围只是背景坐标，不是预期剩余空间或真实压力；与 BTC/USD 现货是不同交易所和产品，不能拼价。费率仅用 t 前七天各次 Binance BTCUSDT 永续结算，不能代表人数、全市场资金流或真实心理。[本轮定义](浪浪周期-首次上越第三日背景对照定义-20261105.md)

## 后来才知道的价格事实与反例

以上五个时点之后 28 个完整日日收相对当时依次约 **+26.34%、+29.59%、-0.77%、-10.43%、-30.73%**，仅用于回顾反例，不是当时可用信息、交易回报或阶段真值。2024 与 2026 年费率正负数相同但年度位置和后续路径不同；2025 两点年度位置相近但后续幅度也不同。因此无论只看三日收、资金费，还是只看年度位置，都不能可靠地区分下跌反弹与真正启动。

表中 2023 年在第三个日收已经回到固定区间，后来仍出现上涨；不能机械把“收回一次”定义为启动失败。同样，2026 年第三次仍在上方、三尺度代理向上，不能机械把它定义为启动成功。因两组不是受控实验、选例已见，不能归因于任何单个维度，也不能挑阈值后声称已验证。真实阶段和浪浪同期判断均保留 UNKNOWN。

本轮没有对所有观察点取得同口径、完整的市场广度或全市场情绪，因此不将此前个别案例的样本上涨数拼成横向排名；有差异的缺失是 UNKNOWN，不当成零。继续研究需要将已形成的假设和独立人工标准用于未参与设计、完整不同环境，并保留非上越和反例，才可能检验其区分能力。
