# 2015 年：摆点过时后保留价格事实

**结论：将“摆点过时”和“当前价格位置”分开，能在部分旧规则留空的时点保留已知价格事实；它没有解决春秋识别，也没有证明漏判率下降。**双所可能都在旧摆点外，但这可以随后延续，也可以迅速返回。不能将历史穿越当成观察时的新突破，不能把价格事实升级成真实阶段或浪浪本人的规则。

## 事前范围及实际数据

本轮 [事前定义](摆点过时之后-价格状态与跨所覆盖-2015事前定义-20261102.md) 保留 2017 的 56/28/8 日固定背景、56 日摆点及摆点过时规则，另记最近已完成日收盘相对各自已确认高低摆点的位置：高于高点 ABOVE、低于低点 BELOW、其间 INSIDE。旧摆点若曾被完整日收盘穿越仍标 STALE，价格之后收回不重置它；新字段只是价格位置，不是新的春秋或交易信号。单所事实与双所共同事实分别输出，不能用一所补另一所。

目标为 2015-06-01 至 11-23 每周 26 点、价格自 04-01 至 2016-01-01，BTC/USD 现货。定向检索未发现该时段用于本规则设计，公开历史可能已为模型或研究者所知；不能称严格盲测、完全未见或前瞻。

原先预定 Bitstamp–Coinbase：Bitstamp 4h 网格 1650/1650；Coinbase 从原始 1h 严格聚合得到 984/1650 个完整 4h 柱（缺 666；原始小时缺 2661），不可称完整跨所行情，也不能把缺小时理解成必然无交易。查看行情缺口、**尚未计算判断或未来结果前**，固定 [补充来源定义](2015跨所覆盖-Bitfinex补充来源事前定义-20261102.md)：同时保留原组合，另加独立 Bitstamp–Bitfinex 组合。Bitfinex 原始 1h 自身聚合得 1648/1650 根 4h，缺 08-24 04:00、08:00 UTC 两根；仍不是全段完整。

Bitstamp–Coinbase 同时存在柱的高低价差超过 10% 警报的有 0 根；Bitstamp–Bitfinex 则有 2 根，分别为 08-18 20:00、08-19 00:00 UTC，最低价差别明显。可能是异常成交、缺陷或两所真实交易差异，原因 UNKNOWN；该组合两所将对应整日及受影响窗口保守留空。另一组合没有该组的质量标记，故 Bitstamp 在两组中同一时点的可用性可以不同，但底层原始行情没有被修改。10% 是研究数据质量警报，不是交易门槛，也不能认证未报警价格正确。数据来源、时间缺口和哈希见 [Bitstamp/Coinbase](../data/market/btc-2015-usd-cross-20261102-01/manifest.json)、[Bitfinex](../data/market/btc-2015-bitfinex-20261102-01/manifest.json)。

## 同一个状态，后来可以不同

以下时点为 UTC，分别使用本所边界。观察时的 P 为前一完整日收盘；观察后只在真实日线结束时记录返回，不能倒填观察日。

- **06-15，可能没被旧留空展示的上行事实：**Bitstamp P=232.09、确认摆高 H=230.79；Bitfinex P=233.54、H=232.07。两所旧摆高已在 06-14 被收盘越过，所以旧组合 UNKNOWN；新字段均为 ABOVE。其后 28 个完整日中两所日收盘都未回到各自 H 下方；第 28 日结束时 Bitstamp 为 310.55、Bitfinex 为 311.15。这是该窗口内的事后事实，不能证明 06-15 就是真正春天。
- **07-06，同样两所 ABOVE，却很快收回：**Bitstamp P=271.50、H=268；Bitfinex P=271.96、H=269。07-08 00:00 UTC 两所日收分别为 265.51、265.72，已回到各自 H 以下，7 日内返回代理成立。它证明 ABOVE 不能等同“突破必然持续”，但也不能由此判断真实春秋。
- **06-01，两所 BELOW 并非必然持续走弱：**Bitstamp P=228.91、确认摆低 L=233.10；Bitfinex P=228.70、L=235。两所 7 个完整日内未收回 L 上方，但 06-16 00:00 UTC 分别以 235.92、236.98 回到本所 L 上方，属于 28 日内返回事实。回到边界内不把旧摆点自动恢复为有效，也不表示已确认春天。
- **10-26，两所 ABOVE 后在 28 日内未回收：**Bitstamp P=283.96、H=273；Bitfinex P=284.79、H=275.19。其后 28 个完整日未以日收盘回到各自 H 下方；第 28 日结束时分别为 324.20、324.66。这里新字段保留了较强价格位置，但即便事后上涨也不能反证旧时点的真实季节。

另一来源组合及包括 INSIDE、分歧、UNKNOWN 的完整时点均在 [两所逐点表](../data/verify/market-2015-position-20261102-01/pairs.csv)、[单所状态](../data/verify/market-2015-position-20261102-01/asof.csv)、[事后 7/28 日和固定区间事件](../data/verify/market-2015-position-20261102-01/future.csv) 中；不只展示这些例子。

## 验证与边界

[独立复算](../data/verify/market-2015-position-independent-20261102-01/summary.json) 直接从原始 4h 重算两组共 104 个来源/时点的固定层、摆点确认与过时、单所位置、两所状态、104 条固定区间事件和 76 项后续期限检查；摆点/状态/事件独立实现，固定区间关系复用既有 helper，一致。Coinbase 984 根、Bitfinex 1648 根有效 4h 柱分别从原始 1h 独立重算。22 项合成/回归测试覆盖等值、过时后收回仍过时、未来扰动、确认延迟、缺柱与两所分歧。

仍缺独立人工真实阶段标签、情绪和当时资金动因，不能说找到了可交易的春秋判断；即使两所同向，市场与价格源相关，也不证明真实阶段。下一个必要问题不是继续把 UNKNOWN 改名，而是先确定独立判读标准和人类逐点标签，评估这类价格状态能否在同等可见信息下区分启动与反弹；未有标签时只能报告竞争解释。此轮未选币、入场、交易或操作平台 start/stop。
