# 同刻止损组合亏损：事后描述定义

沿用已研究的四份双延迟历史已平仓账本，按相同 UTC `exit_ts` 将 `stop`、`stop_next_open` 止损交易分组。对每组统计笔数、各笔净损益合计、各笔初始价格风险合计及前者除以后者；报告多笔同刻组数、最差同刻组合和所有同刻组明细。不得将每笔净 R 直接相加当作组净 R；分母为该组初始价格风险总和。期末未平仓不在这些组内，数量单列。

止损事件按模拟记账时间聚合；同柱止损时间可能被统一记为柱末，非真实同时成交。净损益包括各笔从入场到出场的所有手续费、资金费和价格损益，不是该时刻的现金变化；无同期可靠组合权益时不得换算为账户回撤比例。不同组数据依赖历史仓位和同一信号，事后统计不等于未来损失概率或风险上限。保存输入账本哈希和明细，不启动策略或修改冻结规则。
