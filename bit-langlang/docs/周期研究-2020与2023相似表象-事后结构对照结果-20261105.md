# 相似窗口、不同局部结构：2020 与 2023 的事后对照

## 结论

上一轮的两个 BTC/USD 案例，在观察时点的 56 日和 28 日固定窗口均上移、8 日四小时窗口均下移，前28日区间位置接近；但从当时已确认的局部日线摆点看，并非完全相同：

- **2020-08-26 00:00 UTC**：两所最近两个已确认摆高和摆低都抬高；不过，最新确认摆低已经被上一完整日收盘跌破。较长局部结构的抬高与最新价格走弱同时存在。
- **2023-02-12 00:00 UTC**：两所最近两个已确认摆高降低，而摆低仍抬高，局部结构为混合；此前已有完整日收盘跌破最新确认摆低。

两例都不能仅以“长中窗口向上、短窗口向下”概括全部价格结构；但它们的最新确认摆低在观察时均已被日收跌破，这一事实也不能单独区分正常回调和衰退。真实阶段、真实漏判和假突破均 UNKNOWN。观察到的局部摆点差异是**事后提出的待验证研究问题**，不是能预测后续走势的已验证规则，也不是浪浪本人给出的精确公式。

## 当时已确认的局部日线摆点

沿用项目已有的研究代理：候选日的高点严格高于前后各两个完整日高点才为摆高，摆低相反；候选日 UTC 00:00 加三天后才确认，等值、同日同时为高和低不计。任何一个摆点必须已在观察时点之前或当时可知，不能把后来确认的点倒填。这只是可复核的局部结构方法，不声称浪浪使用了左右两日。

| 案例 / 所 | 前一个已确认摆高 → 最近已确认摆高 | 前一个已确认摆低 → 最近已确认摆低 | 观察时局部结构 |
|---|---|---|---|
| 2020 / Bitstamp | 12,080 → 12,473 | 11,130 → 11,367 | 高、低均抬高 |
| 2020 / Kraken | 12,082.9 → 12,480.6 | 11,133 → 11,350 | 高、低均抬高 |
| 2023 / Bitstamp | 24,258 → 23,439 | 22,504 → 22,643 | 高降低、低抬高，混合 |
| 2023 / Kraken | 24,282.1 → 23,450 | 22,519.2 → 22,599.9 | 高降低、低抬高，混合 |

2020 两所最新摆低均发生在08-22、08-25 00:00 UTC才可确认；08-25 完整日收盘低于该点，于08-26 00:00 已可见。2023 两所最新摆低发生在02-06、02-09 00:00才确认；02-10 00:00已可看到其后一个完整日收盘低于该点。2023最近摆高02-08形成、02-11 00:00确认，与此前02-02的摆高相比降低。

必须将“摆点高低的历史关系”和“最新价格是否已经越过该摆点”并列：2020的两个高低点虽然都抬高，但截至观察时最新低点已被完整日收盘跌破。这个事实本身仍可能出现在正常回调，也可能是进一步转弱的早期迹象，不能据此认定秋天。2023低点同样已破，但高点关系不同；也不能因为高点降低就断言趋势必然结束。机械摆点只是可观察结构，不是阶段真值。
