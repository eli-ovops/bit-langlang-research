# TPH v2 最终验证：全样本 vs 冻结样本外（含选择器/季节过滤）

> 组合层：2000U、单笔风险 0.1%、并发 1/3、5x 杠杆上限、资金费+10bp。
> 选择器：每日用前一交易日的 rs7 排名取 Top-K 币（不引入未来）。季节：BTC risk_on。
> 数据：2022-05~2026-10（全样本）/ 2024-07~2026-10（冻结样本外，策略参数不改）。
> 代码：`verify/final_validation.py`；结果：`data/verify/final_validation.json`。

## 0. 结论

**全样本好看，样本外为负；选择器无效、甚至有害；跑输 BTC 买入持有。**

| 区间 | 版本（risk 0.1%, conc3） | 年化 | 最大回撤 | Sharpe |
|---|---|---|---|---|
| 全样本 2022-05~2026-10 | 全部信号 | **+20.2%** | −34.7% | 0.60 |
| 全样本 | +季节过滤 | +11.7% | −38.7% | 0.70 |
| 全样本 | +Top3 选币 | −6.0% | −40.8% | −0.23 |
| **OOS 2024-07~2026-10** | **全部信号** | **−3.6%** | −33.3% | **0.28** |
| OOS | +季节过滤 | −3.3% | −26.1% | 0.29 |
| OOS | +Top3 选币 | −17.1% | −37.6% | −2.96 |
| **基准（BTC 买入持有）** | 全样本 +17.8% / OOS **+11.0%** | | | |

**样本外：策略 −3.6%，BTC 买入持有 +11.0%/年——策略没有跑赢最简单的基准，且回撤更大。**

## 1. 关键发现

1. **全样本的正收益来自 2022–2024 的行情**；2024-07 之后同一套参数转为负。
2. **选择器（rs7 Top3/Top5）在全样本和样本外都让结果变差**——再次验证"选币无 alpha"。
3. **季节过滤（BTC risk_on）能降低部分回撤，但不能把 OOS 翻正**。
4. **同期 BTC 买入持有的年化（全 17.8%、OOS 11.0%）都更高**；本策略在 OOS 还承担了 −33% 回撤。
5. 由于形态参数（0.4% 止损/趋势出场）本身是在全样本上确定的，真实样本外表现只会更差，不会更好。

## 2. 这意味着什么

- 之前"组合层能赚钱"（全样本 +20%/年、0.1% 风险）是**样本内结果**；
- 冻结样本外推翻了它：**该做法在 2024-07 之后没有正收益**；
- 加上此前的 v1/v2、选择器、空头镜像、平台马丁测试，**目前没有任何一条证据支持投入资金**。

## 3. 还剩什么没试（诚实清单）

| 方向 | 为什么可能还有机会 | 代价/风险 |
|---|---|---|
| 不同出场（更长/更短、ATR 跟踪） | 我们只测了 EMA20 趋势出场与固定持有 | 参数搜索=过拟合风险 |
| 只做 BTC/ETH（流动性更好、成本更低） | 山寨成本/滑点更高 | 样本更少 |
| 空头在真正熊市 | 2022 空头 72h +0.6R | 2024-2026 是负的 |
| 事件驱动/资金费/基差 | 与 K 线形态无关的新 edge | 需要新数据与基础设施 |
| 放弃主动交易 | 研究已多次证伪 | 机会成本 |

## 4. 最终判定（本项目）

> **TPH v2 在冻结样本外为负、跑输买入持有；选择器无效。**
> **"复刻他的做法能赚钱"这一命题：在 2022–2024 样本内成立（本质是趋势行情+凸性），在 2024-07 之后不成立。**
> 结论：**继续 0 资金；要么换一个全新的 edge 来源，要么停止。**
