# 盘口有限深度重建：离线研究定义

在 `paper-depth-sequence-v1` 输入中增加快照 `snapshot_bids`、`snapshot_asks`（每项 `[价格,数量]`），每个增量含原始 `b`、`a` 价量更新数组。只应用上一阶段序号核对接受的连续前缀；保留 GAP 或 INVALID，不重接、也不将后续消息当作连续数据。标的限 ETHUSDT。精确十进制处理价格数量，快照数量须正，增量数量为 0 删除对应价位、正数为绝对数量；删除不存在的价位允许。价量无效或重建出的买一不低于卖一则 INVALID。

快照只包含有限深度：买一若低于初始快照最低买价，或卖一高于初始快照最高卖价，相应一侧标 UNKNOWN，不能将已知列表末端以外的价格当成完整盘口。无某侧价位也标 UNKNOWN。即便重建序号与有限深度规则一致，来源、真实性、遗漏首尾、RPI、网络延迟、真实盘口和成交仍 UNKNOWN。增量可能合并同批多个变化；不能由最终状态推断批内没有更低价格或触损。

允许给一个正数 `research_bid_threshold` 仅作研究参考：在快照及每条已核验的增量完成之后，记录可确认买一是否不高于该阈值。它没有绑定任何交易、事件时间或订单，不能作为真实持仓触发/成交证明，也不能据未观察到触及断言安全。已观察触及后发生断链或数据异常时保留此前结果，同时明确整体 GAP 或 INVALID。

仅离线读取 JSON、不访问网络、不启动平台策略。合成测试覆盖快照桥接、价量替换/删除、丢链、有限深度耗尽、无效价格/交叉盘口、买一阈值、批内未知与哈希；真实捕获、持仓绑定、断线恢复与数据认证均待完成。
