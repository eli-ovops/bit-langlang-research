# 回踩研究：匿名判读材料制作口径

先冻结[回踩定义](浪浪周期-日线突破后回踩研究口径-20261105.md)及[既有 26 个观察](浪浪周期-回踩补充回顾与独立验证缺口-20261105.md)，不按信号或结果筛图；覆盖 2023Q1、2025Q2 的全部观察，包括非触发。两季早已被项目研究，不是独立样本，也无法保证研究者和评审未见过图形。

每张图只展示该时刻以前已经收盘的 56 个 UTC 日线，左图全部 56 日、右图最后 14 日；逐日价格按各图最后收盘标准化为 100，不显示日期、资产、实际价格、信号及未来结果；时间轴显示距观察日的相对日数。两图是同一份价格的不同视野，不能看成独立证据；只显示价格而不显示大于 56 天背景、成交广度和情绪资料，限制判读。素材不能满足的维度必须 UNKNOWN。显示源为 BTC/USD Bitstamp 日线，评审前不在材料里展示以减少认图；日线每根由六根有效 4h 柱合成。资产、市场结构或归一化图形仍可能被认出，存在猜测答案风险。

打乱全部样本顺序，以匿名编号输出图、空白判读表及说明。各样本的日期、图源、信号及事后结果只写入另一个私有对照文件，不放在评审包，也不向评审者展示。目录隔离不等于技术加密或双盲。对应表保留每一个非触发、已越高、未知及截断后的结果；未来不能用未发生过的部分补足。先收集并保存评审的原始意见、是否认出盘面及记录时间，之后才揭开对应关系比较，不能按后续价格修改原判读。阶段按 v2 草案记录支持与反证，评审可以多选、留空或声明认出行情；价格不是情绪。
