# 2024Q2 归档成交量差异的事后敏感性定义

已计算本轮归档逐日参与和 BTC 候选后，抽查固定的 DOGE、ETH、PEOPLE、SOL、TRB 五个合约，在 2024-03-27、03-28 的月归档与同所公开日线 API 发现 10 处成交量差异，两个来源的价格字段一致，成交量均正；产生时间、原因与哪方正确未知。先保留原始 checksum 和 API 响应，不覆盖或填补。

作为事后质量敏感性，若观察时点此前 29 个完整日日线包含任一差异日，则从该日的归档有效合约集合中额外排除这五个已知受影响合约；其他对象维持原值。在原始与敏感性数据中同时记录有效分母、7/28 日上涨数、此前写入的分歧候选组，并保留全部日。若额外剔除后分母为零则 UNKNOWN；不得根据结果改候选、筛日期或称其他未抽查合约不存在差异。此步骤不验证市场情绪或真实阶段，不选币、入场、交易或执行平台 start/stop。
