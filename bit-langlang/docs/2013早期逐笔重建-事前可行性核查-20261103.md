# 2013 早期逐笔重建：事前可行性核查

上一轮发现 Bitfinex BTC/USD 2013 年 1–3 月小时 K 线缺口，不能因此假定没有成交。为核查来源能力，在请求下述历史逐笔、查看返回前固定单一连续窗口 [2013-01-20 00:00,04:00) UTC，选择日期是早期已有筛查预热起点，不以此窗口的支撑状态或未来结果筛选。窗口此前已作预热，前序筛查亦看过该时期；本项是数据可用性实验，不是未接触、独立样本或事前市场阶段验证。

使用 [Bitfinex 官方公开历史逐笔](https://docs.bitfinex.com/reference/rest-public-trades) tBTCUSD，逐小时请求 start 含、end 下个小时减 1 毫秒、正序、limit=10000；保留原始响应、请求及 SHA-256。逐笔核价格正、数量非零、时间范围、ID 唯一。空小时、异常、达到返回上限、重复 ID 或未能证实记录完整时不能作为完整小时；不得用其他交易所补。按交易所响应计算每小时最高、最低、绝对成交量和首末价格；同毫秒多笔影响首末顺序则不认证开收。将此窗口与已保存的同所原始小时、4h，以及 Bitstamp 对应 4h 分开对照；Bitstamp 正成交量仅是其自报记录，不当作逐笔证明。没有独立逐笔可认证的全区间或独立人类阶段参考时，用户要求的严格验证未完成。

只作历史数据核查，不改规则，不选币、不入场、不交易、不执行代理 start/stop。来源响应不等于其真实成交或历史绝对完整。
