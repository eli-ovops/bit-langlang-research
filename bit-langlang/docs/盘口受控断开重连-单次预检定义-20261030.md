# 盘口受控断开与重新连接：单次预检定义

目的：在没有持仓、账户或订单的情况下，检查一次短时公开数据断开后，重新连接能否分别获取快照、建立新序号接合和归档，同时将两次会话之间的未观察区间标 UNKNOWN。此预检是两次明确顺序执行的独立有限采样，不是正式前瞻或后台持续服务。

使用 `verify.depth_capture_preflight --journal` 顺序运行两个全新目录，分别最多 8 秒或 500 条、一次 WebSocket 连接及一次公开 ETHUSDT REST 快照。第一会话退出并产生有效本地封存、序号和盘口形式结果后才执行第二会话；若第一会话失败、不完整或接口拒绝，立即停止，不以第二次绕过、换身份或重试。两者都成功后使用 `verify.depth_sessions_audit` 检查原始文件、顺序及哈希，报告第一会话最后接收与第二会话首次接收之间的本机时间差；此范围一律 UNKNOWN，不能回填为未触损。

分别保留原始响应、消息、逐条归档、错误与哈希。记录这是人为结束第一进程后运行第二进程，不能称为系统自动断线检测或自动重连；本机时钟、来源和首尾覆盖未独立认证，短样本不能证明高峰吞吐、无丢包、真实成交或止损执行。任何平台策略 start/stop 前先告知用户；本次不访问账户、不下单、不启停平台策略。
