# 近期亏损构成：事后描述定义

使用已存在、已反复研究的 `data/verify/fixed-notional-20261030-01/later_b_equity_closed.csv`，描述 2025-10-01 至 2026-10-25 独立重置账户的权益比例规模模型已平仓记录。定义在结果已被研究后制定，不是事前注册或独立样本外检验；不调整规则，不据此选择参数或预测未来。

按已有 `reason` 统计笔数及净盈亏；按账本成交价（已含假设滑点）计算毛盈亏、已记双边手续费、带符号资金费和净盈亏总额，核对 `gross_pnl - entry_fee - exit_fee - funding_paid = net_pnl`。单独统计成交价毛盈亏为正但扣除手续费和资金费后非正的数量。假设滑点已体现在成交价，不另扣一次；价格影响与手续费、资金费之外的真实成本仍 UNKNOWN。检查期初 2000 与期末权益、平仓数及未平仓情况是否与原汇总相符，保存输入哈希和逐笔差异上限。

这是记录构成而非因果分析：规模和后续入场受现金、并发、规则影响，不能从账面毛亏与费用之和推断“如果没有费用将取得同样交易路径”。亏损可能与信号、市场、止损、执行假设等共同相关，单笔分组、样本过少和被重复研究都限制结论。
