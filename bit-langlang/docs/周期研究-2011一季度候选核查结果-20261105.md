# 2011 年一季度：候选与数据可用性核查

## 结果

已于查看行情前固定 [2011-01-01, 2011-04-01) 的全部 90 个 UTC 日点及 [2010-10-09, 2011-04-29) 的价格数据需求，见[事前定义](周期研究-2011一季度候选与质量审查事前定义-20261105.md)。样本是否曾间接参与本项目规则设计为 UNKNOWN，尚未取得行情，亦没有独立评审或经冻结的阶段分类映射，**未完成完整行情或春秋阶段验证**。不能计算启动、反弹、正常回调、衰退的真实误判或漏判。

定向检索 `docs/` 和 `verify/` 中的 2011 年、自然季度和具体日期表达式，未发现本季度直接参与项目规则设计；已发现 2011 年 11–12 月作为 2012 年预热。搜索未命中不是未接触证明，公开历史可能为模型或评审所熟悉；候选选择在看到多轮历史研究之后，因此不能称无条件盲测或严格无污染。

## 实际数据查询

1. Coin Metrics [官方文档](https://docs.coinmetrics.io/market-data/market-data-overview)说明先查市场标识和覆盖目录，目录只显示可用范围，不能证明逐柱完整。首次误用 `mtgox-btc-usd-spot` 返回 400；查询官方交易所清单找到正确标识 `mt.gox`，随后[市场参考目录](https://community-api.coinmetrics.io/v4/reference-data/markets?exchange=mt.gox&page_size=100)返回 `mt.gox-btc-usd-spot`，HTTP 200。
2. [该市场全部覆盖目录](https://community-api.coinmetrics.io/v4/catalog-all-v2/market-candles?markets=mt.gox-btc-usd-spot&page_size=100) HTTP 200，显示 4h 数据覆盖的最早时间为 2010-07-17 20:00 UTC，最晚为 2014-03-26 20:00 UTC。这只表示提供方目录的时间边界，不保证任意中间柱存在、完整或可靠。
3. 使用无需密钥的 [Community 授权范围目录](https://community-api.coinmetrics.io/v4/catalog-v2/market-candles?markets=mt.gox-btc-usd-spot&page_size=100) 查询，HTTP 403，响应明确为该市场对当前凭据不可用。它不等于历史不存在，也不证明需要何种具体付费方案。未绕过限制、未购买或提交凭据。
4. Bitcoincharts 的 `https://api.bitcoincharts.com/v1/csv/inactive_exchanges/mtgoxUSD.csv.gz` 和 `https://api.bitcoincharts.com/v1/csv/mtgoxUSD.csv.gz` 在本机严格 HTTPS 连接中分别出现 TLS EOF，未获得 HTTP 响应或文件；不能认定资源不存在或永久不可用。查询本机 `LOCAL_BLOCKERS.md` 发现该域名过去已有相同 TLS EOF 记录，本次不降低 TLS、不绕过或重复尝试。

查询只取得目录与错误，**没有下载市场行情，没有生成匿名行情包，没有按走势筛选日点**。目录可覆盖该时间段不代表全年无缺口、有逐笔成交、单所价格真实，或可迁移到现今市场；Mt. Gox 数据是第三方整理，不是当前交易所实时原始响应。其他可合法获取且可验证来源未完成查证。零量、无交易和缺柱要分开看，不能用别的交易所价格补齐。

另一候选 2012 年虽然当年事前检索未发现直接参与所检验规则设计，但后来已作为研究样本使用；并且历史严格质量检查下 Bitstamp 366 个时点的 57 日窗口均受零量日影响，第二来源在 2012 年无可比较柱，因此不能声称满足完整双所验证。[2012 事前定义](摆低回退-2012完整年度事前定义-20261103.md)、[质量更正](零量柱敏感性与双所候选筛查-20261103.md)。
