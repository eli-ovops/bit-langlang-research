# 固定区间上越与连续日收：回顾性对照定义

用户的问题是区分下跌反弹和启动。本轮只考察一个更窄的研究问题：在已有完整季度中，首次日收上越期初固定上沿后，第三个完成日收仍在上方与否，是否足以确定之后价格行为。**它不是浪浪规则，也不是启动或主升的真值。**

范围固定为已有完整期初冻结区间日点的 2022Q4、2023Q4、2024Q4、2025Q3、2025Q4、2026Q1。三个 2022–24 季度使用各期 Bitstamp/Kraken（2024 为 Bitstamp/Bitfinex）；2025Q3 Bitstamp/Bitfinex；2025Q4 和 2026Q1 Bitstamp/Kraken。所有行情及部分后续结果已被项目多次研究，方法也是在知晓多个反例后提出，整个结果为**适应性回顾**，不能叫预注册独立检验、阶段准确率或盈利。

每季度每所按既存、各所独立的期初固定区间，查找季度内首次由区间内或下方变为日收上方的事件；期初已在上方、输入缺失、交叉从 UNKNOWN 恢复、或事件后 2 日数据不足，均列 UNKNOWN，不补所。无首次上越则 NO_CROSS；这不是没有行情或没有启动。发生首次上越的日收时刻记 t0，观察 t0、t0+1 日、t0+2 日共三次已完成日收，若三次全 ABOVE 则标三日均上方，否则标三日非全上方；存在缺口标 UNKNOWN。该状态在 t0+2 日收时点才已知，不能归给 t0。

取 t0+2 为比较时点，记录其自身收盘、固定区域及必要的当时背景；随后 7/28 个完整日的结束收盘变化分别记录为事后事实。若任何中间日收质量 UNKNOWN 或末点缺失，则对应窗口 UNKNOWN；不依后续结果改选日期或门槛。7/28 日仅为可复核的研究观察窗口，不能与真正市场阶段或交易盈亏画等号，也不允许据方向独立判对错。全部来源、无上越、未知及事件点保留；两所、相邻日期非独立样本，不报胜率。

核对各输入文件完整 UTC 网格、现有冻结上沿及每日日收质量；逐来源重复计算事件及三日状态，并独立重算百分比，保留输入和结果 SHA。情绪和大背景只取明确对应观察时点之前已记录并可核实的资料；无法取得则 UNKNOWN。不能用后续信息倒填；不选币、不设计入场、不交易、不执行任何平台 start/stop。
