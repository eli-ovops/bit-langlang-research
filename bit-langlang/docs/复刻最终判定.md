## 3. 一个决定性的实测（比任何文档都硬）

用 `verify/replay.py` 按纪律卡条件在 2025-01~2026-10 的 10 币 5m 上回放：

| 指标 | 结果 |
|---|---|
| 原条件警报 | 34,004 个 / 234 天 = **145/天**（14.5/币/天）→ 人不可能处理 |
| Top3/天过滤后 | **3/天**，止损中位 **1.04%**，样本 702 笔 |
| 毛期望 | **+0.014R/笔**（≈0，与"入场 α≈0"一致） |
| 往返成本 | **0.207R/笔**（taker 5bp + 滑点 5bp） |
| **净期望** | **−0.192R/笔**（去最大 5 笔 −0.208R） |

**结论：把纪律卡机械化执行，是一个"可执行但负期望"的流程。** 这说明：
- 纪律能让你"按规矩做"，但不能让流程产生优势；
- 在找到**独立的正 edge**（更低成本、更好出场、或不同市场）之前，照做 = 慢亏。

## 4. 那"复刻他的做法"到底还剩什么

**保留的（可迁移、与 edge 无关）**：
1. 单笔风险上限、低杠杆、不补仓/马丁、止损纪律、日/周亏损上限；
2. 分仓、固定仓位、利润提走（主动选择不复利）；
3. 逐笔记录、4 类复盘、成本 KPI；
4. "开仓后必须在盘"（因为出场 α 是唯一显著项）、"结构失效才离场"、"不因情绪提前下车"。

**删除/降级的（无证据或反向）**：
- 3R 空间硬门槛（事前不可观测）；
- T1 减半（砍掉 98.6% 利润来源）；
- 连亏停机（他 22 连亏、v2 32 连亏）；
- "只做龙头"准入（真样本外为负）；
- "快速砍"作为必然正确（因果倒置）；
- 90 天后凭遵守率加资金（会把慢亏放大 5 倍）。

**不可迁移的**：
- 规模路径（94% 的美元）、2023–24 行情、20 笔尾部、5m 手工盘感。

## 5. 如果继续，唯一合规的路线

```
V0 费率审计（往返 ≤8bp）
 → V1 行为一致性（30–50 笔模拟：五问 100%、止损 100%、零违规）
 → V2 执行可行性（滑点 ≤止损 10%、错过率 ≤20%）
 → V3 成本后期望（≥300–500 笔：净期望 >0、去尾 >0、聚类 t>3.09）
 → V4 真样本外（未来 3–6 个月）
 → V5 行为压力测试（15 连亏/回撤 −10%）
```

**任何一关不过：不加资金、不改参数、不称"复刻成功"。**
在此之前，这个项目的正确状态是：**有一套可执行的合规协议 + 一套验证工具 + 一个未验证的策略假设。**

---

## 6. 最终回答

> **问：我们能复刻他吗？**
> **答：不能复刻他的收益；可以复刻他的"执行与风控"，但必须先把"纪律"和"优势"分开——纪律让你不死，优势才让你赚。**
> 目前我们只完成了前半句的"设计"，后半句（优势）没有证据，机械化实测还是负的。
> 所以：**可以开始验证，不可以开始投钱。**
