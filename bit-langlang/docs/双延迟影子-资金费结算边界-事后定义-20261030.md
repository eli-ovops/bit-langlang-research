# 双延迟影子：资金费结算边界事后定义

对已知 125 笔历史影子账本和公开资金费快照，识别每笔入场或退出前后 60 秒内的结算事件；60 秒是研究性模糊区间，不是交易所统一的实际结算规则。固定每笔的历史持仓数量、入出场和公开记录标记价，逐个计算这些事件的有符号金额。

以固定账本的公开标记价估算为参考，对每个边界事件分别计算“计入该笔”与“不计入该笔”的最小、最大算术和；非边界事件保持既有 `[entry,exit)` 代理归属。仅用于展示给定边界假设的敏感性，不代表事件可独立发生、真实账户的费用区间、最大亏损或未来风险。相同结算时点可涉及多个同时仓位，不把它们当作独立市场事件。

不重新回放现金、保证金、持仓容量或交易路径；真实交易所、结算标记价、费率、仓位先后和强平规则 UNKNOWN。报告输入哈希、完整逐笔边界明细及固定账本假设；历史分析是事后结果，不是前瞻或执行方案。
