# A01 指数历史可得性核对口径

候选为 Alternative.me 官方说明中按日期固定的指数图片模板；确定先查 A01 观察点前一 UTC 日期的固定图 URL，在其所属自然日及观察点之间搜索可用公开存档。仅取 HTTP 200 的最早抓取，保存响应及 Memento，验证其实际不晚于观察点。若图可读，则将图中数值与当前 API 同日期记录对比，并记录图中任何日期或标注；如不存在索引、返回错误、重定向到期后或图片不清，结果均 UNKNOWN，不推断其他地址没有存档。该查询在已知 A01 图和回溯 API 数据之后提出，只能核可得性与历史版本，不能成为样本外阶段验证。

指数字段时间戳、实际发布时刻、存档抓取时刻分别记录，不能混同。单图匹配至多证明抓取时该版本可见，不能证明当日全天可见、原始数据时间截止、其他日期未修订或真实情绪，更不证明浪浪使用此指标。未选币、不设计入场、不交易，任何平台 start/stop 前告知。
