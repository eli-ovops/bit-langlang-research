# 合成一次性扫描归档：完整链路测量定义

在一次性临时目录中，用已保存的 BTC/ETH 历史 5 分钟数据构造各 295 天连续序列，将时间整体移动至本机当前时间附近，以便测试覆盖起点前 205 天预热及约 90 天候选窗口；全部时刻和追加的一根 K 线都是合成的。公开服务器时间及 K 线响应用本地模拟会话替代，不发网络请求，不访问账户，不创建或启动平台策略。

用 `paper_scan_once.run` 的真实写盘、压缩、扫描子进程、回执和归档代码运行一次；记录从调用开始到返回的壁钟耗时、结果状态、两币输入及输出/归档的逻辑文件字节数和文件系统已分配字节数、候选窗口与输入哈希。合成行情时间平移、价格和重编码均不能代表实时行情或真实成交。

这是单次小样本、无网络的功能与成本测量，不包括连续运行、行情延迟、交易报价、资金费、系统中断或 90 天持续性；不能将其外推为性能保证或真实存储需求。临时测试目录为本次工具创建并由临时目录管理器清理，不改动历史行情或用户已有归档；测量结果写入一个新 JSON 文件。
