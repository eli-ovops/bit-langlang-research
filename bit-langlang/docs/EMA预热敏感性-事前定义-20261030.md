# BTC 市场状态 EMA 预热敏感性（执行前定义）

问题：当前扫描器至少要求连续 205 天 5m K 线，但以 205 日滚动历史初始化 EMA50/EMA200 与使用项目全部可用 BTC 日线初始化相比，市场状态是否有差异？此检查只比较输入历史与初始化方式，不调参、不选择收益最好版本。

以 `data/market/BTCUSDT_5m.csv.gz` 为源，限定 2022-01-01 至 2026-10-25 UTC 左闭右开；从 5m 聚合 UTC 日收盘。使用 `adjust=False` 的 EMA50 和 EMA200；每个完整交易日分别计算全部历史初始化的 EMA，以及仅用截至当日最近 205 日收盘重新初始化的 EMA。状态均为 `close > EMA50` 且 `EMA50 > 5 日前 EMA50` 且 `close > EMA200`；比较日状态不一致的日期数量、全量可比较日期数和价格距离。由于方向逻辑在扫描前使用前一日的数据，差异仅说明潜在信号输入受预热影响，不推断策略收益，也不将历史结果当成前瞻。初始 EMA 真值、历史更早的数据与真实行情为 UNKNOWN。保留源文件 SHA-256 和计算结果；不触发平台操作或真实交易。
