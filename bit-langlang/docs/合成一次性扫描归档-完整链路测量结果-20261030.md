# 合成一次性扫描归档：完整链路测量结果

一次本地演练将保存的两币 295 天历史价格的时间整体平移，并追加一根合成 5 分钟 K 线；服务器时间和行情响应由本地模拟会话提供。随后运行实际 `paper_scan_once` 的增量写盘、扫描子进程、回执和首次归档，明确要求候选窗口覆盖约 90 天。

| 单次测量项 | 结果 |
| --- | ---: |
| 调用到返回的壁钟时间 | 1.725 秒 |
| 合成行情输入，逻辑 / 已分配空间 | 4,571,898 / 4,575,232 字节 |
| 新输出目录，逻辑 / 已分配空间 | 4,621,203 / 4,657,152 字节 |
| 新归档目录，逻辑 / 已分配空间 | 4,597,414 / 4,616,192 字节 |
| 每币新增合成 K 线 | 1 根 |
| 有效候选窗口 | 90 天 |

上述输出和归档是独立额外文件；首次归档不能被当作释放空间。耗时不包含准备合成输入或清理临时目录的时间，也不包含真实网络。扫描状态仍为 `INVALID`，本次 113 个 ETH 候选来自时间平移后的合成输入，不是当时实际市场信号、纸面交易或前瞻证据。

测量后复核两份原历史行情哈希未变。完整指标及代码、输入哈希见[机器可读结果](../data/verify/synthetic-one-shot-fullchain-benchmark-20261030-01.json)，口径见[测量定义](合成一次性扫描归档-完整链路测量定义-20261030.md)。本次只测一次首次归档，不代表后续差量大小、真实行情或网络、持续观察、中断恢复、报价及资金费开销，更不能外推 90 天运行可靠性。没有启用任务或平台策略。
