## 3. 交易策略（核心）

### 3.1 第一性原理：先定"市场在哪个季节"，再谈形态

他把技术分析压缩成三样：**周期、空间、情绪**。指标明确否定：

> "技术指标我不看，我也可以明确的告诉你，技术指标是无用的。"（A 级）
> "不看指标，也不是做的突破，只是表面是突破。"（A 级）

**市场四季模型**（B 级，直播反复讲）：

| 季节 | 特征 | 动作 |
|---|---|---|
| **春** | 大饼从盘整启动，山寨共振普涨，但分不清谁是龙头 | 开始找票，相对激进 |
| **夏** | 共振分离，出现特别猛的龙头，"山寨最猛的时候" | 找龙头、敢上仓位、做多 |
| **秋** | 补涨为主、垃圾币乱飞、大饼高位震荡 | 收缩防守、降杠杆、减少开单 |
| **冬** | 全市场熄火（低位退潮是冬，**高位滞涨也是冬**） | 管住手，休息 |

四季的直接作用是**仓位与交易频率**："春夏一天可十几单，秋冬强制压到 5 笔以内"（B/C 级）。

**阶段划分（本人原话）**：
> 震荡 → 震荡中期 → 震荡末期 → 主跌或主升 → 主升中期 → 主升后期 → 转震荡 →（二波，或下沉到更大级别震荡）→ 周而复始

**五浪嵌套**（B 级）：大级别一浪内可再分四季；"五浪结束还走最后一波加速浪，一定是顶部"。

### 3.2 选币：BTC/ETH 定环境 → 热度榜找龙头

- 标的池（A 级原话）：**"BTC ETH Aicoin"**；"aicoin 有排行榜 + 近期明星次新，大饼 + ETH"；"新热门的都会看看"。
- 顺序：**大饼先启动 → 找共振山寨 → 抓龙头**；补涨币"补哪个随机"，尽量不碰。
- 龙头三条筛选（B/C 级）：① 日线结构好（盘整久、离压力位远）；② 第一波跟涨过 BTC；③ BTC 调整时抗跌。
- 同时盯 **4–8 个**标的；每日看热度榜前 10（剔除 BTC/ETH），新上榜的**等调整再做**。

> 比喻（B 级）："补涨永远是你做不到龙头、没有得选了才去找的。就好比一个绝世美女和一个有瑕疵的美女放这儿，你非要选那个有瑕疵的。"

### 3.3 入场：三类顺势位置 + 5 分钟拐点扳机

**六点位优先级**（B 级笔记，A 级原话印证"只做有逻辑的六个点，除此之外都算犯病"）：

| 编号 | 点位 | 优先级 | 说明 |
|---|---|---|---|
| ① | **启动位** | ★★★ 最优，可重仓 | 大级别箱体向上突破；箱体越久越窄越可靠；**不追突破，等回踩**（回到箱顶 3% 内或跌回箱内） |
| ② | **小分歧承接** | ★★ 次优 | 龙头拉升途中第一次回调的低点；**承接不做突破**；第 3 次小分歧不做 |
| ③ | 大分歧摸顶（逆势） | ✗ 不建议 | 他自己有这习惯但明说不建议学 |
| ④ | **二波启动** | ★★★ 最优，可重仓 | 大分歧后箱体，**第二次冲箱顶不过再回踩、踩稳**；回踩到箱体下沿 1/3 且不破前低 |
| ⑤ | 五浪背离高位空（逆势） | ✗ 不建议 | 逆势单"死结" |
| ⑥ | 箱体内反弹 | ✗ 最差 | 箱体内部没有开仓逻辑 |

**扳机：5 分钟拐点**（B 级，标准最具体）：

1. 5 分钟跌出一个低点，随后 **3 根 K 线不跌破它**；
2. 再等 **1 根阳线，收盘价高过前一根 K 线最高价 → 收盘即进**；
3. 中途若再破低点，重新数。

拐点本质："**下降趋势不创新低、上升趋势不创新高**，出现 W/M 之类结构。"

**激进/保守开关**（B 级）：BTC/ETH 已先启动、市场热 → 龙头一拐头直接进；BTC/ETH 都没动 → 必须等确定信号。

**注意**：他真正的做法是"**带预判、尽量不追突破**"（A 级），"假突破能不能识别？——**没有**"（A 级）。所谓"突破"更多是**突破前的结构预判 + 突破后的回踩**。

### 3.4 止损：不固定百分比，固定在"关键位置"

> "任何仓位我都有严格止损的，**开仓必带止损，且严格执行**。"（A 级）
> "止损**并不是绝对的百分比**，看根据市场的拐点也就是防守点位去设置止损。"（A 级）
> "一般是**附近的高低点**止损。"（A 级）

执行细节：

- **开仓前挂好**，单子一开止损已经在了（A）；
- 止损位 = **5 分钟级别最近的相对高低点 / 拐点低点 / 箱底 / 实体支撑区下方 / 大级别关键结构位**；
- 单笔止损金额 **≤ 那份本金的 10%**（A/B）；
- **用标记价格**触发，防止插针扫损（A）；
- 建议**限价止盈止损**（A）；
- **止损距离 → 杠杆反算**（C）：`最大倍数 = 10 ÷ 止损距离%`，如止损 4% → 最多 2.5 倍；
- **止损被打 ≠ 做错**：判据是"是否执行了纪律"。

### 3.5 止盈与出场：由开仓逻辑决定，不由浮盈决定

- 目标位：**日线前高 / 筹码密集区 / 整数关口**；"上方空间不够就不做"（A/B）。
- **两道止盈**（C，与其"先分批止盈"建议一致）：第一压力位出一半 → 剩余**止损推到开仓价（最差保本）** → 拿到第二压力位。
- **盈亏比门槛**：开单前算两道止盈平均盈利% ÷ 止损%，**≥3 才做**（C）；他自评实际盈亏比 **2.5**（A）。
- 持仓纪律：**没触发止损不因情绪提前下车**；"**顺势单可以一直做，做到亏损为止**"（A）。
- 高位/加速段："边拉边跑"；箱体内/逆势单："有赚就跑，不要太格局"（B）。
- **从不补仓**："开完了止盈止损设好了，亏钱我就止损"（B）；不滚仓、不对冲、不网格。

### 3.6 仓位管理：三份法（最出圈、也最被争议）

**A 级原文（几乎逐字）**：

> "比如你拿出 3 万 U 来做合约，分成 3 份，每份 1 万 U。每次开仓用其中 1 份，固定的 1 万 U，大饼不超过 10 倍，山寨不要超过 5 倍。亏了 1000U 就从外面补进 1000U，赚了 1000U 就把 1000U 提走。确保每次开仓都保证在固定 1 万 U。直到 3 万 U 赚到 6 万 U，把每份仓位提高到 2 万 U。"

三条理由（A 级原文）：① 分仓 + 低倍躲开插针；② 上头时**最多爆掉 1/3**；③ 固定仓位让盈亏时心态平稳。

执行层：

- **只把 1 份放合约账户**，另 2 份放资金账户/场外，天然后手；
- **全仓模式**；**一次打满**、不分批；
- 杠杆上限：**BTC/ETH ≤ 10×，山寨 ≤ 5×**（实际多数 5×，整体杠杆率 ≤5×）；
- **拒绝复利**（A 级）："**复利回撤太大，我的系统不支持。**"
- 新手版：山寨 2–3×、主流 3–5×；小资金 100–2000 元也分三份练。

**关键纠偏（A 级）**：有人问"固定仓位还是固定止损"，他答"**固定仓位，止损不固定**"；又问"开仓大小会不会变"，他答"**开仓大小是根据行情级别和确定性决定的**"。→ **"铁律 1 万 U"是对外的新手简化版，他本人执行是浮动的。**

### 3.7 频率、工具与心态纪律

- **频率**（D）：500 多天里只有 **2 天完全空仓**；日均 **6–8 笔**，热时 10–20 笔；**一半交易持仓 < 10 分钟**；持仓 >24h 仅 **18 笔**（0.3%）。
- **看盘**（A）："没行情基本不看盘，真正交易的时间也就 **5% 不到**"；"大饼/以太关键位设警报，用 AiCoin 看热度榜"。
- **工具**：裸 K、AiCoin、币 Coin、标记价格、多屏；**不用指标/均线/斐波那契/订单块/清算地图**（无一手证据）。
- **三条铁律**（B）：**不做逆势单、不乱刷单、不做没有逻辑的单子**。
- **心态**（A）："一颗宁静的心始终是职业交易者最强的武器"；上头就"**关机，离开盘面**"。
- **复盘 SOP**（B）：周期定性 → 逐单分类（体系内亏损 / 逻辑错误 / 纪律错误）→ 遮挡未来逐根推 K 线 + 同类横向对照 → 量化归因，输出三条可执行修正。

### 3.8 隐藏技能：接针（新手勿碰）

- 针 = 一两根 K 线突然扎下又立刻拉回；**三条件同时满足**才接：① 大级别上方还有空间；② 针**没有击穿实体支撑区**；③ 整体仍在**第一波上涨**里（二波/高位盘整的针不接）。
- 操作：等针尖企稳出拐点再进，**不一路往下接**；止损放实体支撑区再往下一点。
- 案例：2023-11-10 凌晨 BTC 从 3.8 万插针到 3.53 万，3.62 万进、止损 3.52 万（2.85%），10÷2.85≈3.5 倍，止盈 3.75 万/4.5 万（C 级）。

## 5. 币种（交易对象）

**结构**：BTC/ETH 是"温度计"和方向锚，真正下重手的是**山寨龙头**。

| 类别 | 币种 | 说明 |
|---|---|---|
| 定环境 | **BTC、ETH** | 只作为市场温度/方向判断，不做主战场（也做 BTC/ETH 合约） |
| 经典主升浪案例 | **PEOPLE**（+118 万 U 名场面）、**SOL**（2023-10 二波）、**ORDI**、**LINK** | 均为"龙头 + 启动/二波"样本 |
| 常被提及的炒作币 | **DOGE、SHIB、PEPE、TRB、GALA、MOODENG、WIF** | 他称之为"有完整洗盘拉升过程、与 BTC/ETH 共振"的币 |
| 反例/教训 | **OP、LTC（辣条）、BNT** | OP/LTC：高位情绪下"看似结构很好的突破"是最容易亏的两类周期之一；BNT：盘口太浅、流动性差，重仓会被自己砸穿 |
| 筛选池 | **AiCoin 热度榜前 10（剔除 BTC/ETH）+ 近期明星次新** | 新上榜 → 等调整 → 看日线结构/跟涨/抗跌 |

> 结论：**币种不是固定的，是"当期最强龙头"**。可复刻的是筛选规则（热度榜 + 次新 + 跟涨 + 抗跌 + 箱体结构），不是某一个币。

## 7. 争议、风险与"不可复刻"清单

### 7.1 核心争议：仓位管理是否科学

- **质疑**（[知乎](https://zhuanlan.zhihu.com/p/2047354554904318390)）：只固定名义本金和杠杆上限、**不管止损距离**，止损 0.5% 与 2% 时单笔风险差 4 倍 → "风控形同虚设"；主张**以损定仓（单笔 1%）**。
- **支持**：① 这套仓位是**配合入场**的——小级别震荡很少入场，止损距离本身被入场位置约束；② "三等份适合新手"，他实际下单是浮动的；③ "把这套逻辑放震荡里用，止损都得吃麻"。
- **本人回应**（A）："**开仓大小是根据行情级别和确定性决定的**，偶尔会上头，只要严格止损并不致命。"

### 7.2 其它风险

1. **数字不可核实**：收益终点 5 个版本，全部自述/截图。
2. **样本期偏差**：2022–2024 主要是单边牛市，"只做多、只做主升浪"**没有熊市/长期震荡的样本外验证**。
3. **幸存者偏差**：他自己承认"从小资金做起来的概率万中无一""考研上清北是万里挑五"。
4. **同名账号风格漂移 / 冒充**：2025–2026 年多平台出现同名账号带单/发分析；实测其风格（100X、满手空单、代币化美股、86.8% 胜率、扛亏损单）与历史体系**完全相反**，本人可能性存疑。**不要跟单、不要付费**。
5. **可复制性低**：需全职、每天 10 小时盯盘复盘；知乎分析师估算这套超短模式**只能用 300–1000U 极小资金测试**。
6. **执行难度**：他本人在直播里反复承认会"犯病"、上头、追高——**区别只在于始终带止损、始终分仓**。

## 8. 对"蒸馏 + 复刻"项目的可执行含义

### 8.1 可量化、可回测的部分（建议优先实现）

| 模块 | 规则化描述 | 数据需求 |
|---|---|---|
| 市场状态 | 用 BTC 日线/4H 结构定义"春夏秋冬"：突破/主升/高位震荡/下跌 | BTC 日线、4H |
| 选币 | 热度榜前 10 + 次新 + 第一波跟涨 + 相对 BTC 抗跌 + 日线箱体 | 山寨日线 + 热度榜历史（难） |
| 位置 | ① 箱体突破回踩；② 第一次小分歧低点；④ 大分歧后二波回踩 | 多周期 OHLCV |
| 扳机 | 5m：低点后 3 根不破 + 阳线收盘破前高 | 5m OHLCV |
| 止损 | 5m 拐点低点下方；单笔风险 ≤ 10% 那份本金；标记价格 | 5m/1m |
| 止盈 | 日线前高/整数位；两道止盈；RR ≥ 3 | 日线 |
| 仓位 | 固定名义本金 / 按级别浮动；杠杆 ≤10×（BTC）、≤5×（山寨） | — |
| 频率 | 按"季节"调节日交易数上限 | — |

### 8.2 难量化的部分（蒸馏时要显式标注为"主观/不可复刻"）

- "**上方还有多少空间**"的判断（空间感/结构经验）；
- "**龙头**"的识别（热度榜 + 盘感 + 板块叙事）；
- "**市场温度**"的定性判断（资金、情绪、赚钱效应）；
- 拐点的"**企稳**"感觉（3 根不破是形式，背后是盘口/量能经验）；
- 加仓/减仓的临场判断（他自己都说 PEOPLE 回踩加仓是"危险动作"）。

4. 忽略"**只做多 + 牛市样本**" → 熊市直接失效。
