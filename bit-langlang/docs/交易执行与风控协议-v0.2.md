### 2.2 关键修改（相对 v0.1）

1. **季节**：7 阶段 → 3 状态（趋势/震荡/下跌）；日线 shift(1)；每周更新；季节只控**频率**，不控方向。
2. **空间**：删除"<3R 不做"（事前不可观测）；改为"止盈 ≥1.5R（覆盖成本）且 ≤ 可观测前高距离"，作为**记录项**而非否决项。
3. **胜率/盈亏比**：删除"40%+3 倍"目标；改用 `胜率×盈亏比 > 1+成本占比`。
4. **只做多**：保留 90 天首期约束；空头登记为独立待验证腿（不再称"进阶项"）。
5. **流动性**：量化——1% 深度 ≥ 名义 20×；单笔 ≤ 5m 均额 0.5%。
6. **逆势**：按日线/4H 定义；5m 反转不算逆势。
7. **选标的**：首期写死 1–3 个；"龙头"只作排序，不作准入。
8. **盯盘**：**开仓后 15–30 分钟必须在盘**（出场 α 是唯一 edge）；计划内 ≤3h/天；删除"没有警报就不看盘"。
9. **位置**：只保留"预判承接/假突破收回"两种，且**不作否决**，仅记录。
10. **止损距离**：统一账户 % 公式；**止损距离 ≥1.0%**（否则成本闸门不过）；紧止损需有 maker 返佣才允许。
11. **市价**：加深度/名义上限；大单拆单或限价。
12. **提前离场**：唯一合法理由 = 结构失效（5m 摆动破位）；否则持有。
13. **分批卖出**：默认**一次性**；删除"T1 减半"作为默认（它砍掉 98.6% 利润来源）。
14. **连开 3 单**：删除；改为"连亏 3 笔 → 冷却 30 分钟"。
15. **复盘分类**：4 类——体系内亏损 / 逻辑错误 / 纪律错误 / **规则错误**（按规则做仍亏）。
16. **周复盘**：必须报 2 个数字——规则错误笔数、成本/毛利。
17. **分仓映射**：总资金 T → 合约 T/3 → 单笔 ≤T/9。
18. **扩张规则**：V1–V4 全过 + 3 个月正期望 → 仓位 ×1.5（此前永远不放大）。
19. **连亏停机**：删除"8–10 笔停机"；改为**回撤 6% 停机** + 连亏 8 笔仅降档复盘。
20. **单日新开总风险**：≤3%；同币不重复开。

### 2.3 删除的 7 条（红队 DEL1–7）

| 删除 | 理由 |
|---|---|
| 3R 硬门槛 | 事前不可观测；v1 内置 ≥5% 仍只 3.0% 达标 |

## 5. 成本闸门（V0）

`往返成本(bps)=2×(fee+slip)`；`成本(R)=往返成本÷止损距离%`；**成本(R) ≤0.2 才允许交易**。
- taker 5bp+滑点 5bp → 止损必须 ≥1.0%；
- 若只能做 0.4% 紧止损 → 必须有 maker 返佣/更低费率，否则不做。

## 7. 仍未验证 / 不可解决

1. **2024-07 后无他的真实样本**：今天是否还适用，无法用历史验证，只能 V4 前瞻。
2. **机械核心负期望**：`verify/replay` 实测 Top3/天、止损中位 1.04%、往返 10bp 下，净 **−0.192R/笔**（毛 +0.014）。
3. **出场 α 可能是执行 artifact**：无法区分真实择时与平仓冲击。
4. **94% 的美元来自规模**：本协议主动不复利，因此**不追求复刻收益**。
