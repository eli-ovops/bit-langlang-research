## 对判读的影响

2022 与 2023 各自从首点至次点，现货价格上涨，v0.2 条件由未触发变成候选；当时之前存档的指数分别由 23 变为 34、由 25 变为 52。这些同时发生的描述，**不能证明情绪变化导致启动，不能证明两次处于同一阶段，也不能从两个案例推导门槛**。第三个点均为非候选，2023 年 1 月 23 日情绪页面仍 UNKNOWN，不能用当前 API 的回填值替代。

按浪浪截图中“周期、空间、情绪”研究时，应分别列示大级别背景、参考区域及其形成、观察时已发生的小级别变化、来源带时间的情绪/参与线索，再保留相反解释；不足的真实阶段和情绪留空。截图本身没有给出本表的指数、数值阈值或 v0.2 公式。该观察流程是研究操作化，不是他已证实的规则。

六个周点来自两个连续时间窗口，彼此不独立，且均为已看过的历史；没有独立阶段评审，不计算阶段准确率、漏判率或复刻程度。后续 28 日价格之前单独保存于[事后材料](浪浪周期-2022与2023同期阶段对照-20261110.md)，本 T0 矩阵没有读取或合并该结果。
