# 盘口逐条归档：单次公开预检定义

在此前一次性公开预检的相同 ETHUSDT 公开 WebSocket 和 REST 快照方案上，启用本地逐条归档。先完成合成成功和写入失败测试，再仅运行一次：一次连接、一次快照、最多 8 秒或 500 条消息，不读账户、不下单、不启动或停止平台策略。

每条文本消息收到后立即写入新的单写者归档并 fsync 文件及目录，REST 原始响应单独独占写入并 fsync；原始文件和派生文件并存。若网络、归档或快照写入出错立即停止，不重连或换路径，归档保持未封存或 INVALID，记录错误。成功结束后仅当序号接合和有限深度重建均为对应 PARTIAL 状态时，封存消息记录；封存是本次有限采集已结束的本地记录，不证明期间没有漏包。

记录每次逐条写入本机耗时的统计、消息数、末哈希、封存哈希、序号和价量检查及原始响应哈希。短时耗时不代表长时间或高峰性能；连接、时钟、来源、首尾覆盖、订单和真实成交均未认证。若进程被强行终止，事后只通过独立检查器读取可恢复的前缀，不能当作完整捕获或真实前瞻；不要补写未知事件。
