# 同期存档串行补核：发现一处实际指标口径差异

## 结论

在[上轮版本检查](浪浪周期-同期文章版本校验结果-20261109.md)的基础上，按默认 TLS 校验串行补取六个观察前的官方文章存档。其中五个的返回时间与预先选定的最近 CDX 抓取一致；另一个被站点重定向到更早的抓取，故不能称已取得预先选定的最近版本。

最重要的发现是：**2025-04-16 的文章在观察前的早期存档，与现页对一项亏损相关链上指标的表述存在实质差异。**早期文本使用“未实现亏损”表述；现页相应位置改为“亏损供给的已实现市值”等表述。这两种量不能不加说明地视为同一指标；本项目没有复算任一指标，不能裁定哪个版本正确，也不能把现页数值直接当作 04-22 观察时的已知数据。

## 六项核查

| 项目周点 UTC | 实际存档 UTC | 版本对比及限制 |
|---|---|---|
| 2023-02-26 | 02-25 12:13:22 | 所选存档正文归一化后与现页一致；HTML 标题少一个冠词。 |
| 2023-03-05 | 03-03 12:12:37 | 所选存档正文一致；文章主体讨论 ETH/NFT，不能以此补出 BTC 阶段。 |
| 2023-03-12 | 03-08 08:57:21 | 所选存档正文一致；HTML 标题存在冠词差异。 |
| 2023-03-19 | 03-13 12:02:59 | 所选存档正文与现页一致。 |
| 2025-04-15 | 04-10 22:18:18 | 所选存档与现页行情正文一致；免责声明附近多一个词。此前该时点版本风险已部分解决，底层指标仍未复算。 |
| 2025-04-22 | 04-16 16:53:25 | CDX 中预选最近抓取为 04-18 01:54:10，但请求后重定向到 04-16 的较早抓取；两者都早于观察点，但 **04-18 版本正文未知**。04-16 存档与现页存在亏损指标用语及其他文字差异。 |

上述“正文一致”指使用同一 `section.gh-content` 抽取、移除脚本/样式并统一空白后的文本一致，不涵盖动态数据、图表、图片、链接目标或站点其余部分。前 4 项与 04-15 的 Memento-Datetime 均和预选的 CDX 抓取严格一致；04-22 直接保留站点重定向及真实 Memento，不能把 HTTP 200 当成最近快照核验成功。存档抓取时间本身早于观察时点，也不证明其是原作者的最初发布版本。

## 对既有报告的影响

上轮 24 篇中 6 篇通过预选存档核查；本轮新增 5 篇，所以目前 **11 篇达到该文本对比口径**，另外 13 篇仍未达到，其中一篇有更早但非预选的替代快照。前述 `DIFF` 包含非行情文本单词差异，不能全部描述为正文逐字相同。2025-04-16 一文的指标差异须单独保留；原[2025 全季报告](浪浪周期-2025二季度同期周报连续对照-20261109.md)已更新风险标识，不能用它算阶段真值或声称当天实时知情。

复核原始 HTTP 头中的 Memento、日期与 2023 原索引或 2025 重新取得的 CDX，检查所有抓取时间均早于各自周点、原始响应和头文件 SHA256，保留 gzip 传输原件及离线解压哈希；回执和逐项差异见[独立核对记录](../data/verify/cycle-report-archive-recovery-20261109-01/audit_verified.json)。系统 curl 串行请求取得结果不说明上一轮 TLS EOF 的根因，也不代表所有未知存档可用。原始 HTML 和 CDX 是研究证据，保留不清理。

这一步改善了同期文字的可追溯性，但未完成未参与规则设计历史行情或独立阶段评审；作者观点和浪浪原话仍需分开。没有选币、入场、交易或执行平台 start/stop。
