# 2022Q1 与 2024Q2：周期、空间和情绪逐段复盘

## 主要发现

两段行情为研究“反弹还是启动”提供了不同环境：2022Q1 的 BTC 现货日收多次跌出、收回期初固定区间；2024Q2 的季度日收则大多处于期初区间内部，只有两次日收低于下沿。**区间内反复、短期转强或一次收回，都不能直接证明震荡即将结束，更不能独立确认启动。**

这两段行情和部分后续结果此前都已被研究；本轮是事后逐段复盘，不是独立留出或阶段准确率验证。截图署名 Bit浪浪 的回答强调周期、空间、情绪及市场阶段，但没有给出本表的固定 28 日、56/28/8 窗口或资金费判定公式。[原话归属](浪浪周期-阶段术语归属及突破条件审查-20261105.md)

## 数据口径

按[本轮定义](浪浪周期-2022一季2024二季逐段复盘定义-20261105.md)，以 Bitstamp BTC/USD 现货观察两个完整季度：2022Q1 共 90 日、2024Q2 共 91 日，分别每七日取一个段首，均为 13 段，2022 末段 6 日。每季起点固定此前 28 个完整日的高低，整季不变；仅用每个段首当时之前已完成的数据。固定区间是研究坐标，不是已证实的支撑压力；该时点此前 28 日形成的较近范围另行保存在[逐段数据](../data/verify/cycle-2022q1-2024q2-segments-20261105-01/asof-segments.csv)。

长/中/短是项目旧 56/28/8 日双半窗口结构：↑=高低均上移，↓=均下移，内=后半范围位于前半内部，混=其他。此前 7/90 日变化来自 Binance BTCUSDT 永续，不是现货交易回报；现货和期货不混价。费率为该时点此前七日的 21 次永续结算正/负数，不是市场真实心理或现货资金流。窗口、区间与费率均非浪浪量化公式。

2022Q1 前五个段首所需更早 90 日日线超出本次保存的 API 响应，90 日变化为 UNKNOWN；2022-01-01 此前费率也缺失。其余 2022 费率仅有本地数据、标 **L**，没有逐条官方响应对账；2024 费率有保存的 API 响应对账、标 **A**。真实阶段、浪浪同期判断和真实情绪全部保留 UNKNOWN，不能根据后续价格倒填。

## 独立列出后来事实与反例

2022Q1 期初固定区间内的日收，在 01-08 首次位于下沿之下，之后多次收回又跌出；整个季度 90 个日收有 40 个在区间内、50 个在下方。01-15 时短尺度向上，但到 01-22 的日收已在固定下沿下方；不能仅凭 01-15 的短期上行确认启动。跨越均在相应 UTC 日线收盘后才可知。

2024Q2 的 91 个季度日收有 89 个在期初固定区间内、2 个在下方；05-02 00:00 首次收在下沿下方，05-04 00:00 收回。2024-06-17 前 28 日的**较近**下沿为 64,936 美元，不同于期初固定下沿 59,313；Bitstamp 后来于 06-21 日收跌破该较近下沿，之后七个完整日未收回。这两条参考线不能混用；两所对应跌破时间不完全相同。[原双所研究](周期研究-2021与2024二季度连续复盘结果-20261104.md)

区间里的反复可能出现在后来不同的路径中；单次上越、下破或收回都不是阶段真值。两个季度根据已见历史选取，不能从中计算真假启动率，也不能声称浪浪本人会在这些时点如此判断。

## 核验
