# 前瞻扫描：两币历史网格一致性核验

扫描入口此前分别检查 BTC 和 ETH 行情的新鲜度、5 分钟网格及最少 205 天预热，但仅比较两币最新已收盘 K 线的时间。合成复现显示：即使最新时间相同、各自连续且达到最少预热，BTC 比 ETH 多一根早期 K 线时，旧扫描仍将 ETH 标为 FRESH 并可能生成观察信号。两币使用不同起点时，日线指标的预热背景也可能不同；这不等于已证明实际发生了错误信号。

已修复 `verify.forward_scan.build_snapshot`：在计算该币相对于 BTC 的信号之前，要求两者**完整已收盘时间网格一致**。不一致时该币返回 `INVALID`，不产生候选或 watch，同时保留其输入哈希；BTC 自身仍按原校验。该检查是研究采集口径的保守要求，不证明数据来源、时钟或行情真实，也不解决下一根开盘能否成交的问题。

回归测试先用两份连续且最新时刻相同、起点差一根的合成行情复现旧问题，修复后检查 ETH 为 INVALID 且不调用其信号计算；两币对齐时仍为 FRESH。另针对此前历史研究使用的数据，在 2026-10-25 UTC 截止时核对 BTC/ETH 网格一致，各为 506304 根；这一核对不证明所有历史数据或实时行情的其他质量问题均已解决。

此修复不修改冻结策略、不创建或启停平台策略。行情及回测结果仍须按[纸面前瞻研究阶段决策卡](纸面前瞻研究-阶段决策卡-20261030.md)所列条件判断。
