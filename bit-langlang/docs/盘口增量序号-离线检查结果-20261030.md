# 盘口增量序号离线检查结果

[Binance USDⓈ-M 官方本地订单簿说明](https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/websocket-market-streams/How-to-manage-a-local-order-book-correctly) 给出快照与增量接合的序号规则，以及后续 `pu` 与前条 `u` 的衔接方式。新增 `python3 -m verify.depth_sequence_audit --trace <已有JSON>` 对保存的记录做离线序号检查，遇到断链标 GAP；没有桥接事件标 UNKNOWN。输入和定义分别计算 SHA-256。

三项合成测试通过，覆盖桥接、旧事件丢弃、断链、重复/倒退、缺桥、错误标的/类型和 JSON 重复键。工具对后续 `u` 严格递增还有额外本地保守要求，可能拒绝交易所可能允许的记录；没有声称该要求来自官方。

即使序号连接也仅返回 `PARTIAL_CHAIN_UNVERIFIED`。此工具不重建价量、核验接收时钟与连接生命周期，也不证明源真实性、首尾无漏、止损触及或成交；没有运行真实 WebSocket 或平台策略。其作用只是为后续核验真实捕获和重连缺口提供一个形式检查，不能替代持续观察。
