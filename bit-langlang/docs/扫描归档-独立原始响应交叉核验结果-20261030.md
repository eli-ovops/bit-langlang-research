# 扫描归档：独立原始响应交叉核验结果

新增 `verify.paper_scan_source_independent`，以独立的 CSV 和 Decimal 解析逻辑核对采集前基线、原始 K 线响应与归档行情：检查旧 CSV 原样保留、响应重叠行、时间网格和 OHLC，并比较实际追加行与已收盘响应。它不调用采集器的 `load_base` 或 `advance`；归档压缩载荷的读取和哈希校验仍复用项目归档模块。

七周期合成归档中，首条及后续六条共 **7 次过渡均匹配**，状态为 `PARTIAL_INDEPENDENT_CROSSCHECK`。单步合成测试还检查修改行情行、分页参数或扫描时间时会拒绝；一份既有旧预检归档缺首条基线，结果仍为 `UNKNOWN_INCOMPLETE`，没有被追溯补证。

运行入口：

```sh
python3 -m verify.paper_scan_source_independent --archive <归档目录> --expected-head <预期头部SHA256>
```

这提高了对采集器自身解析错误的检出能力，但不是完全独立的归档实现；预期头部、原始响应、交易所来源和时钟均未独立认证，也不证明真实连续行情或成交。该工具只读已有归档，不连接网络、不启动平台策略。[核验定义](扫描归档-独立原始响应交叉核验定义-20261030.md)
