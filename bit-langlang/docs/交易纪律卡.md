# 交易纪律卡（打印贴屏幕）

## 开仓前·五问（全"是"才做）
1. 现在是**春/夏**吗？（秋/冬 → 不做）
2. 到上方阻力 **≥3R** 吗？
3. 位置是：①突破回踩 ②第一次小分歧 ④二波回踩？（其他 → 不做）
4. 止损在 **5m 拐点/前低下方**，单笔亏损 ≤ **1.5% 账户**？
5. 这笔亏了，我明天还会按规则做吗？

## 下单
- [ ] 先挂止损（标记价格）
- [ ] 一次打满（不分批）
- [ ] 市价成交
- [ ] 截图 + 写理由（5 行以内）

## 持仓
- [ ] 没到止损 = 不下车
- [ ] T1（2–3R/第一压力）减半 → 止损推成本
- [ ] 剩余跟踪 5m 摆动低点
- [ ] 不看 1 分钟、不刷群

## 禁止（犯一条 = 当天停手）
- [ ] 改/撤止损
- [ ] 补仓、摊平、加仓
- [ ] 反手
- [ ] 逆势/摸顶
- [ ] 连开 3 单不休息
- [ ] 盯盘 > 2h

## 停机条件
- 连亏 **8–10** 笔 → 停 1–3 天
- 日亏 **-5%** / 周亏 **-10%** → 停手
- 心态乱 → **关机**

## 每天收盘 20 分钟
- [ ] 记录 8 项（日期/币/方向/入场/止损/出场/仓位/理由）
- [ ] 分类：体系内亏损 / 逻辑错误 / 纪律错误
- [ ] 明天只看 1–3 个标的，设警报

> 目标不是赚钱，是**按规矩做完每一笔**。
