# 周期近似筛选：动态对照的事后探索定义

该方案在看过 106 笔静态分组结果之后制定，**不是事前独立假设或样本外**。问题是：当加入一个简化条件、并重新处理被释放的仓位及资金后，静态分组结论是否仍然成立？

- 保留原冻结 ETH 规则、既有数据与窗口 UTC `[2024-07-01, 2026-10-25)`。比较原信号和额外要求「入场前一天已完成的 ETH 20 日收益小于 20%」的信号；使用完整 288 根 5m 数据的首尾日计算，日期和数据缺失时不允许该候选入场。20 日和 20% 是研究者选择，非交易者原话。
- 两组分别从 2000 USDT 空仓开始，使用 `verify.tph_ledger.replay` 重算仓位占用、每日/并发限制、资金费、逐仓清算代理和窗口末未平仓权益。两组均单边手续费 5bp、滑点 2bp，其他参数不动。
- 逐笔保留账本、所有被过滤的候选时间、输入及代码哈希；报告候选、交易、期末权益、5m 收盘权益回撤、资金费、手续费和清算代理。对每组校验权益等式、交易与候选时序、分组条件。两组入场不同，不把收益差当作配对交易差或因果证据。
- 此处已看过同一数据，筛选有严重选择偏差；不能宣称筛选有效、可真实成交或具备前瞻资格。5m 回撤不包含柱内低点；交易场所、真实费用、标记价、保证金和清算均 UNKNOWN。不修改冻结规则，不启动或停止平台策略。
