# 2025 年第四季度：年度位置与广度分歧的回顾性扩展

## 为什么继续与证据边界

看过 2022–2026 五个目标月份的完整归档参与、BTC 年度范围及后续后，发现 2023/2024 的分歧案例靠近年高、2026 案例位置较低，而 2025 年八月高位案例随后亦有回落。为检查是否存在更多反例，本次在取得新的归档月包和计算本轮 2025Q4 广度结果前，固定 [2025-10-01,2026-01-01) 全部 92 个 UTC 日点；所有非触发、缺失和两所状态均保留。2025Q4 已参与项目回测及部分交易研究，BTC 后续历史广为人知；该扩展由已知结果引发，不是独立盲测、前瞻或无偏样本外。

## 固定的研究对象与观察条件

从此前已留存的 Binance USD-M 目录快照中，以 USDT 结尾且非 BTC 的全部 922 个目录为候选，逐个请求 2025-09、10、11、12 月的 1d 月包及 checksum，保存全部请求状态、ZIP 和校验文件。只统计 t 之前连续 29 根完整已完成 UTC 日线、OHLC/价格/量有效且所属月包校验通过的对象；缺失和零量 UNKNOWN，不视为下跌或推断上币/退市。当前目录快照不保证历史交易池完整、可能存在更名/倍数/特殊合约，合约数不是唯一币数，全市场广度、真实资金流、投资者心理及浪浪本人同期阶段 UNKNOWN。不得以此筛选交易币或做入场。

BTC 56 日研究背景使用 Bitstamp、Kraken BTC/USD 现货各自 4h 独立构建的既有双半窗方法；数据来自 Bitstamp 公共 4h 响应与已保存 Kraken 官方 4h 成员，至少包含季度开始前 57 日、季度及末尾后 28 日。每个 t 截止此前 K 线，标记数据缺口、无效或跨所同柱高低比大于 1.1/小于 0.9 的提示；涉及问题的相关时点 UNKNOWN，不交叉填价。BTC 年度位置使用此前留存 Binance BTCUSDT 永续 API 的 [t-365d,t) 同一来源 365 根完整正量日线，空间 `(最近完整日收-年低)/(年高-年低)`；现货与永续是不同产品，位置信息分列不拼价。7 日资金费使用本地 Binance BTCUSDT 永续 t 前 21 次 8h 结算，若追加公有接口核对失败按来源未验证，不更改字段或绕过拒绝。

以先前五个月归档参与报告的研究候选原条件不变：各所 BTC 56 日代理 UP、当时有效归档合约 28 日上涨比例 ≥80%、7 日上涨比例 ≤60%，标记分歧；数据不足标 UNKNOWN，其余均 OTHER。为了检查上一轮已见案例激发的年度位置想法，**只在该候选内**以年内位置 ≤50% 为 LOW、>50% 为 HIGH。50% 是在看过历史后人为设定的探索性分割，不是浪浪规则、事件真值、已验证过滤器或交易信号；全体原始背景、分母、位置及两种分类均保留。不得根据本季度结果再次调整阈值，观察样本稀少时不能计算或声称稳健胜率。

后续 7/28 个完整 UTC 日末 BTC 现货日收变化仅是事后价格事实，不是当时已知、真实阶段、交易收益或最终触发规则；相邻时点和两所价格高度相关，不能视作独立实验。完整报告所有日点和跨所矛盾，缺口 UNKNOWN，结合已知压力位置、样本分母与资金费给出多种竞争解释。若本期无候选则如实汇报无条件覆盖，不换期、不补造案例。

## 数据和验证

归档全量目录分页快照、每月请求状态、checksum 原件及 SHA-256 保留；Bitstamp 4h 分页原响应、请求、哈希及 Kraken 本地源哈希保留；核验 4h 网格、OHLC、正量与跨所价差提示，后续单独质量标记。结果以单所、两所合并/分歧及所有非触发时点输出；从原数据独立重算若干边界、年度位置、宽样本分母与未来窗口，测试未来数据扰动。归档不保证所有历史退市品被保存，也不能证明当时实时可获得。禁止选币、设计入场、交易或执行任何平台 start/stop。
