# 未平仓与盘口会话风险核对：验证结果

新增离线检查入口，将已保存的完整预检会话与给定纸面未平仓账本按时间关联，检查事件最终状态的可确认买一是否不高于账本止损。联合风控已 STOP 或某个有效会话观察到该条件时，报告 STOP；即使其他会话损坏也保留告警与错误明细。没有观察不等于安全，连续路径始终 UNKNOWN；该入口只做文件对照，不操作平台。

使用此前公开 ETH 盘口样本，事后构造**虚构**未平仓：入场价 2248、止损 2239.008、数量 0.1，初始价格风险 0.8992 USDT；估值亦为合成，不代表账户价格。文件核对识别到入场后一个已保存事件的买一为 2238.28，低于该虚构阈值，返回 STOP；该结果不代表真实持仓、订单或实际触发。合成输入及结果位于 `data/verify/open-depth-synthetic-20261030-01/`，公开会话原始资料单独保留。这个示例是在看过数据后构造的，仅验证软件链路，不能用作策略业绩。

新增入口、会话核对、既有未平仓风控和盘口模块共 13 项合成测试通过，覆盖入场前事件、事后采集、阈值、会话损坏及缺口。正常结果最多 `PARTIAL_DISCRETE_UNKNOWN_PATH`；不验证信号、资金费完整性、真实时钟、实际标记价触发、委托成交或批内路径。该入口不读取无效会话的前缀作为报价，因此可能无法报告该会话中此前的观察；必须同时查看 INVALID 明细，不能据此认为安全。

未创建真实持仓、订单或正式前瞻，没有启动或停止平台策略。使用范围见[事前定义](未平仓-盘口会话风险核对-事前定义-20261030.md)。

命令入口：`python3 -m verify.paper_open_depth_review --closed <已平仓CSV> --open <未平仓CSV> --start <UTC起点> --as-of <UTC检查时刻> --sessions <已保存会话目录...> --out <新结果JSON>`。该入口仅按已提供账本关联，不独立验证入场信号、交易事件或账户；须结合既有信号、事件、资金费和账本对账。无 `--sessions` 可用于显示观察缺失。

时间因果补充：增量消息可能在 REST 快照响应完成前已经到达，此时仅凭接收时间不能知道完整盘口。现在每个触及明细同时给出消息接收时刻和 `book_state_not_before_utc`（消息接收与快照响应完成两者中较晚者）；该值只是可用时间的下界，并非盘口重建或交易决策的实际时刻。逐条文件持久化的具体时刻未记录，明确标 `durably_persisted_at_utc=UNKNOWN`。合成缓冲消息案例及相关 9 项测试通过。此前虚构持仓示例的触及出现在快照完成后，按新代码复核仍为 STOP，新输出为同目录 `SYNTHETIC_result_causality.json`；原文件保留，但其时间字段不得单独解释为盘口可用或成交时刻。
