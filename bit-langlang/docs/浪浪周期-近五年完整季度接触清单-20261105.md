# 近五年 BTC 历史季度：项目接触清单

## 目的和边界

本清单按 UTC 自然季度汇总已有文档中能够直接找到的项目研究记录，目的是防止把已用于研究的整季行情误称作全新独立留出集。只检查所列文档，不声称已穷尽项目文件、完整上下文或模型先验。这里的“已研究”不等于每个时点都直接用于规则参数设计；是否直接或间接影响某个特定候选，须审查该候选形成时间和输入，不能一概断言。未发现记录也不证明未接触。

近五年以 2026-11-05 为基准，起点约为 2021-11-05。完整历史季度从 2022Q1 开始；2026Q4 尚未结束，不能作为完整季度。下表记录的是项目已有研究，而不是本轮新算的行情质量或阶段真值。

## 结论与下一步

在已检索的材料中，2022Q1 至 2026Q3 的每个完整自然季度均有项目研究接触证据，难以把其中任何整季无保留地称作未接触的独立留出集。这个清单并未证明所有日点都用于设计，也未证明所有历史都不能用于任何独立性不同的研究。其他市场、外部独立标注者、历史实时发布的观点或以后形成的连续数据可能提供不同层次的检验，但都不能自动消除 BTC 同期行情或设计者先验的暴露，必须分别说明。

现有独立评审表仍待实际填写，阶段标准与旧候选的独立对照、三阶段的漏判误判和反例检验尚未完成。阶段、情绪和浪浪同期真实判断仍按证据留空；不选币、不设计入场或交易，不执行任何平台 start/stop。
