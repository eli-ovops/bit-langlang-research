# 九币纸面实验：完全虚构路径的算术演练

## 做了什么

新增[隔离测试](../verify/test_nine_paper_path_synthetic.py)：在测试进程内部构造虚假的 BTC 日线、九个虚假的币种序列、两根虚构 4h K 线、模拟报价和一条模拟资金费；用实验性市场条件、强弱排序及入场形态产生一个**虚构样例**，再交给独立账本算术检查器计算初始风险、双边假设手续费、带符号资金费、净盈亏与净 R。测试数据与用户纸面账本分开，不创建事件、不发送订单、不连接账户或行情服务。

检查了模拟尺寸的初始价格风险不超过假设权益的 0.5%、名义金额不超过权益、价格中已反映的假设滑点不再次扣除、缺一个币的数据不能返回排名，以及截取人工追加的未来数据前结果不变。报价和时间仅为测试代码中的虚构值，不能作为某一市场的有效交易或对真实条件的建议。

本次运行 `python3 -m unittest verify.test_nine_paper_path_synthetic verify.test_paper_nine_accounting verify.test_paper_nine_initial_bridge`，**16 项测试通过**，其中新增 3 项检验演练路径、币池缺失和切片时间边界。这里的市场条件和排名函数写在测试文件里，并非可运行的实时观察器；人工构造的时间检查只说明该样例顺序，没有证明未来记录不可回填或数据可实时取得。对未来数据的扰动只验证该测试中的显式切片，不构成整个系统的泄漏审计。

## 仍不能证明什么

合成路径仅证明所给数字在所测逻辑里可以对上；没有真实报价、连续盘口或实际触价顺序，不能把模拟目标价穿越当成实际成交，也不能证明虚构资金费是完整的。账本检查器仍返回 UNKNOWN，因为没有证明来源、信号、执行、资金费覆盖、权益完整性与实际强平；测试结果不是策略盈利。

v0.1 市场“回撤”表述失真尚未修复为经验证的新模拟策略；此前 v0.2 只作为研究候选。真实纸面观察仍只有首次空仓记录，没有持续监控、事件流水或新增纸面交易。新文件与本文为研究成果并保留，无需清理的临时产物；未访问真实账户或操作任何平台 start/stop。
