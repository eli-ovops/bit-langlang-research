# A01 历史市场列表可用性检查

问题：在不依赖今日幸存币池的前提下，能否找到 A01 截点之前的 CoinGecko 首页存档，作为第三方当时市场列表的片段性证据？先对官方 `https://www.coingecko.com/` 首页查询截点前一完整 UTC 日的公共存档索引；按存档时间最早且状态 200 选择，核查 replay 的 Memento 时间、响应和可见正文，保存原始响应及哈希。没有索引、无法访问、无法确认 Memento、主体未渲染或更新时间不明，则相应内容 UNKNOWN；不绕过限制或根据今天页面补全。

若页面提供当时可见的原始市场排名或涨跌信息，记录其页面标注的覆盖和时间；展示 30 个（不足则全部）按页面原顺序的对象，只做历史列表和可见性核验。不得因后续结果或涨跌挑对象；这是测试数据源，不是选交易币。所见行不是全市场、资产身份/重复和退市历史不是由排名自动证明。排名时间、当日变化、七日变化的更新时间和计价来源若未标明均 UNKNOWN，不冒充截点精确实况。

这只是已研究的 A01 历史样本，模型及研究者均已有该行情的接触；第三方当日网页即使可得也不改变历史污染或构成浪浪本人标签。项目旧量化候选和未来行情不得纳入判断。没有证据则保留 UNKNOWN；不选币、不设计入场或交易，任何平台 start/stop 前先告知。
