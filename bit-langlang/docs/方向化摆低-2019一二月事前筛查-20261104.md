# 2019 年一二月方向化摆低事前筛查

在计算本段逐日状态及下载 Bitfinex 本段数据前固定 BTC/USD 现货 [2019-01-01,2019-03-01) UTC 每日 00:00 所有 59 点，原始范围 [2018-11-01,2019-04-01)；方向化 10%、56/28/8 层次及摆低回退冻结，不因结果选日期、排除非触发点或调阈值。Kraken 官方原生 4h 取已留存的完整 XBTUSD_240.csv 成员，Bitfinex 官方 1h 独立聚合 4h，不互相补价。此前 2019 年 1–2 月曾作为其他阶段研究预热，2018 下半年及 2019 年 3–8 月参与既有研究和阶段检查；定向检索未见这一段逐日方向化直接参与候选提出，但间接影响不可排除，不能声称严格独立、未见或盲测。无独立人工真值。

完整性按所与影响窗口分别判：网格、每根正成交量、OHLC；同柱高低比 >1.1/<0.9 为质量警报，整日及依赖窗口标 UNKNOWN。成交 0 不理解为必定行情缺失；不填补。完整期若不合格仍保留单日结果及缺陷，不能称双所整期完整。所有日期记录单所 56/28/8、旧/回退/方向化状态、摆低、日收和 7 日严格下破/收回价格事实，缺失与跨所冲突保留；相邻日不能视独立事件。阶段、真实漏判和假突破若无独立标签为 UNKNOWN。

先在全期识别两所同时 56 UP、28 UP、8 DOWN 且至少一所支撑低于价格超过 10% 的全部日期；不事后改焦点。对每个满足条件日期，取案例决策前最后一分钟逐笔（Kraken 公开 Trades API、Bitfinex 公开 trades hist API），检查时间、ID 或 API 的唯一性限制、数量正值、各自四小时柱范围及成交量，保存原始响应和 SHA。限制页数触顶、缺失或不满足则案例逐笔 UNKNOWN；仅一分钟证据不得表示全柱/全期完整。若无焦点日，明确此期不提供远支撑案例验证，不选事后样本冒充通过。事后事件观察不是真值，不把假设说成浪浪真实规则，不选币/入场/交易/操作代理 start/stop。
