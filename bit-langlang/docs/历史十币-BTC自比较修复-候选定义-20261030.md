# BTC 自身相对强度修复候选：历史对照定义

问题已确定：BTC 的 7 日收益减自身同一收益恒为零；如果所有币一律要求相对 BTC >0，则 BTC 永远不能进入候选。十币历史代理中 544 条可比较 BTC 多头记录均因该结构无法产生 BTC 信号。这是币种门槛的定义缺陷，不代表所有 BTC 交易均应满足其他入场条件。

在查看既有诊断后、计算该候选结果前，单独复制十币历史研究脚本并新增 `three_bar_btc_exception`：沿用[三柱候选](历史入场替代候选-三柱防守-定义-20261030.md)及[十币扩池规则](历史十币入场复刻-补充定义-20261030.md)，仅对 BTC 跳过“收益减 BTC 自身 >0 且排名前二”，改为 BTC 市场背景开启且前 30 个 UTC 日完整；BTC 仍须通过相同 5 分钟形态、4 小时位置、止盈目标和 2R 等条件。其他币逐根信号必须与旧三柱候选完全一致。该修复只让 BTC 有可能进入候选，不声称浪浪要求此公式，也不动现有运行策略。

输出与旧十币研究相同的逐行时间匹配、分币和模型全期信号数；先核对旧两个版本结果不变，再核 BTC 是否出现可见候选、历史时间重合数量和异常/误触发。该规则在看到自比较缺陷后定义，历史已反复研究，**不是独立样本外**；模拟信号不受真实仓位容量限制，匹配只证明有限时间接近，不证明真实决策、止损或止盈被复现。
