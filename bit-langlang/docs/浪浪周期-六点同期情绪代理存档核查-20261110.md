# 六个历史观察点：情绪代理的存档可得性

## 结果

依据[筛选口径](../data/verify/cycle-sixpoint-fng-archive-20261110-01/口径.md)，六个已接触历史观察点的 Alternative.me BTC 恐惧贪婪默认 API 端点在各点前 48 小时内，CDX 对指定 URL、HTTP 200 和 JSON 的查询均返回空列表。这只说明该限定 URL、时间与 MIME 过滤下未找到，不证明其他变体没有存档。

之后额外查同一提供者官网 HTML；在看到第一个结果后，才决定对剩余五点做相同检索，因此本次是补充探索而非盲设验证。读取快照的静态 HTML `Historical Values / Now` 字段，不执行动态脚本，不使用页面示例 API JSON 冒充当时数据。

| 2022-10-24 | 2022-10-23 04:17:53 | 23 / Extreme Fear | 19.70 小时 | 页面未给出数值内部计算截止时刻 |
| 2022-10-31 | 2022-10-30 09:44:34 | 34 / Fear | 14.26 小时 | 同上 |

上述五个成功抓取的存档均为所选时窗内最近的指定官网快照，Memento 与 CDX 时刻相符，原始响应 SHA-1 Base32 与 CDX 摘要一致；[完整值、时间、链接及哈希](../data/verify/cycle-sixpoint-fng-archive-20261110-01/all-six-archived-page-values.json)。在 2022-10-31 样例中，事后 2026 年取得的当前历史 API 对 10 月 30 日也返回 34，但官网快照本身未提供计算日期或底层成分截止时刻，不能仅因数值一致就证明两条记录完全同源或断定 00:00 当时数值未变。

## 与阶段研究的关系

这五个数提供了**观察点之前一个不同时间实际存档的第三方页面线索**，不是观察点即时读数。2022-10-31 页面显示 34 / Fear，而此前同一天 UTC 00:00 的 v0.2 研究条件为候选；2023-01-16 之前页面显示 52 / Neutral，同日该条件也为候选。两者在样本内后续价格不同，但不同快照时间、情绪算法、价格历史和市场环境均不同，不能由两例推断指数预测能力、信号有效性或浪浪本人判断。

[Alternative.me 官方当前说明](https://alternative.me/crypto/fear-and-greed-index/)称指数包含 BTC 价格波动、成交/动量等输入，与 BTC K 线不独立。历史算法权重和每个输入的截止时间未经核实；一个指数也不等于全部市场的真实情绪，更不能当作浪浪的指标或阶段真值。两段行情已参与研究，未达到独立留出和独立人工阶段判读要求。
