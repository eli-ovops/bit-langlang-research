# 00 项目总览与最终结论

## 1. 研究对象与问题

- 对象：加密交易者 **bit浪浪**（2022-05 ~ 2024-06 交割单 4,808 条，10 个币行情覆盖 53.7% 仓位 / 70.7% PnL）。
- 最初问题："他是谁、怎么做、能不能复刻他的高收益低止损"。
- 问题演化：
  1. 复刻策略 → 机械复刻全部为负；
  2. 第一性原理："他为什么赚钱" → 钱来自规模×行情×尾部，不是信号；
  3. "不需要到他那种地步，只要证明**他的做法能赚钱**" → 分离"行为"与"信号"，找到趋势跟随+凸性结构；
  4. 2026-10-29 起：把做法落地成可执行策略（TPH v2 / BTC-ETH 趋势代理），先过回测关，再上 paper。

## 3. 最终判定（分层）

| 命题 | 判定 |
|---|---|
| 复刻他的**收益**（5,000× / 5,000,000U） | ❌ 不可复刻（94% 规模、88% 2024H1、87% 20笔） |
| 复刻他的**入场信号** | ❌ 无证据（9 口径 CI 全含 0） |
| 复刻他的**出场/持有行为** | ✅ 有证据（唯一显著 α：+0.094%/笔；让利润跑） |
| "他的做法"能赚钱 | ✅ 有条件成立：趋势跟随 + 凸性 + 低成本 + 极低单笔风险 |
| 现在能投真钱 | ❌ 不能；只有 paper 候选 |

## 4. 当前唯一候选（两层）

### A. 平台 paper 代理（正在跑）

- 名称：`TPH代理A SMA120-1d BTC 回测通过 20261029`
- 规则：BTC/USDT:USDT、1d、SMA120、只做多、100% 权益名义、3x 杠杆、启动即开仓
- 回测（平台引擎）：
  - 全样本 2022-05~2026-10：**+287.6%，MDD 29.2%，Sharpe 3.06，22 笔**
  - 样本外 2024-07~2026-10：**+34.2%，MDD 28.9%，Sharpe 1.96，16 笔**
  - 稳健性 SMA80~200：OOS 全部 +27%~+44%，Sharpe 1.8~2.2
  - 本地独立复算：+276.9%，MDD -27.7% → 与平台一致
- 当前：running；equity ≈ 961.9；long BTC 0.012 张 @ 80,138.7，浮亏 -37.6（BTC 77,002）

### B. 本地 TPH v2（纸面前瞻，未启动）

- 冻结参数：`verify/frozen_config.json`
- 规则：BTC/ETH、只做多、日线 rs7>0 + 距 20 日高<3% + BTC risk_on；5m 回踩 20 根低点收回；0.4% 止损；日线跌破 EMA20 出场；最长 30 天；单笔风险 0.1–0.2%；并发 ≤3
- 证据：BTC/ETH-only 冻结样本外 CAGR 13.9%（0.1% 风险/3 并发）、MDD 18%、Sharpe 1.53；0.2% → +26.5%/-32.9%/1.56
- 状态：risk_off，无信号

## 5. 明确不能声称的

1. 不能声称"复刻了他的收益"；
2. 不能把代理 A 当成 TPH v2 的证据（平台表达不了 TPH 规则，代理只验证趋势骨架）；
3. 不能把样本内/回测数字当未来收益；
4. 不能在 `forward_report` 给 PASS 之前投钱。

## 6. 剩余风险（按严重度）

1. **多重检验偏差**：BTC/ETH-only、SMA 周期都是多次尝试后的选择；真实前瞻可能更差。
2. **单一周期/单一资产**：代理 A 只做 BTC，2022 熊市小亏，靠牛市赚钱。
3. **样本外不是未来**：2024-07~2026-10 是已知历史。
4. **平台依赖**：AlphaFox paper 免费槽位 5 个；第 6 个起 PAYG $0.01/h。
5. **TPH v2 频率低**：可能数周无信号，需要耐心。
