## 一句话画像

**BTC/ETH 定市场季节 → 只做主升浪龙头 → 5 分钟裸 K 拐点入场 → 极窄止损（0.2%–1%）→ 固定仓位不复利 → 按季节调频率。** 胜率约 40%，盈亏比约 3.3，一半交易持仓 <10 分钟，靠少数大单覆盖大量小亏。

## 真实数据速览（4808 笔，2022-05 ~ 2024-06）

| 指标 | 值 |
|---|---|
| 总收益（逐笔累加） | 5,536,491 USDT |
| 胜率 / 盈亏比 / PF | 40.8% / 3.27 / 2.29 |
| 多 / 空 | 63.5% / 36.5%（多头贡献 76% 收益） |
| 杠杆中位数 | 10×（最大 100×） |
| 持仓中位数 | 7 分钟（56.5% <10 分钟） |
| 手续费 | -750,764（占毛利 13.5%） |
| 年份集中度 | 2024 年 1–6 月贡献 85% 利润 |

## 推进顺序

1. **行情数据**：1m（首选）/5m K 线，覆盖 2022–2024 训练 + 2025 至今样本外；资金费率。
2. **规则引擎**：按 `docs/策略规格-v0.md` 实现五层状态机（季节→选币→点位→5m 扳机→风控）。
3. **回测**：真实手续费/滑点/资金费率，下一根开盘成交。
4. **体检**：去尾检验、连亏压力、参数敏感性、样本外。
5. **交付**：spec + 回测代码 + 报告 + 实盘前检查清单。

## 红线

- 不把二手拆解当本人体系（他本人否定"做突破""看指标"）。
- 不把"固定 1 万 U / 只做多 / ≤10×"当铁律——交割单显示实际是浮动的，且他做空占 36.5%。
- 不忽略"2024 年贡献 85% 利润"的样本外风险。
- 回测不允许隐藏手续费与滑点。
